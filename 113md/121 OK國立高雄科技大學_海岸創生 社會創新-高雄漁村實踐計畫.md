學校名稱：國立高雄科技大學
計畫名稱：海岸創生 社會創新-高雄漁村實踐計畫
計畫類型：大學特色類深耕型計畫
計畫摘要：
問題意識與計畫目標（200字以內）

本計畫以「地方創生」為核心，解決海岸漁村的人口外流、老化、漁業萎縮和競爭力不足等問題。在前期取得成效後，我們深化在永安場域的實踐，同時以海線擴散地方創生。與漁村個體戶及養殖青年合作，結合現行國家政策，致力實現海岸地方創生。計畫以「在地永續」、「人才培育」及「產業創新」為主軸，融入設計力與科技力，期望在計畫持續投入下，實現教學和地方產業創新，致力於實現地方創生目標。

計畫執行重點（200字以內）

計畫聚焦在「在地永續」、「人才培育」、「產業創新」三大面向：(1)在地永續透過社會創新，引入海岸創生模式，促進地方組織及青年參與座談會，強化大學與地方連結，建立大學為地方智庫(2)人才培育以學生及地方青年為對象，發展跨領域課程培育具備地方創生能力的人才，強調核心能力的培養，同時以水域及食品安全為主軸，深化大學與地方連結(3)產業創新致力於轉型地方產業結構，引入負責任生產概念，推動地方產業創新發展。

計畫實質進度（500字以內）

本計畫自106年A類計畫啟動至今年112年C類計畫，已歷經6年的實施。初期主要以漁民團體為主，輔以個體小漁，由團隊擔任主導示範的角色，引領地方參與並深耕創生意識。隨著時間推移，團隊的角色逐漸轉為協助，支援個體小漁培養地方創生實踐能力。透過座談會及諮詢會議，團隊提供意見與交流，強調地方本位，使每項在地深耕的事業在兼顧大學人才培育前提下，能夠貼合在地需求，實現效益最大化。
在人才培育方面，計畫團隊舉辦在地教師研習，推動食漁教育納入校本課程，弘揚水產食品安全教育理念。在產業創新方面，主要以水產副產物為主，協助地方開發新穎產品，創造產業經濟效益。團隊同時進行場域參訪及課程培力等活動，促使師生與場域共同學習與成長，從不同視角投入地方議題，並協力解決問題，進一步強化大學與地方的合作，實現共榮。
除此之外，本計畫積極參與各項交流活動，並分享計畫執行經驗至其他學校及公私單位。同時，參與USR計畫共培活動，發揮深耕型計畫的責任與作用，以達到USR擴散的效益。此外，透過串聯外部資源，計畫團隊強化與地方縣市政府的合作關係，將培訓的種子師資人才引入各級學校，實踐教學目標。

主要成果及亮點（500字以內）

在地永續：本團隊開始轉為助攻角色，由地方自主統籌「尻海風」活動，計畫團隊則提供活動優化建議，加值地方慶典，在提供學生學習機會的同時，亦亦致力於深化並展現漁村獨有的文化印象。包括在地基地改造，將環境議題融入我們的實際行動，進一步展現漁村未來的多元價值。
人才培育：本年度開設26堂課程有超過1,000名學生修讀，累積影響國教端師生及場域夥伴約1,500人次，另輔導在地養殖青年申請青年洄游計畫、南安國小申請海保署海洋保育計畫，透過外部資源的投入，讓在地的合作夥伴們能培養協同合作的能力，也確保在地永續及人才培育的長期運作機制能落地實踐。產業創新：本團隊致力於推動減碳趨勢，透過辦理碳排查相關課程，引導團隊教師深入了解此議題並將其應用於後續在地特色水產品開發，致力於利用石斑魚的副產物和機能性成分，研發新穎性產品，例如蔬菜精力湯、點心麵以及番茄口味魚餅酥酥，並開發相關衍生產品，為場域帶來實質的經濟效益。未來，我們將持續深化並擴散此產業創新模式，期能更全面地促進場域的永續發展。

成效評估機制實質進度及落實成效（500字以內）

本計畫評估方面，特別注重實際成效的確認。透過社會影響力評估模式的運用，能夠更全面地了解計畫對社會和地方產生的影響。在每個階段，積極與地方利害關係人對話，以確保計畫目標與地方需求保持一致。此外，亦針對人才培育建立多元成效分析機制，為確保其問卷調查過程符合學術倫理之要求，於本年度12月通過學術倫理審查後，方啟動問卷專家諮詢階段，以確立問卷構面、指標及其細部題項，並擬於新學期進行問卷之預試。
針對執行期間的管考與成果評估，團隊設計了KPI指標，以清晰且具體的方式衡量每個階段的達成情況。這不僅能讓計畫辦公室追蹤進度，更能在需要時進行及時的調整，確保計畫能夠順利實現預定目標。
在團隊內部，持續進行任務型工作會議，強調開放性的溝通和合作，確保每位成員都能深入參與計畫的推動。透過回饋問卷的形式，主動收集各方面的建議和意見，這不僅提供計畫改進的方向，也展現計畫對於參與者意見的重視。最後，團隊評估成果整合至計畫的活動紀錄表中，此數據不僅是計畫的一部分，更是未來改進和優化的參考依據。透過這樣的評估機制，期望能夠達到計畫的長遠效益，並持續為地方社群帶來實質的永續發展。

團隊成員聘用情形、專長與任務安排之妥適性及分工情形 
　　計畫團隊專職人員資訊詳如表1，主要組成為國立高雄科技大學(以下簡稱高科大)教師，由高科大海洋事務與產業管理碩士班(以下簡稱海管所)專任教師擔任計畫主持人，設立計畫執行辦公室，負責控管計畫執行、每月辦理教師社群會議、經費核銷等。

* 相關課程（學程）等內涵與計畫目標契合度 
　　參與計畫的教師在原有課程中與在地議題產生連結，初期先導入實地參訪，後期再逐漸擴展至解決當地議題。學生在初步了解場域並學習基本專業能力後，發現地方問題，鼓勵學生針對當地議題進行創新思考，培養解決問題的能力。以食品分析與實驗為例，我們與當地合作社和漁場合作，協助學生參與新產品檢測項目。這不僅培訓學生的食品分析檢驗能力，還將這些技能應用於實習課程，為他們未來就業鋪平道路。這樣的教學模式旨在將理論知識與實際應用相結合，使學生在解決現實問題的同時獲得豐富的實踐經驗。 
　　打破傳統的學校教室框架，我們引領學生進入實際場域，建立起場域教室的全新概念。我們的課程設計將場域與課程緊密結合，實現逐步擴散的目標。整個團隊致力於將計畫目標轉化為實際行動，確保學生參與場域的執行率達到100%。簡而言之，凡是與計畫相關的課程，都將充分運用課程專業知識，實際應用於場域，以確保理論與實務之間能夠緊密連結。 

* 教學模式創新性與跨領域教學成果 
　　教師團隊在課程中引入富有深度的議題，並透過創新的教學模式不斷深化成果。在這種模式的引領下，我們運用跨領域思維，引導學生發展多元化的面向和技能。具體成果如，團隊於112年榮獲食創獎-大學組的 USR 永續創新獎（新的道路：實現永安石斑魚副產物的永續價值），「魚餅酥酥」被授予比利時ITQI風味絕佳獎章，以及「大學對溺水的社會責任」在第三屆 TSAA 台灣永續行動獎社會共融類之 SDGs4教育品質議題獲得銅獎。在今年度(113年)榮獲遠見 USR 大學社會責任獎 產業共創組楷模獎，以及第四屆 TSAA 台灣永續行動獎社會共融類之 SDGs17 全球夥伴議題獲得銀獎。 
　　上述成果發想皆源自教師教學成果的延伸，顯示計畫教學模式的創新性，以及在跨領域學習中取得的成就。透過將實際課程與現實世界的挑戰相結合，不僅豐富學生的知識領域，亦培養跨足不同領域的能力。這樣的教學模式不僅激發學生的創造力，也為他們未來的職涯發展打下了堅實基礎。 

* 教師社群運作及教學工作坊辦理成果 
　　在校內「教師專業社群」計畫支持下，連續數年榮獲教師專業社群獎勵，於每月定期辦理教師社群會議促進計畫團隊溝通，帶領計畫團隊成員檢視計畫執行情況，討論及滾動式調整計畫推動方向。同時，為深化各目標執行效益，邀請專業講師透過辦理教師培力工作坊、講座等活動加值團隊的知能與技能，並且在本年度團隊特別重視「社會影響力評估(Social Impact Assessment，簡稱 SIA)」導入成效評估機制，展開了一系列社會影響力之培力與討論會議。

　　於開放性水域安全教育主軸，與大葉大學、中華民國水中運動協會 (在地組織)合作籌劃辦理開放性水域安全種子師資培訓，安排培訓之種子師資，將所學實踐於國教端入校宣導開放性水域安全教育。過程中除強化與高雄市政府教育局合作關係外，更能夠將開放性水域安全教育加以推廣普及至學校與社會大眾。 
　　執行 USR計畫過程中，總會遇到些困難與挫折，將這些透過行前會議轉化為討論議題，例如111年時曾辦理SIG交流時以「尬聊」形式，希望與會的跨校夥伴能以「暢所欲言」模式交流豐富的執行經驗，第一次結束後獲得迴響，打鐵趁熱的辦理第二場次的尬聊 SIG，於此同時更促成本校與正修科技大學簽訂校際 MOU 及透過共識營訂定聯盟機制。 
　　本期在112年度12月也持續辦理了兩場「尬聊」SIG 交流，主題分別為「Ｍind the USR gap：校管和計畫之間的距離」與「經營 USR 小宇宙的100個方法：如何引導學生投入」，由於活動不斷收到正向回饋，故本年度(113年度)在11月辦理一場 SIG 活動，延續「尬聊」的精神，針對「大學與地方，誰幫誰？」以及「大學在青年留鄉可扮演的角色？」兩個議舉辦 SIG 交流活動。具體成果重點如下： 
　　綜合大學端與場域端針對「議題一：大學與地方，誰幫誰？」進行交流之結果，發現大學端進入場域，對在地而言是一種擾動，且大學端與場域端實屬互助關係，但場域端所提出的需求，不一定符合大學端的需求，此外，亦針對此議題衍伸「大學端提出計畫結束後應如何退場？」以及「地方是否可獨自思考」的疑問。針對「議題二：大學在青年留鄉可扮演的角色？」進行交流後，發現留鄉青年大多不僅是孤軍奮戰，同時也需面臨親朋好友質疑的聲浪，經本次交流證實 USR可讓學生發揮所長幫助場域的地方，但場域端亦反應每回大學端將引領學生至場域交流，都是全新的面貌，已出現延續性的問題，爾後可延伸本次交流所提出議題進行深入探討。

## 七、 其它重點工作推動進度
　　本年度於11月辦理一場次 SIG，過去參與 USR 交流活動發現大部份都相對較正式與嚴肅，在眾多人員參與情況下針對議題討論較難發揮更深入的討論與交流。因此我們思考假如能創造一個輕鬆不拘謹的環境，讓參與 USR的伙伴們，無論是老師、助理或學生，能暢所欲言不受束縛，也許有可能交織出有趣的事情，同時能有助於 USR間的深入交流、聚焦、推動與落地。2022年首次推出《尬聊 USR》獲得參與者的認同，今年的尬聊將聚焦在「如何引導學生投入 USR」以及「校管和計畫之間的距離」兩大議題。 

* 「大學與地方，誰幫誰？」：USR 的推動需要「大學」與「地方」共同參與。大學以地方為實踐場域，幫助地方解決在地議題，一起培育人才並促進地方發展。然而在共同實踐的過程裡，更多的是大學為地方注入一股活水？還是地方為大學提供更多人才培育的實踐資源？本場次通過大學與地方代表的對談，讓與會者一起思考大學與地方在 USR 中不即不離的幽微關係。 

* 「大學在青年留鄉可扮演的角色」：教育部2018年啟動USR計畫，鼓勵大學積極參與地方的發展，如今 USR 推行已邁入第七年，大學已是在地長期發展的重要夥伴。在地方「青年留鄉」的議題上，大學端的作為，是否有效觸發並深化青年對在地的興趣及認同，進而投入在地發展？本場次邀請實際參與 USR 的夥伴作夥來尬聊心聲。

* 計畫預期成果達成情形及衍生效益 
　　本年度計畫的著眼點主要在於石斑魚副產物再利用，以蔬菜精力湯、點心麵以及番茄口味魚餅酥酥的創新食品，並由蔬菜精力湯衍生蜆精力湯。透過跨專業合作，結合場域資源和師生的共同努力，我們致力於運用石斑魚副產物和機能性成分，引導學生參與產品開發和構思的過程，使其在實踐中不僅學習理論，更能夠轉化為實際的實用技能。 
　　同時，我們特別注重將計畫與聯合國永續發展目標(SDGs)相關聯，特別關注減少飢餓(SDG 2)和促進負責任的消費與生產(SDG 12)等議題。透過學生的參與，計畫以實際可行的解決方案回應 SDGs 的挑戰，期望所開發的產品不僅能滿足市場需求，更能夠成為當地永續發展的一部分，深化其在社區中的影響。 
　　今年度執行的重點在於深化計畫成果的影響，不僅在計畫執行期間，更強調將這些成果融入當地場域。這不僅有望提升和激發當地經濟的發展，使計畫在投入期間，場域不僅發生改變，更能實現當地社區的永續發展目標。 
　　此外，本年度計畫延續地方創生擴散效益與彌陀區南安國小合作共同打造專屬南安國小的食漁教育校本課程。本次合作模式跳脫傳統的活動型式的推廣教育，係透過培訓國小教師成為食漁教育的種子師資，讓南安國小的教師成為校園內推動食漁教育的執行者，並結合在地的虱目魚養殖文化、隬陀漁港的捕撈漁業和海岸光廊的海洋觀光資源等，形成南安國小特有的食漁課程。 
　　本年度也針對水產品食用安全及營養等課程，強化國小教師對食漁教育的認識。同時，由於過去兩年的合作經驗，本團隊也協助南安國小參與更多地方(高雄巿政府海洋局)的海洋體驗活動(獨本舟體驗)及申請中央單位(海洋委員會海洋保育署)的海洋保育在地守護計畫(海洋公民保育推廣活動暨海岸光廊水下生態調查)，強化南安國小的師生同仁與地方議題的連結，並成為守護地方海洋環境的力量。 
　　今年度與梓官漁會進行跨域合作，辦理食農/漁教育推廣活動，並以肌少症為主題，結合師生的營養專業與設計力，研發食漁增肌教案「拼石斑」，推廣營養與食漁教育的觀念。同時，協助梓官區同安社區規劃定期運動課程，協助長輩建立運動的基本概念，以運動集點換好禮的方式來鼓勵長輩體驗運動，進而養成週週規律運動習慣。亦與大葉大學教師進行跨校合作，辦理好好生活系列工坊，建立學生營養觀念，並結合色彩搭配與構圖技巧，培養拍攝技巧與美感。

　　參考英國的國際社會價值協會(Social Value International, SVI)所提出之社會投資報酬率(Social Return on Investment, SROI)指南、影響最大化之四階段(圖3)以及十大影響問題(表15)，進行社會影響力的概念導入本 USR 實踐計畫的討論會議，並針對每次的討論狀況調整將社會影響力的概念導入本計畫的方法，使其適用於本計畫中。本計畫研發之社會影響力概念導入 USR 實踐計畫方法如下：首先透過釐清 KPI、行動方案及其預期效益確定範圍，其次則是藉由辨識利害關係人的環節確認其 KPI 及行動方案之目標對象，再次則將 KPI、行動方案及其預期效益對接本校中程發展目標及其策略，最後再展開成果事件鍊說明以及指標盤點，若於各階段的討論過程中有較不明確的部分，則汲取團隊教師的反饋後滾動式調整 KPI 或預期效益，並再次確認各個階段的資訊是否需進行調整(圖4)，以確認本計畫執行活動所帶來之影響力。 
　　本計畫開發多元成效分析機制，擬於正式課程及非正式課程(如工作坊)中，發放前測問卷了解學生的先備知識，並於課程中為學生建立 USR 基本概念，帶領學生赴場域進行課程參訪或在地實踐後，發放後測問卷，再針對前後測問卷分析結果調整本案人才培力之策略，如圖5。

# 肆、 計畫執行與原規劃內容及預定成果之差異分析及因應措施
　　本年度已建構多元成效分析機制，但尚未實際進行施測，使用 SROI 進行社會影響力評估，針對人才培力評估時發覺其成果難以透過貨幣化呈現，而轉以建立多元成效分析機制進行評估，根據社會情緒學習的核心構面，建構適用於 USR的構面、指標及其細部題項的問卷。由於當前國內外之相關研究對象，著眼於學齡前至國中階段的學生，且多應用於基礎教育課程，鮮少有用於 USR的案例，因此投入多數時間於討論。同時，亦為確保實施多元成效分析機制的問卷調查過程符合學術倫理規範，經「人類研究倫理審查委員會」進行反復查核，本計畫方於
113年度12月通過相關審查，並於本年度12月中啟動問卷專家諮詢階段，以確立其構面、指標及其細部題項，亦因本年度難以配合學期時間發放學習成效之問卷，改於新學期進行問卷之預試。
