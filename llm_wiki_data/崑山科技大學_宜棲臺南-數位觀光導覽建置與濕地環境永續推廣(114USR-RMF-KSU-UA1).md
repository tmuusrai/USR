# 宜棲臺南 數位觀光導覽建置與濕地環境永續推廣

| 欄位 | 內容 |
|------|------|
| 執行學校 | 崑山科技大學 |
| 計畫類型 | 萌芽型 |
| SDG 關聯 | [[SDG4]]、[[SDG6]]、[[SDG15]] |
| 計畫議題 | [[環境永續]] |
| 實踐場域 | [[臺南市]]、[[安南區]]、[[七股區]]、[[北門區]] |

## 執行目標

本計畫旨在運用[[數位觀光]]導覽與遊程規劃，推廣[[臺南市]]濕地[[環境永續]]觀念，提升旅遊品質並增加遊客數量。同時，培育具備[[環境永續]]推廣能力的[[數位觀光]]人才，並活化場域閒置空間。

## 主要活動與成果

-   前期HUB計畫（綠色生活）榮獲2024TCSA大學永續單項氣候領袖獎。
-   延續並擴大「[[環境永續]]主題之AI幼兒繪本創作研習營與競賽」及「[[環境永續]]主題之全國旅遊文學明信片創作大賽」。
    -   產出10組以上[[環境永續]]主題AI創作圖片與繪本。
    -   競賽超過200組參加，產出60組以上得獎旅遊明信片與AI幼兒繪本。
-   辦理「場域[[環境永續]]遊程規劃競賽」，產出10組以上遊程設計，參與人數約100人。
-   建置[[北門遊客中心]]、[[七股鹽山]]、[[四草大眾廟]]等場域的[[數位觀光]]導覽系統（含VR互動小遊戲），並持續更新。
-   舉辦7場針對高中職與大學生的[[數位觀光]]導覽活動，參與人數約200人。
-   透過[[數位觀光]]導覽系統線上認識場域，觸及人數約1000人。
-   開設4門PBL（[[問題導向學習]]）課程，提升學生[[環境永續]]認知，參與人數約100人。
-   辦理環境教育場域課程認證研習營，參與人數約100人。
-   結合場域提供[[環境永續]]遊程，推廣[[在地文化]]，促進[[地方創生]]，參與人數約100人。
-   建置「宜棲[[臺南]]環境永續推廣基地」，提供特色空間推廣成果，預計接觸人數約500人。
-   規劃「[[數位旅遊]]經營管理跨領域學分學程課程」，包含電子商務與民生應用程式設計、導遊領隊實務、遊程規劃與設計、數位智慧觀光、社群行銷、導覽解說實務等。
-   成效評估顯示，參與活動能顯著提升「關注[[環境永續]]相關議題」、「參加[[環境永續]]的相關活動」、「日常生活中支持[[環境永續]]觀念」及「日常生活中推廣[[環境永續]]觀念」的同意程度。
-   社會投資報酬率（SROI）評估：
    -   濕地[[環境永續]]推廣與人才培育：SROI 1.73。
    -   場域閒置空間再利用：SROI 0.88。
    -   增加場域遊客數量：SROI 0.99。

## 核心概念與連結

[[臺南市]] — 計畫主要實踐場域，涵蓋安南、七股、北門區。
[[安南區]] — [[臺南市]]的行政區之一，計畫實踐場域包含[[四草大眾廟]]、[[四草綠色隧道]]。
[[七股區]] — [[臺南市]]的行政區之一，計畫實踐場域包含[[七股鹽山]]、[[七股遊客中心]]。
[[北門區]] — [[臺南市]]的行政區之一，計畫實踐場域包含[[北門遊客中心]]、[[洗滌鹽觀光工場]]。
[[四草大眾廟]] — [[臺南市]][[安南區]]的計畫實踐場域之一，建置[[數位觀光]]導覽系統。
[[四草綠色隧道]] — [[臺南市]][[安南區]]的計畫實踐場域之一，推廣濕地[[環境永續]]觀念。
[[七股鹽山]] — [[臺南市]][[七股區]]的計畫實踐場域之一，建置[[數位觀光]]導覽系統。
[[七股遊客中心]] — [[臺南市]][[七股區]]的計畫實踐場域之一，推廣濕地[[環境永續]]觀念。
[[北門遊客中心]] — [[臺南市]][[北門區]]的計畫實踐場域之一，建置[[數位觀光]]導覽系統並開發VR互動小遊戲。
[[洗滌鹽觀光工場]] — [[臺南市]][[北門區]]的計畫實踐場域之一，推廣濕地[[環境永續]]觀念。
[[環境永續]] — 本計畫的核心議題，透過數位導覽、遊程設計及教育活動推廣濕地生態保育。
[[數位觀光]] — 本計畫採用的關鍵方法，透過360VR導覽系統、短影音推廣等方式提升旅遊體驗與推廣[[環境永續]]。
[[SDG4]] — 優質教育，透過幼兒繪本創作、PBL課程及學分學程培育[[環境永續]]與[[數位觀光]]人才。
[[SDG6]] — 乾淨用水及衛生，與濕地生態保育及[[環境永續]]推廣相關。
[[SDG15]] — 陸地生物，與濕地生態保育及[[環境永續]]推廣相關。
[[在地文化]] — 結合場域遊程推廣，促進[[地方創生]]。
[[地方創生]] — 透過結合場域遊程推廣[[在地文化]]，增加遊客數量，活化地方發展。
[[問題導向學習]] — 課程教學方法，用於提升學生[[環境永續]]認知。
[[數位旅遊]] — 規劃相關學分學程，培育[[數位觀光]]經營管理人才。
