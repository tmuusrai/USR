# 時光共融：高齡長健與跨世代共學計畫

| 欄位 | 內容 |
|------|------|
| 執行學校 | 國立臺灣師範大學 |
| 計畫類型 | 大學特色類深耕型 |
| SDG 關聯 | [[SDG3]]、[[SDG4]]、[[SDG8]] |
| 計畫議題 | [[高齡照護]]、[[世代共融]]、[[人才培育]]、[[創齡方案]] |
| 實踐場域 | [[臺北市]] ([[大安區]]、[[士林區]])、[[宜蘭縣]] ([[五結鄉]]) |

## 執行目標

本計畫在前三期基礎上深化，以[[創齡方案]]為核心，旨在強化既有場域的[[高齡人才培育]]，並將服務對象擴展至[[中高齡族群]]。透過[[跨世代共學]]與[[世代交流]]，建立[[高齡友善文化]]，促進社會[[世代共融]]與[[永續發展]]。

## 主要活動與成果

-   **深化社區跨域人才培育**：
    -   開設「[[社區高齡者服務人才培力學分學程]]」，共計12系所、51位教師、59門課程，修課人數達2,615人次，82人取得學程資格。
    -   學程學生設計方案投入社區，服務超過3,500人次[[高齡者]]。
-   **建構高齡健康管理模式**：
    -   提供[[智慧檢測]]服務，強化[[高齡者自主健康管理]]，結合健康量測提供[[數位諮詢]]及防詐宣導。
    -   辦理28場大型[[健康促進]]活動，超過7,000人次[[社區高齡者]]參與。
    -   [[銀齡樂活據點]]開設4期、18門高齡健康身心樂活課程，共240場，服務[[社區高齡者]]7,030人次、學生320人次。
-   **塑造創齡正向高齡文化**：
    -   透過超過30場[[創齡方案]]及[[生命敘說]]，提升[[高齡者美學教育]]與[[社區參與]]。
    -   以[[青銀共學]]模式增進[[高齡者]]與學生間之[[世代交流]]，建立相互理解、包容、正向的[[高齡文化]]。
    -   透過[[老老學習]]模式，辦理[[宜蘭]]場域[[人才共備方案]]，培養[[高齡者]]自信，帶動[[社區樂齡增能]]風氣。
-   **發展中高齡者教育系統**：
    -   辦理14場[[前瞻因應講座]]，共257位[[中高齡者]]、18位教師、30位學生參與。
    -   進行[[中高齡照顧]]現況問卷調查，瞭解服務場域提供[[中高齡支持者]]知能提升及資源支持網絡。
    -   參考調查結果辦理[[喘息服務]]及[[世代共融方案]]，建構符合[[跨世代需求]]之教育方案。
-   **亮點活動 - 生命敘說方案**：
    -   辦理「實．光 The Light of Our Field 社會實踐映像節」，以照片及文字敘事，述說不同世代間的[[生命故事]]，展出超過100件作品，吸引超過1,300人次觀賞。
    -   強調[[青銀共學]]、[[共創]]、[[共生]]、[[共融]]，融合[[社會實踐]]及[[社區實地參與]]，透過[[跨世代多元視角]]，用影像重新詮釋並理解不同世代對周遭人事物的感受。
-   **亮點活動 - 創齡方案**：
    -   「聲影流轉：[[跨世代AI聲景計畫]]成果展」：與[[臺北市政府資訊局]]合作，培訓長者運用[[數位工具]]，展出吸引304人次觀展。
    -   高齡夢想市暨全齡運動會：將辦理第8屆[[高齡夢想市集]]活動暨第1屆[[全齡運動會]]，主題為「[[高齡共學]] [[青銀共學]] [[社區共好]]」。預計50個攤位，邀請[[高齡者]]、[[中高齡者]]及年輕世代組隊挑戰趣味競賽，促進[[世代交流]]與[[共融]]，預估3,000人參與。

## 核心概念與連結

[[SDG3]] — 透過[[高齡照護]]、[[健康促進]]及[[智慧檢測]]服務，提升[[高齡者]]與[[中高齡族群]]的健康與福祉。
[[SDG4]] — 透過[[社區高齡者服務人才培力學分學程]]、[[跨世代共學]]及[[老老學習]]，提供優質且具包容性的教育機會。
[[SDG8]] — 透過[[人才培育]]及[[中高齡者教育系統]]的發展，促進[[高齡者]]與[[中高齡族群]]的合宜工作與經濟成長潛力。
[[高齡照護]] — 本計畫核心議題，旨在建構[[高齡者長健全方位系統]]，提供全方位的健康與生活支持。
[[世代共融]] — 本計畫核心目標，透過[[青銀共學]]、[[世代交流]]及[[跨世代共學]]活動，促進不同世代間的理解與合作。
[[人才培育]] — 透過「[[社區高齡者服務人才培力學分學程]]」及[[人才共備方案]]，培養投入[[高齡照護]]與[[社會實踐]]的專業人才。
[[創齡方案]] — 本計畫主軸，透過藝術、文化及科技活動，提升[[高齡者美學教育]]與[[社區參與]]，塑造正向[[高齡文化]]。
[[臺北市]] — 本計畫主要實踐場域之一，包含[[大安區]]與[[士林區]]的多個社區據點。
[[宜蘭縣]] — 本計畫實踐場域之一，特別在[[五結鄉]]推動[[人才共備方案]]與[[社區樂齡增能]]。
[[銀齡樂活據點]] — 位於[[臺北市大安區]]的固定實踐場域，提供[[高齡者]]健康身心樂活課程與活動。
[[心田心理諮商所]] — 位於[[臺北市大安區]]的合作場域。
[[臺北市大安區錦町社區發展協會]] — 位於[[臺北市大安區]]的合作場域，服務錦安里居民。
[[臺北市長立健康樂活協會]] — 位於[[臺北市大安區]]的合作場域，服務龍陣里居民。
[[龍泉里辦公室]] — 位於[[臺北市大安區]]的合作場域。
[[揚生慈善基金會]] — 位於[[臺北市大安區]]的合作機構。
[[銀髮方舟社會企業]] — 位於[[臺北市士林區]]的合作機構，提供居家長照服務。
[[五結鄉公所活動中心]] — 位於[[宜蘭縣五結鄉]]的合作場域，推動[[老老學習]]與[[人才共備方案]]。
[[社區高齡者服務人才培力學分學程]] — 國立臺灣師範大學開設的學程，旨在培育[[高齡照護]]領域的專業人才。
[[高齡者]] — 本計畫主要服務對象，透過多樣化方案促進其健康、學習與社會參與。
[[智慧檢測]] — 應用科技手段，提供[[高齡者自主健康管理]]服務，強化健康監測。
[[高齡者自主健康管理]] — 透過[[智慧檢測]]與[[數位諮詢]]，賦能[[高齡者]]主動管理自身健康。
[[數位諮詢]] — 結合健康量測數據，提供[[高齡者]]個人化的健康建議與防詐宣導。
[[健康促進]] — 透過舉辦大型活動與課程，鼓勵[[社區高齡者]]參與，提升整體健康水平。
[[社區高齡者]] — 本計畫在各實踐場域服務的在地[[高齡者]]群體。
[[高齡者美學教育]] — 透過[[創齡方案]]與[[生命敘說]]，提升[[高齡者]]的藝術鑑賞與創作能力。
[[社區參與]] — 鼓勵[[高齡者]]積極參與社區活動，增強社會連結與歸屬感。
[[青銀共學]] — 一種[[世代交流]]模式，鼓勵年輕世代與[[高齡者]]共同學習、分享經驗。
[[世代交流]] — 促進不同年齡層之間的互動與理解，打破世代隔閡。
[[高齡文化]] — 透過[[創齡方案]]與[[青銀共學]]，建立尊重、包容、正向的[[高齡]]社會氛圍。
[[老老學習]] — 鼓勵[[高齡者]]之間相互學習、分享知識與技能，提升自信與能力。
[[人才共備方案]] — 在[[宜蘭]]場域推動，培養[[高齡者]]成為在地[[樂齡增能]]的帶領者。
[[社區樂齡增能]] — 透過[[老老學習]]與[[人才共備方案]]，提升社區[[高齡者]]的學習與生活能力。
[[中高齡族群]] — 本計畫擴展的服務對象，旨在滿足其[[前瞻因應]]老化及[[中高齡照顧]]的需求。
[[前瞻因應講座]] — 針對[[中高齡族群]]舉辦，提供應對未來老化挑戰的知識與策略。
[[中高齡照顧]] — 關注[[中高齡者]]及其[[中高齡支持者]]的照顧需求與資源網絡。
[[中高齡支持者]] — 負責照顧[[中高齡者]]的家庭成員或社區人士，本計畫提供其知能提升與資源支持。
[[喘息服務]] — 針對[[中高齡照顧]]者提供短暫休息的服務，減輕其照顧壓力。
[[世代共融方案]] — 旨在建構符合[[跨世代需求]]的教育與活動，促進不同世代的共同參與。
[[跨世代需求]] — 考量不同年齡層的學習、生活與社會參與需求，設計多元方案。
[[生命敘說]] — 透過分享[[生命故事]]，促進[[高齡者]]自我認同與[[世代交流]]。
[[生命故事]] — [[高齡者]]個人經歷的口述或書寫，是[[生命敘說]]的核心內容。
[[共創]] — 鼓勵不同世代共同參與創作與活動，產生新的價值與連結。
[[共生]] — 強調不同世代在社會中相互依存、共同發展的關係。
[[共融]] — 追求社會各群體（特別是不同世代）的平等參與與和諧共處。
[[社會實踐]] — 國立臺灣師範大學師生將學術知識應用於解決社會問題的行動。
[[社區實地參與]] — 師生深入社區場域，與居民共同合作，推動計畫活動。
[[跨世代多元視角]] — 鼓勵不同世代從各自的經驗與觀點出發，理解與詮釋世界。
[[跨世代AI聲景計畫]] — 結合[[數位工具]]與[[創齡方案]]，讓[[高齡者]]參與AI聲景創作。
[[臺北市政府資訊局]] — 本計畫在[[跨世代AI聲景計畫]]中的合作夥伴。
[[數位工具]] — 協助[[高齡者]]學習與創作，提升[[數位包容]]。
[[高齡夢想市集]] — 結合[[高齡共學]]與[[青銀共學]]的市集活動，展示[[高齡者]]的學習成果與活力。
[[全齡運動會]] — 邀請[[高齡者]]、[[中高齡者]]及年輕世代共同參與的趣味運動會，促進[[世代交流]]。
[[高齡共學]] — 鼓勵[[高齡者]]持續學習，並與同儕或年輕世代共同成長。
[[社區共好]] — 透過本計畫的各項活動，促進社區居民的共同福祉與和諧發展。
