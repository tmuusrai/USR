# 否極泰來–原住民文化資產保存人才培育與在地實踐計畫

| 欄位 | 內容 |
|------|------|
| 執行學校 | 正修科技大學 |
| 計畫類型 | 大學特色類萌芽型 |
| SDG 關聯 | [[SDG8]]、[[SDG9]]、[[SDG11]] |
| 計畫議題 | [[文化永續]]、[[人才培育]]、[[地方創生]] |
| 實踐場域 | [[屏東縣]]、[[泰武鄉]]、[[來義鄉]] |

## 執行目標

本計畫旨在透過[[原住民文化資產]]的保存與修復，培育在地人才，並結合教育推廣與社區參與，深化[[文化永續]]的在地實踐。目標是建立社群對文化資產修復的正確認知與價值理解，促進[[跨世代知識傳承]]，並與[[永續發展]]目標接軌。

## 主要活動與成果

-   **在地文保與人才培育**：
    -   辦理「文保講堂」及「微修復實作課程」，內容涵蓋木質、紙質、服飾等文物保存與修復技術，累計參與人次達821人。
    -   舉辦「原民文史講座」與大學端講座，提升[[在地知識]]與文化認同。
    -   導入[[翻轉教室]]與[[移地教學]]模式，師生深入部落進行文物檢視與修復，促進[[社區陪伴]]。
-   **跨領域教育推廣**：
    -   將[[社會責任與場域實踐]]及[[SDGs永續發展]]等概念融入課程，吸引跨十餘系所學生參與。
    -   投入社會實踐課程學生達490人次，遠超原定目標。
-   **特色加值與地方創生**：
    -   推動[[在地文創商品開發]]，協助部落居民萃取文化元素進行設計實作。
    -   導入[[人工智慧]]技術於圖騰創作與商品包裝設計，提升文化商品的市場辨識度與深度。
-   **合作網絡建立**：
    -   與[[屏東縣泰武鄉公所]]、[[來義鄉原住民文物館]]、[[原住民族文化發展中心]]、[[原住民族博物館籌備處]]建立穩定合作關係。
    -   由正修科技大學視覺傳達設計系、文物修護研究中心、文創設計與藝術保存碩士班及科技藝術發展處組成跨領域執行團隊。

## 核心概念與連結

[[SDG8]] — 促進包容且永續的經濟成長，提供所有人的合宜工作，並提升生產力。本計畫透過文創商品開發與人才培育，為原住民社區創造經濟機會。
[[SDG9]] — 建立具韌性的基礎建設，促進包容且永續的工業化，並推動創新。計畫導入[[人工智慧]]於文創設計，推動文化產業創新。
[[SDG11]] — 建立具包容、安全、韌性及永續的城市與人類住居。透過[[原住民文化資產]]保存，強化在地社區的文化韌性與永續發展。
[[文化永續]] — 本計畫的核心目標，透過教育、修復與推廣，確保原住民文化資產得以傳承與發展。
[[人才培育]] — 計畫透過微修復課程與文史講座，培養在地居民與學生具備文化資產保存的知識與技能。
[[地方創生]] — 藉由[[在地文創商品開發]]，將原住民文化元素轉化為具市場潛力的產品，帶動地方經濟發展。
[[屏東縣]] — 本計畫的主要實踐場域所在縣市。
[[泰武鄉]] — [[屏東縣]]內本計畫的重點實踐鄉鎮，與[[泰武鄉公所]]合作。
[[來義鄉]] — [[屏東縣]]內本計畫的重點實踐鄉鎮，與[[來義鄉原住民文物館]]合作。
[[泰武鄉公所]] — 本計畫在[[泰武鄉]]的重要合作夥伴。
[[來義鄉原住民文物館]] — 本計畫在[[來義鄉]]的重要合作夥伴，提供文物修復與展示場域。
[[原住民族文化發展中心]] — 本計畫的合作機構，有助於資源整合與政策連結。
[[原住民族博物館籌備處]] — 本計畫的合作機構，擴大文化保存的社會影響力。
[[微修復課程]] — 本計畫採用的關鍵方法之一，透過實作教學提升學員的文物修復能力。
[[翻轉教室]] — 創新的教學模式，將學習主導權交給學生，鼓勵主動參與。
[[移地教學]] — 讓學生走出校園，深入部落場域，進行實地學習與文化觀察。
[[在地文創商品開發]] — 結合原住民文化元素與設計，創造具有市場潛力的文化商品，促進[[地方創生]]。
[[人工智慧]] — 應用於圖騰創作與商品包裝設計，提升文化商品的創新與市場競爭力。
[[原住民文化資產]] — 本計畫的核心關注對象，包括木質、紙質、服飾等文物。
[[在地知識]] — 透過文史講座與部落互動，挖掘與傳承原住民社群的傳統知識與智慧。
[[永續發展]] — 本計畫與聯合國SDGs接軌，旨在確保文化資產的長期保存與社區的永續發展。
[[大學社會責任]] — 本計畫是正修科技大學實踐其社會責任的具體行動，透過學術專業服務地方。
[[跨世代知識傳承]] — 透過教育與實踐活動，促進原住民文化知識與技藝在不同世代間的傳遞。
[[社區陪伴]] — 師生深入部落，與居民共同參與文化保存行動，建立長期合作關係。
