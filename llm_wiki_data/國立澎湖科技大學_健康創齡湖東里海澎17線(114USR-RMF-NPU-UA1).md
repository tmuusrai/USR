# 健康創齡湖東里海澎17線

| 欄位 | 內容 |
|------|------|
| 執行學校 | 國立澎湖科技大學 |
| 計畫類型 | 萌芽型 |
| SDG 關聯 | [[SDG3]]、[[SDG11]] |
| 計畫議題 | [[高齡照護]]、[[地方創生]]、[[食農教育]] |
| 實踐場域 | [[澎湖縣]]、[[湖西鄉]]、[[湖東社區]] |

## 執行目標

本計畫以[[高齡預防醫學]]為架構，推動[[活躍老化社區]]，強調高齡者的獨立、參與、自我實現與尊嚴。透過[[適口健康飲食]]與[[身心健全活化]]兩面向，優化[[青銀共創]]模式，延緩身體機能老化，串聯社區與[[洄游青年]]，打造具目標性與生產性的高齡生活樣態，實現高齡者生命價值與社會貢獻。

## 主要活動與成果

-   整合前期USRHub計畫成果，聚焦[[高齡樂食]]、[[社區高齡健康]]及[[記憶與文化重現]]。
-   針對高齡族群咀嚼吞嚥機能衰退問題，推動[[高齡適口性飲食]]的創新實踐。
-   導入[[IDDSI食物質地分級系統]]，培訓食品與餐旅專業學生從實務角度應用該標準。
-   與[[高雄市小港醫院]]合作，培訓學生掌握高齡咀嚼吞嚥評估技巧，並進入[[湖東社區]]設計製作符合高齡營養需求的[[在地食材]]菜單。
-   推動[[青銀共學]]模式，編制高齡共餐衛生安全管理手冊，強化社區志工衛教能力。
-   建立高齡咀嚼吞嚥評估訓練模式，發展多元即時適口性飲食，並建構[[高齡預防醫學]]飲食指引。
-   開設「高齡社會與創新實踐」微學分課程，整合食品科學、餐飲烹調、醫療照護、行銷管理與人文教育等跨域知識。
-   結合「銀髮健康俱樂部」及地方專業團體，共同規劃設計高齡體適能活動。
-   運用[[澎湖]]當令食材設計24節氣適口菜單，並編製「健康創齡手冊」。
-   結合高齡者文史記憶採集與[[文化再現]]，促進世代交流與[[社區參與]]。
-   透過「[[銀青共培]]」模式，培育學生、[[洄游青年]]與社區志工多元專才，促進[[文化傳承]]、青年返鄉與[[地方經濟活化]]。
-   將計畫意象擴展至在地高中職，運用高中職師資在地議題工作坊模式，建置大學與高中職端在地議題的連結。

## 核心概念與連結

[[SDG3]] — 良好健康與福祉：本計畫透過高齡適口性飲食、體適能活動及預防醫學指引，直接促進高齡族群的身體與心理健康。
[[SDG11]] — 永續城市及社區：計畫以[[湖東社區]]為實踐場域，透過[[地方創生]]、[[社區陪伴]]及[[青銀共創]]，打造高齡友善且具韌性的永續社區。
[[澎湖縣]] — 計畫的地理實踐範圍，聚焦於[[澎湖]]的在地資源與高齡議題。
[[湖西鄉]] — [[澎湖縣]]內具體實踐的鄉鎮，為計畫提供在地脈絡。
[[湖東社區]] — 本計畫的核心實踐場域，所有活動皆在此社區落地執行，深化[[社區陪伴]]與連結。
[[高齡照護]] — 本計畫的核心議題，涵蓋高齡者的飲食、健康、身心活化及社會參與等全面性關懷。
[[地方創生]] — 透過活化[[湖東社區]]、促進[[洄游青年]]參與及[[文化傳承]]，實現地方的永續發展。
[[食農教育]] — 透過設計[[在地食材]]菜單、推廣高齡適口性飲食及食品安全管理，提升社區居民的飲食知識與健康。
[[健康促進]] — 本計畫旨在透過飲食與體適能活動，全面提升高齡族群的健康水平。
[[食品安全]] — 導入[[IDDSI食物質地分級系統]]及編制共餐衛生管理手冊，確保高齡飲食的安全性。
[[文化傳承]] — 透過耆老[[在地知識]]的採集與[[文化再現]]，促進世代交流並保存地方記憶。
[[青銀共創]] — 本計畫的核心方法之一，透過[[青銀共學]]、[[銀青共培]]等模式，促進不同世代間的協作與學習。
[[社區陪伴]] — 計畫團隊與[[湖東社區]]建立長期信任關係，深入在地，提供持續性的支持與服務。
[[在地知識]] — 透過採集耆老記憶與文史，將地方獨特的知識融入計畫活動中。
[[永續發展]] — 本計畫的終極目標，旨在透過大學社會責任的實踐，為[[湖東社區]]創造長期的社會、經濟與環境效益。
[[高雄市小港醫院]] — 本計畫的外部合作機構，提供專業的咀嚼吞嚥評估與重建師資培訓。
[[湖東社區發展協會]] — 本計畫的重要在地合作夥伴，共同推動社區活動與資源整合。
[[澎湖縣政府]] — 本計畫的外部合作機構，提供政策支持與資源連結。
[[IDDSI食物質地分級系統]] — 國際吞嚥障礙飲食標準，為本計畫設計高齡適口性飲食提供專業依據。
[[高齡預防醫學]] — 本計畫的理論架構，旨在透過早期介入與健康管理，延緩高齡者機能老化。
[[在地食材]] — 本計畫設計高齡適口性菜單的重要元素，強調運用[[澎湖]]當令食材，兼顧營養與地方特色。
[[洄游青年]] — 本計畫[[地方創生]]的目標群體之一，透過[[銀青共培]]模式，鼓勵青年返鄉並參與社區發展。
[[活躍老化社區]] — 本計畫期望達成的社區樣貌，鼓勵高齡者獨立、參與、自我實現與尊嚴。
[[適口健康飲食]] — 本計畫為高齡者設計的飲食方案，考量咀嚼吞嚥機能，兼顧營養與美味。
[[身心健全活化]] — 本計畫透過飲食與體適能活動，促進高齡者身體與心理的全面健康。
[[青銀共學]] — [[青銀共創]]的具體實踐方式，促進年輕世代與高齡者共同學習與成長。
[[銀青共培]] — [[青銀共創]]的另一實踐方式，透過培訓，讓年輕人與高齡者共同具備多元專長。
[[記憶與文化重現]] — 透過採集耆老故事，將地方文化重新呈現，促進[[文化傳承]]與社區認同。
[[地方經濟活化]] — 透過培育[[洄游青年]]與社區志工，帶動地方產業發展與經濟活力。
[[文化再現]] — 將採集到的文史記憶，透過多元形式重新呈現，讓更多人認識與參與。
[[社區參與]] — 鼓勵高齡者積極參與社區活動，提升其社會連結與自我價值。
