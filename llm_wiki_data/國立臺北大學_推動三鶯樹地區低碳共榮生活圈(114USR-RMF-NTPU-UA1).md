# 推動三鶯樹地區低碳共榮生活圈

| 欄位 | 內容 |
|------|------|
| 執行學校 | 國立臺北大學 |
| 計畫類型 | 大學特色類萌芽型計畫 |
| SDG 關聯 | [[SDG9]]、[[SDG12]]、[[SDG13]] |
| 計畫議題 | [[產業鏈結與經濟永續]] |
| 實踐場域 | [[新北市]]、[[三峽區]]、[[樹林區]]、[[鶯歌區]]、[[中和區]] |

## 執行目標

本計畫以「[[三鶯樹低碳共榮生活圈]]」為核心，透過「在地優化、在地產品、在地實踐（[[3P模式]]）」與「[[5S協作模式]]」，推動地方[[永續發展]]、培育人才並擴散[[社會影響力]]。計畫旨在透過[[在地實踐]]、[[企業輔導]]與[[國際交流]]，達成[[低碳生活]]與[[經濟永續]]的目標。

## 主要活動與成果

-   導入[[社會投資報酬率]]（SROI）評估機制，系統化呈現計畫的[[社會影響力]]。
-   協助[[恩主公醫院]]推動[[永續治理]]與[[氣候管理]]，並辦理[[氣候變遷管理]]與醫院[[永續轉型]]講座，參與人數逾百人。
-   輔導[[全球傳動]]及[[阜爾運通]]依循[[IFRS S1/S2]]、[[TCFD]]及[[AA1000]]進行[[永續揭露]]與[[風險管理]]系列課程，協助企業建立符合國際標準的[[永續治理]]能力。
-   參與[[三峽綠茶季]]，舉辦「我是[[永續低碳]]人」闖關遊戲，推廣[[低碳生活]]理念。
-   舉辦[[春沐永續生活節]]系列活動，包含蔬食永續市集、文化手作及[[藍染體驗]]，結合[[文化走讀]]，參與人數超過千人，深化[[社區參與]]。
-   與[[新北市政府]]合作推出「[[淨零新北App]]」，首創市民[[碳資產]]機制，推廣全民[[碳資產]]紀錄與日常[[減碳行為]]。
-   透過「[[零碳夫妻]]」粉專與Podcast《[[台灣台灣ESG生活圈]]》推廣[[低碳生活]]理念，粉絲累積逾7,000人。
-   接待[[日本早稻田大學]]、[[韓國漢陽大學]] MBA 師生團隊，安排[[三峽製茶]]與[[鶯歌陶藝]]文化體驗，建立[[跨文化交流]]平台。
-   舉辦「[[永續發展目標]]與[[創業論壇]]」促進[[臺日學術對話]]，並赴日與[[法政大學]]、[[千葉商科大學]]交流[[SDGs策略]]，深化[[台日韓永續交流]]。

## 核心概念與連結

[[3P模式]] — 本計畫核心策略，強調「在地優化、在地產品、在地實踐」，以促進地方[[永續發展]]。
[[5S協作模式]] — 本計畫推動[[低碳共榮生活圈]]的協作框架，促進多方夥伴合作。
[[AA1000]] — 國際[[永續揭露]]標準之一，用於強化企業[[永續治理]]與[[風險管理]]能力。
[[IFRS S1/S2]] — 國際財務報導準則永續揭露標準，本計畫協助企業依循此標準進行[[永續揭露]]。
[[SDG9]] — 產業、創新和基礎設施，本計畫透過[[產業鏈結與經濟永續]]實踐此目標。
[[SDG12]] — 負責任的消費及生產，本計畫透過[[惜食教育]]、[[低碳生活]]推廣此目標。
[[SDG13]] — 氣候行動，本計畫透過[[氣候管理]]、[[減碳行為]]、[[淨零新北App]]等實踐此目標。
[[TCFD]] — 氣候相關財務揭露工作小組建議，本計畫輔導企業進行[[氣候揭露]]與[[氣候變遷管理]]。
[[在地實踐]] — 本計畫透過在[[三峽區]]、[[樹林區]]、[[鶯歌區]]等地的活動，將[[永續發展]]理念落實於地方。
[[在地知識]] — 透過[[三峽製茶]]、[[鶯歌陶藝]]、[[藍染體驗]]等活動，連結地方文化與[[永續發展]]。
[[全球傳動]] — 本計畫合作夥伴，協助其進行[[永續揭露]]與[[風險管理]]。
[[低碳共榮生活圈]] — 本計畫的核心願景，旨在[[三鶯樹地區]]建立[[低碳生活]]與[[經濟永續]]的共榮模式。
[[低碳生活]] — 本計畫透過多樣活動與平台，推廣民眾日常[[減碳行為]]與[[永續低碳]]理念。
[[企業輔導]] — 本計畫協助[[全球傳動]]、[[阜爾運通]]等企業提升[[永續治理]]與[[永續揭露]]能力。
[[創業論壇]] — 本計畫舉辦的國際交流活動，旨在促進[[永續發展目標]]與[[創業]]的對話。
[[減碳行為]] — 本計畫透過[[淨零新北App]]等方式，鼓勵民眾參與日常[[減碳行為]]。
[[永續發展]] — 本計畫的總體目標，涵蓋環境、社會與經濟面向的平衡發展。
[[永續發展目標]] — 聯合國提出的全球發展框架，本計畫多項活動與此目標連結。
[[永續教育推廣]] — 本計畫透過講座、活動、社群媒體等方式，向企業、醫院與社區推廣[[永續發展]]知識。
[[永續治理]] — 本計畫協助企業與醫院建立符合[[永續發展]]原則的治理模式。
[[永續揭露]] — 本計畫輔導企業依循國際標準，透明化其[[永續發展]]相關資訊。
[[永續轉型]] — 本計畫協助[[恩主公醫院]]等機構，朝向[[低碳治理]]與[[永續發展]]模式轉變。
[[永續低碳]] — 本計畫推廣的[[生活方式]]與[[產業模式]]，旨在減少碳排放。
[[恩主公醫院]] — 本計畫合作夥伴，協助其推動[[永續治理]]與[[氣候管理]]。
[[社會影響力]] — 本計畫透過[[社會投資報酬率]]（SROI）評估，量化並呈現其對社會的正面影響。
[[社會投資報酬率]] (SROI) — 本計畫導入的評估工具，用於衡量計畫的[[社會影響力]]。
[[社區參與]] — 本計畫透過[[春沐永續生活節]]、[[三峽綠茶季]]等活動，鼓勵社區居民參與[[永續行動]]。
[[氣候行動]] — 本計畫多項活動直接或間接支持[[SDG13]]，推動[[氣候變遷管理]]與[[減碳行為]]。
[[氣候管理]] — 本計畫協助企業與醫院建立應對[[氣候變遷]]風險與機會的能力。
[[氣候變遷管理]] — 本計畫協助合作夥伴應對[[氣候變遷]]挑戰，推動[[永續轉型]]。
[[氣候揭露]] — 本計畫輔導企業依循[[TCFD]]等框架，揭露其[[氣候變遷]]相關資訊。
[[淨零新北App]] — 本計畫與[[新北市政府]]合作開發的應用程式，推廣[[碳資產機制]]與[[減碳行為]]。
[[國際交流]] — 本計畫與[[日本早稻田大學]]、[[韓國漢陽大學]]、[[法政大學]]、[[千葉商科大學]]等進行學術與實務交流。
[[新北市]] — 本計畫主要實踐場域所在的縣市。
[[新北市政府]] — 本計畫合作夥伴，共同推廣「[[淨零新北App]]」。
[[春沐永續生活節]] — 本計畫舉辦的社區活動，結合蔬食市集、文化體驗，推廣[[低碳生活]]。
[[產業鏈結與經濟永續]] — 本計畫的核心議題，透過[[企業輔導]]、[[產學合作]]等方式促進產業[[永續發展]]。
[[產學合作]] — 本計畫與企業、醫院等機構合作，將學術知識應用於[[永續實踐]]。
[[碳資產]] — 本計畫透過「[[淨零新北App]]」首創的機制，鼓勵市民記錄並累積[[減碳行為]]。
[[惜食教育]] — 本計畫透過「USR x eFOOOD」活動推廣，減少食物浪費，符合[[SDG12]]。
[[跨界合作]] — 本計畫與政府、企業、醫院、社區及國際夥伴等多方合作，擴大[[社會影響力]]。
[[風險管理]] — 本計畫協助企業在[[永續揭露]]中納入[[氣候變遷]]相關風險評估。
[[三峽區]] — 本計畫主要實踐場域之一，包含[[北大特區]]、[[三峽老街]]等。
[[三峽綠茶季]] — 本計畫參與的在地節慶活動，結合[[低碳行動]]推廣[[永續理念]]。
[[三峽製茶]] — 本計畫[[國際交流]]活動中，向[[韓國漢陽大學]]師生介紹的在地文化體驗。
[[北大特區]] — [[三峽區]]與[[樹林區]]的實踐場域之一。
[[台灣台灣ESG生活圈]] — 本計畫推廣[[低碳生活]]理念的Podcast平台。
[[台日韓永續交流]] — 本計畫透過接待與互訪，深化與[[日本]]、[[韓國]]在[[永續發展]]議題上的合作。
[[千葉商科大學]] — 本計畫教師團隊赴日交流[[SDGs策略]]的合作大學。
[[中和區]] — 本計畫的實踐場域之一，包含[[雙和醫院]]。
[[日本早稻田大學]] — 本計畫接待的國際交流夥伴。
[[日本學者]] — 本計畫邀請來台舉辦「[[永續發展目標]]與[[創業論壇]]」的國際合作夥伴。
[[法政大學]] — 本計畫教師團隊赴日交流[[SDGs策略]]的合作大學。
[[阜爾運通]] — 本計畫合作夥伴，協助其進行[[永續揭露]]與[[風險管理]]。
[[全球傳動]] — [[樹林區]]的實踐場域之一，也是本計畫的企業合作夥伴。
[[國立臺北大學]] — 本計畫的執行學校。
[[韓國漢陽大學]] — 本計畫接待的國際交流夥伴。
[[樹林區]] — 本計畫主要實踐場域之一，包含[[北大特區]]、[[全球傳動]]等。
[[雙和醫院]] — [[中和區]]的實踐場域之一。
