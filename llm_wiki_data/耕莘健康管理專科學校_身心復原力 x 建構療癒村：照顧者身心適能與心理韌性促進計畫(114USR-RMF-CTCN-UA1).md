# 身心復原力 x 建構療癒村：照顧者身心適能與心理韌性促進計畫

| 欄位 | 內容 |
|------|------|
| 執行學校 | 耕莘健康管理專科學校 |
| 計畫類型 | 大學特色類萌芽型 |
| SDG 關聯 | [[SDG3]]、[[SDG4]]、[[SDG10]] |
| 計畫議題 | [[健康促進與食品安全]]、[[高齡照護]]、[[照顧者支持]] |
| 實踐場域 | [[宜蘭縣]]、[[三星鄉]]、[[壯圍]]、[[礁溪]] |

## 執行目標

本計畫旨在強化[[照顧者]]的[[心理韌性]]與[[社區支持系統]]，提升其[[自我照顧能力]]及[[照顧知能]]，進而改善[[照顧品質]]。透過營造關懷長者與照顧者的友善社區，最終目標是達成[[照顧者身心適能]]與[[全齡共好]]的[[療癒村]]願景。

## 主要活動與成果

-   **跨域師生培力與創新教學：**
    -   建立「復原力提升」、「[[反射健康法]]全人照護」、「[[身心適能]]健康促進」三大課群，並推動創新教學實踐。
    -   完成6門相關課程，舉辦1場師資培訓基礎班，成立3個跨域、跨校教師社群，並有1件研究發表，提升師生[[社會責任實踐]]能力。
-   **社區身心促進與共生模式：**
    -   依[[在地需求]]規劃多元活動，透過[[身心促進]]專業服務，營造場域夥伴關係。
    -   提供支持性環境，推動多元[[身心復原]]與[[社區共生]]模式。
    -   完成照顧者[[身心適能]]「身心技法」與「[[身心律動]]」課程各1期，舉辦2場輕旅程，並進行1場照顧者身心評估與測量。
    -   將[[身心律動]]課程推廣至[[三星鄉]]、[[壯圍]]、[[礁溪]]等社區，深獲好評。
-   **產業合作與多元發展：**
    -   建立[[社區照顧者健康促進聯盟]]，鏈結產官學界資源，定期舉辦[[健康促進論壇]]。
    -   完成1個社群平台，舉辦長照機構家屬及社區照顧者[[足部反射健康班]]各1場。
    -   邀請日本照護專家進行[[國際交流]]1場，促進國際經驗分享。
-   **創新亮點與成效：**
    -   課程不僅提升學員[[健康意識]]，也培養校內學生實作與溝通能力，增進職場競爭力。
    -   餐旅科學生因長期場域服務，於全國賽事中榮獲手沖咖啡冠亞軍。
    -   學生參與[[反射健康法]]與[[心理韌性]]課程，強化溝通與[[健康促進]]技能，提升專業自信與就業穩定性。
    -   規劃成立「[[科技導入足部全人照護共學社群]]」，將[[智慧科技照護]]與[[虛擬實境]]（VR）技術融入[[足部全人照護]]實務與教學。
    -   達成「有健康的照護者，才能讓被照顧者得到連續性的照護，也讓彼此的生命歷程得到調適與平衡」的目標，提升照護者及長者的[[健康管理]]能力。

## 核心概念與連結

[[SDG3]] — 良好健康與福祉：本計畫直接關聯此目標，透過提升照顧者與被照顧者的身心健康，促進社區整體福祉。
[[SDG4]] — 優質教育：透過師生培力、創新教學與實作課程，提升學生的專業技能與[[社會責任實踐]]能力。
[[SDG10]] — 減少不平等：關注[[照顧者]]群體的[[身心健康]]需求，透過支持系統減少其在社會照護體系中的不平等負擔。
[[宜蘭縣]] — 計畫主要實踐的地理區域，聚焦於其鄉鎮社區。
[[三星鄉]] — [[宜蘭縣]]內主要的固定實踐場域，包含社區據點與長期照護機構。
[[壯圍]] — 因計畫口碑良好而擴展的實踐場域之一。
[[礁溪]] — 因計畫口碑良好而擴展的實踐場域之一。
[[健康促進與食品安全]] — 本計畫所屬的計畫議題類別，尤其著重於健康促進面向。
[[高齡照護]] — 計畫核心關懷議題，針對[[高齡化]]社會中長者與其照顧者的需求。
[[照顧者支持]] — 計畫的核心目標，透過多樣活動與課程，提供[[照顧者]]身心靈的支持。
[[心理健康]] — 透過[[心理韌性]]課程與活動，提升[[照顧者]]的[[心理健康]]與壓力調適能力。
[[身心適能]] — 計畫強調的健康面向，透過[[身心律動]]、[[身心技法]]等課程提升[[照顧者]]的身體與心理健康狀態。
[[社區陪伴]] — 透過師生長期進駐社區，與在地居民建立關係，提供持續性的支持與服務。
[[在地知識]] — 計畫依據[[在地需求]]規劃活動，結合地方特色與資源。
[[永續發展]] — 透過建立持續性的[[健康促進]]循環與合作模式，確保計畫效益的長期性。
[[社會責任實踐]] — 大學USR計畫的核心精神，將學校專業能量轉化為對社會的實質貢獻。
[[社區共生]] — 營造學校與社區共同成長、相互支持的關係，達成[[全齡共好]]的目標。
[[健康管理]] — 提升[[照顧者]]與長者對自身健康的管理能力。
[[反射健康法]] — 計畫中採用的關鍵[[身心促進]]方法之一，特別應用於[[足部全人照護]]。
[[身心律動]] — 計畫中推動的[[身心適能]]課程，深受社區長者與[[照顧者]]好評。
[[健康促進論壇]] — 結合產官學界力量，定期舉辦以滾動式調整議題解決方案的平台。
[[國際交流]] — 邀請日本照護專家進行交流，引進國際經驗與視野。
[[智慧科技照護]] — 計畫未來發展方向，將[[科技]]導入[[足部全人照護]]領域。
[[虛擬實境]] — 應用於[[科技導入足部全人照護共學社群]]的創新技術。
[[照顧者身心適能]] — 計畫欲達成的具體目標，提升[[照顧者]]的身心健康與適應能力。
[[全人照護]] — 透過[[反射健康法]]等方式，提供全面性的身心健康關懷。
[[科技導入足部全人照護共學社群]] — 計畫未來規劃成立的創新社群，結合科技與[[足部健康]]。
[[社區照顧者健康促進聯盟]] — 連結多方資源，共同推動[[照顧者]][[健康促進]]的合作平台。
