# 足感心～全方位樂齡關懷培力計畫

| 欄位 | 內容 |
|------|------|
| 執行學校 | 國立臺北護理健康大學 |
| 計畫類型 | 大學特色類萌芽型計畫 |
| SDG 關聯 | [[SDG3]]、[[SDG4]]、[[SDG11]] |
| 計畫議題 | [[高齡照護]]、[[健康促進與食品安全]]、[[青銀共創]] |

## 執行目標

本計畫旨在透過[[青銀共創]]、跨專業合作與資源串聯，以「在地關懷」與「健康促進」為核心，全面促進[[北投區]]長者身心健康、維持功能與生命尊嚴，並實踐[[SDG3]]、[[SDG4]]及[[SDG11]]目標。

## 主要活動與成果

*   **健康吃**：
    *   舉辦4場健康飲食講座與銀髮共餐活動。
    *   開發「[[銀養食牌人生]]」APP，協助長者進行飲食管理，並整合[[北投健康餐盒地圖]]，由營養師提供飲食紀錄回饋，展現[[科技應用]]於[[健康促進]]。
*   **快樂動**：
    *   推動連續12週「國寶『韻』動，戲曲人生」課程，結合歌仔戲與律動，兼具[[文化傳承]]與[[健康促進]]，有效提升長者體能與情緒穩定，降低失能風險。
    *   辦理[[社區健康促進]]方案，鞏固[[社區支持網絡]]。
*   **心無礙**：
    *   舉辦13場次團體[[音樂輔療]]課程與[[園藝治療]]活動，促進長者情緒調適與人際互動。
*   **足關懷**：
    *   開設「足部照護與實作」微學分課程及足部護理實務工作坊，培養學生專業技能並服務社區，兼顧專業培力與[[在地回饋]]。
*   **善終了**：
    *   辦理ACP（預立醫療照護諮商）講座與團體諮商活動，協助長者理解並規劃預立醫療決策，逐步落實[[善終教育]]。
*   **跨域合作與[[世代交流]]**：
    *   結合跨領域專業與[[社區場域]]，帶領學生實踐服務，連結[[在地資源]]，推動[[青銀共學]]與[[世代交流]]，形塑[[社區共好]]模式。
    *   透過多元課程與社區實作，強化學生專業知能與服務經驗，培養世代理解與[[社會責任]]感。
*   **成效評估**：
    *   採用[[社會投資報酬率]]（SROI）作為成效評估框架，盤點利害關係人並建立成效資料庫，為後續量化社會價值奠定基礎。

## 核心概念與連結

[[SDG3]] — 良好健康與福祉：本計畫透過多面向的[[健康促進]]活動（飲食、運動、心理、足部照護），直接提升長者身心健康與生活品質。
[[SDG4]] — 優質教育：計畫提供學生專業培力課程與社區實作機會，並透過[[青銀共學]]促進[[世代交流]]與理解，提升教育品質與社會責任。
[[SDG11]] — 永續城市及社區：計畫深耕[[北投區]]，鏈結[[在地資源]]與合作機構，建立[[社區支持網絡]]，形塑[[社區共好]]與[[永續發展]]的模式。
[[高齡照護]] — 本計畫的核心議題，透過五大主軸提供全方位的樂齡關懷與服務，旨在促進長者健康與生命尊嚴。
[[健康促進與食品安全]] — 計畫主軸「健康吃」聚焦於健康飲食講座、銀髮共餐及「[[銀養食牌人生]]」APP，直接回應此議題。
[[健康促進]] — 貫穿計畫所有主軸，從飲食、運動、心理到足部照護，全面提升長者的健康狀態。
[[青銀共創]] — 計畫透過[[青銀共學]]、[[世代交流]]等活動，鼓勵不同世代共同參與、學習與服務，創造共融價值。
[[臺北市]] — 本計畫的實踐場域所在縣市。
[[北投區]] — 本計畫的主要實踐場域，所有社區服務與合作夥伴皆位於此區。
[[國立臺北護理健康大學]] — 本計畫的執行學校，也是重要的實踐場域與專業資源提供者。
[[北投健康餐盒地圖]] — 「[[銀養食牌人生]]」APP整合的在地資源，方便長者取得健康飲食資訊。
[[在地關懷]] — 本計畫聚焦於[[北投區]]在地長者的需求，透過社區服務與資源連結，深化在地連結與關懷。
[[社區健康促進]] — 計畫透過「快樂動」主軸推動社區健康促進方案，鼓勵長者參與運動，增進社區活力。
[[善終教育]] — 計畫「善終了」主軸透過ACP講座與諮商，協助長者及家屬理解並規劃預立醫療決策，推廣生命尊嚴與善終理念。
[[北投區健康服務中心]] — 本計畫的重要合作機構之一，共同推動社區健康服務。
[[臺北市樂齡關懷協會]] — 本計畫的合作機構，共同關懷樂齡長者。
[[立群社區發展協會]] — 本計畫的合作社區夥伴。
[[振華社區發展協會]] — 本計畫的合作社區夥伴。
[[吉慶社區發展協會]] — 本計畫的合作社區夥伴。
[[天母康健身心診所]] — 本計畫的合作醫療機構。
[[北護耆老守護社]] — 本校學生社團，參與計畫服務。
[[北投區老人服務中心]] — 本計畫的合作機構，提供老人服務。
[[台灣長期照護管理學會]] — 本計畫的合作專業學會。
[[台灣安寧照顧基金會]] — 本計畫「善終了」主軸的合作機構。
[[菲特邦健康管理中心]] — 本計畫的合作健康管理機構。
[[營佳社區營養推廣中心]] — 本計畫「健康吃」主軸的合作營養推廣機構。
[[活力大衛音樂輔療團隊]] — 本計畫「心無礙」主軸的合作音樂輔療團隊。
[[荷星牙科診所]] — 本計畫的合作醫療機構，可能涉及口腔保健。
[[音樂輔療]] — 「心無礙」主軸的核心方法，透過音樂活動促進長者情緒調適與人際互動。
[[園藝治療]] — 「心無礙」主軸的核心方法，透過園藝活動促進長者身心健康。
[[社區陪伴]] — 計畫透過建立銀髮友善據點、深化長者支持網絡，提供長者持續性的陪伴與關懷。
[[科技應用]] — 計畫開發「[[銀養食牌人生]]」APP，將數位工具應用於長者飲食管理與健康促進。
[[社會投資報酬率]] — 本計畫採用的成效評估框架，旨在量化計畫所創造的社會價值。
[[在地知識]] — 計畫透過連結[[在地資源]]與社區夥伴，汲取並運用在地經驗與智慧。
[[永續發展]] — 本計畫旨在建立制度化的服務模式與合作基礎，確保USR計畫能長期持續，實現[[永續發展]]目標。
[[社區支持網絡]] — 計畫透過社區健康促進方案與合作夥伴，強化長者在社區中的支持系統。
[[社區共好]] — 本計畫透過[[青銀共學]]、[[在地關懷]]與資源串聯，旨在促進社區成員共同受益、共同發展。
[[文化傳承]] — 「國寶『韻』動，戲曲人生」課程結合歌仔戲，在[[健康促進]]的同時也傳承了傳統文化。
[[銀養食牌人生]] — 本計畫開發的LINE bot APP，是[[科技應用]]於[[健康促進]]的具體成果。
[[世代交流]] — 透過[[青銀共學]]等活動，促進不同世代之間的理解與互動。
[[青銀共學]] — 計畫創造長者與學生共同學習的場域，促進知識與經驗的雙向傳遞。
[[在地回饋]] — 「足部照護與實作」微學分課程培養學生專業技能後，直接服務社區長者，實踐大學對在地的回饋。
