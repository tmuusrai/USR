# 安心葉興百業邁(賣)向全世界

| 欄位 | 內容 |
|------|------|
| 執行學校 | 大葉大學 |
| 計畫類型 | 萌芽型 |
| SDG 關聯 | [[SDG3]]、[[SDG4]]、[[SDG12]] |
| 計畫議題 | [[健康促進與食品安全]]、[[地方創生]] |
| 實踐場域 | [[南投縣]]、[[竹山鎮]]、[[雲林國小]] |

## 執行目標

本計畫以教育推動地方[[永續發展]]為核心，結合課程實作、場域合作與社會影響評估，旨在促進[[竹山鎮]]茶產業升級，並培育具備茶藝、[[食品安全]]與行銷能力的跨域人才，最終將「安心葉」品牌推向國際。

## 主要活動與成果

-   開設 18 門跨域課程，涵蓋茶文化、影像行銷、品牌設計與[[食農教育]]，吸引逾 600 人次修課。
-   學生參與場域學習 241 人次，完成製茶、導覽與品牌策展任務，其中 40 人考取丙級製茶技術士證照。
-   完成「[[茶產業微學程]]」課程架構設計，預定下年度開設，強化產業實務連結。
-   與[[竹山鎮公所]]、農會、靜嘉草堂、一龍谷、旭美茶廠及[[雲林國小]]等夥伴合作，舉辦 8 場場域活動。
-   建置「[[竹山TEAM八通行銷與人才培育平臺]]」，完成 70% 核心功能並試營運，推動[[竹山鎮]]茶業數位轉型與青年培育。
-   與[[仙夷茶莊]]及[[大榮生技公司]]合作，以大葉大學「製茶技產品研發基地」為核心，共同開發 GABA 康普茶產品。
-   辦理「全國創意茶飲調製競賽」，學生作品獲獎，提升創新與實作能量。
-   連續六年參與[[南投世界茶業博覽會]]與[[USR EXPO]]，展出「安心葉」品牌成果，並辦理 SDGs 課程及 USR 論壇 20 場。
-   導入[[社會投資報酬率（SROI）]]架構，完成 28 筆利害關係人訪談，歸納 49 項成果、15 類效益，評估計畫社會影響力。
-   採用「[[目標導向績效管理（MBO）]]」結合[[社會投資報酬率（SROI）]]雙軌評估模式，整體 KPI 達成率逾九成。

## 核心概念與連結

[[南投縣]] — 計畫主要實踐場域之一，位於臺灣中部。
[[竹山鎮]] — [[南投縣]]的鄉鎮，計畫核心場域，推動茶產業轉型與[[地方創生]]。
[[雲林國小]] — 計畫合作夥伴之一，參與「茶×文化×教育×永續」行動網絡。
[[健康促進與食品安全]] — 本計畫的核心議題，透過茶產業鏈結食安管理與健康產品開發。
[[地方創生]] — 計畫旨在透過茶產業的升級與人才培育，活化[[竹山鎮]]地方經濟與文化。
[[永續發展]] — 計畫的長期目標，建立教育、產業、社區共榮的模式。
[[SDG3]] — 良好健康與福祉：透過[[食品安全]]管理與健康產品開發（如 GABA 康普茶）來實踐。
[[SDG4]] — 優質教育：開設跨域課程、微學程、證照輔導，培育茶產業人才。
[[SDG12]] — 負責任的消費及生產：推動茶產業升級、品牌行銷與永續生產模式。
[[竹山鎮公所]] — 計畫的重要合作夥伴，共同建構[[竹山TEAM八通行銷與人才培育平臺]]。
[[仙夷茶莊]] — 產學合作夥伴，共同開發茶產品。
[[大榮生技公司]] — 產學合作夥伴，共同開發茶產品。
[[茶產業微學程]] — 計畫為培育茶產業人才而設計的專業課程模組。
[[食農教育]] — 跨域課程內容之一，連結茶葉生產與飲食文化。
[[竹山TEAM八通行銷與人才培育平臺]] — 計畫建置的數位平台，旨在推動[[竹山鎮]]茶業數位轉型與青年培育。
[[南投世界茶業博覽會]] — 計畫團隊連續六年參與的國際性展覽，推廣「安心葉」品牌與成果。
[[USR EXPO]] — 大學社會責任實踐計畫的成果展，計畫團隊持續參與。
[[社會投資報酬率（SROI）]] — 計畫用來評估社會影響力的量化方法。
[[目標導向績效管理（MBO）]] — 計畫採用的績效管理模式，結合 SROI 進行雙軌評估。
[[在地知識]] — 計畫透過與地方茶農、社區的合作，傳承與活化[[竹山鎮]]的茶產業[[在地知識]]。
