# 超高齡社會幸福學──在地青銀共好實踐

| 欄位 | 內容 |
|------|------|
| 執行學校 | [[國立臺灣大學]] |
| 計畫類型 | 萌芽型 |
| SDG 關聯 | [[SDG3]]、[[SDG4]]、[[SDG11]] |
| 計畫議題 | [[在地關懷]]、[[高齡照護]]、[[青銀共創]]、[[幸福老化]] |

## 執行目標

本計畫以「如何讓老化成為幸福的歷程」為核心，旨在透過[[跨域整合]]與[[數位健康]]應用，結合[[臺大醫院北護分院]]、[[龍山老人服務中心]]等在地機構，建立[[青銀共學]]及[[幸福科技]]實踐平台。最終目標是推動健康、活躍、幸福的[[高齡友善城市]]與[[社區]]，實現[[永續發展]]。

## 主要活動與成果

-   **前期基礎延續**：延續前期「安寧終老」計畫，聚焦[[臺北市]][[萬華區]]，推動[[病人自主權利法]]理念與[[社區實踐]]，形塑以[[生命價值教育]]為核心的[[社區支持網絡]]。
-   **主題轉化與擴展**：自114年度起，計畫轉化為「超高齡幸福學」，以「如何讓老化成為幸福的歷程」為主題，擴展服務對象與內容。
-   **社區講座與共學活動**：
    -   舉辦「唱出老後人生幸福曲」系列講座，運用「老後人生設計書」促進長者為老後人生規劃。
    -   與[[日本]]代表若宮正子女士共同舉辦「台日樂齡數位交流」，推動[[數位藝術]]與[[高齡科技]]應用。
    -   辦理「理出老後人生幸福帳戶」講座，協助長者規劃經濟與心理安全感。
    -   辦理「失智症醫療選擇與病人自主」講座，引導長者理解[[身體自主]]的重要性。
    -   舉行「夏日樂齡藝文時光」提升長者身心幸福感。
-   **校內教學與人才培育**：
    -   開設「[[健康體適能]]指導員」課程四班，落實USR理念於校內教學，培育學生為社區健康種子教師。
    -   USR課程開設4門，修課學生達160人，學生於場域學習中培養[[跨世代溝通]]與[[行動能力]]。
-   **量化成果**：辦理活動15場、跨域會議5場、試用與工作坊2場，參與人次逾420人；合作夥伴8單位，跨國交流1場。
-   **質性亮點**：
    -   **跨國交流**：邀請[[日本]]高齡創作者若宮正子女士線上交流，促進台日[[高齡科技]]對話。
    -   **跨校合作**：楊培珊教授應[[國立臺北大學]] USR計畫邀稿，於《學老誌 Learning & Aging》發表專文，展現USR國際延伸與[[社會影響]]。
    -   **幸福老化實踐**：透過「幸福帳戶」與「唱出老後人生幸福曲」系列活動，促進長者自信與[[社區互助]]。
    -   **幸福科技導入**：[[Corn Soup平台]]與VR《黃金稻穗》運用於健康與[[藝術療癒]]教學。
    -   **青銀共學深化**：學生於場域學習中培養[[跨世代溝通]]與[[行動能力]]。
-   **團隊運作**：建立「學術—醫療—社區—企業」四方協作網絡，與[[臺大醫院北護分院]]、[[龍山老人服務中心]]及地方里辦公室建立定期合作模式。

## 核心概念與連結

[[臺北市]] — 本計畫主要實踐場域之一，為超高齡社會議題的重點關注區域。
[[萬華區]] — [[臺北市]]的特定區域，前期「安寧終老」計畫及本計畫的核心實踐場域。
[[日本]] — 透過線上交流與高齡創作者若宮正子女士合作，促進國際[[高齡科技]]對話。
[[高齡照護]] — 本計畫核心議題，旨在透過多元活動與科技應用提升長者福祉。
[[在地關懷]] — 透過與[[萬華區]]在地機構合作，回應社區長者需求，建立[[社區支持網絡]]。
[[幸福老化]] — 本計畫的核心理念，強調讓老化過程成為積極、有意義的體驗。
[[SDG3]] — 透過健康體適能、失智症醫療選擇等活動，促進長者身心健康與福祉。
[[SDG4]] — 透過[[青銀共學]]課程與講座，提供長者及學生優質教育機會。
[[SDG11]] — 致力於在[[萬華區]]建立[[高齡友善城市]]與[[永續社區]]。
[[國立臺灣大學]] — 本計畫的執行學校，提供跨院系專業資源。
[[臺大醫院北護分院]] — 重要的醫療合作夥伴，共同推動[[全人全社區照護計畫]]。
[[龍山老人服務中心]] — 在地社區合作夥伴，共同策劃與執行長者服務活動。
[[國立臺北大學]] — 跨校合作夥伴，共同推動USR計畫的交流與影響力擴散。
[[青銀共創]] — 透過[[青銀共學]]活動，促進跨世代交流與合作，共同創造幸福生活。
[[跨域整合]] — 結合社會工作、醫療、體適能、數位科技等多方專業，建立協作網絡。
[[幸福科技]] — 導入[[Corn Soup平台]]、VR等數位工具，應用於高齡者的健康與[[藝術療癒]]。
[[社區實踐]] — 將大學知識與資源帶入[[萬華區]]社區，回應在地需求並產生實質影響。
[[病人自主權利法]] — 前期計畫的重點推廣理念，引導長者理解[[身體自主]]的重要性。
[[生命價值教育]] — 透過「老後人生設計書」等活動，引導長者思考與規劃人生終末歷程。
[[社區支持網絡]] — 透過跨領域合作與志工培力，在社區中建立互助支持系統。
[[永續發展]] — 本計畫旨在建立可持續運作的USR共學網絡，促進[[高齡友善城市]]的[[永續發展]]。
[[社會影響]] — 透過計畫的實踐與推廣，擴大大學對社會的正面影響力。
[[青銀共學]] — 透過課程與活動，促進青年學生與長者之間的學習與互動。
[[數位健康]] — 結合數位科技應用於長者健康促進與照護。
[[高齡友善城市]] — 透過多面向的計畫實踐，營造適合高齡者居住與生活的城市環境。
[[社區]] — 計畫實踐的核心場域，強調在地連結與居民參與。
[[數位藝術]] — 透過與[[日本]]若宮正子女士的交流，探索數位工具在藝術創作與高齡者生活中的應用。
[[高齡科技]] — 運用科技工具提升高齡者的生活品質、健康與福祉。
[[身體自主]] — 透過講座引導長者理解並實踐對自身醫療與生活的自主權。
[[健康體適能]] — 透過指導員課程與活動，提升長者的身體活動能力與健康狀況。
[[跨世代溝通]] — 透過[[青銀共學]]活動，促進不同世代間的理解與交流。
[[行動能力]] — 學生在參與計畫中培養解決問題與實際執行的能力。
[[社區互助]] — 透過計畫活動，強化社區居民間的相互支持與合作。
[[Corn Soup平台]] — 本計畫導入的[[幸福科技]]工具之一，用於健康與[[藝術療癒]]教學。
[[藝術療癒]] — 透過藝術活動，促進長者的身心健康與情感表達。
[[全人全社區照護計畫]] — [[臺大醫院北護分院]]參與本計畫的重點項目，強調整合性醫療與社區健康服務。
