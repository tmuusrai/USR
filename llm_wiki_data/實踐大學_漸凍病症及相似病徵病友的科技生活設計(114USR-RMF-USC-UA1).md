# 漸凍病症及相似病徵病友的科技生活設計

## 執行目標

本計畫旨在透過[[科技生活設計]]，關注[[漸凍病症]]及[[相似病徵病友]]的[[生活福祉]]，並[[深耕在地鏈結]]形成[[社群平台]]，同時培育[[進階人才]]，以回應社會需求並提升病友生活品質。

## 主要活動與成果

-   **服務對象擴展**：從[[漸凍病友]]擴大至[[相似病徵病友]]，拓展服務應用場域。
-   **人才培育與課程發展**：
    -   成立院級[[跨領域微學程]]，規劃「[[進階人才培訓]]三年計畫」。
    -   設立年度「[[跨域智慧照護設計]]」大工作營。
    -   開設『[[科技生活設計講座]]』課程，提升學生對[[漸凍症]]的認識。
    -   規劃開設『[[科技生活設計跨領域工作營]]』，開放[[實踐大學]]、[[台北大學]]、[[東吳大學]]學生參與。
    -   在設計課程中積極導入[[AI科技]]於設計應用，並與[[東吳大學]]資料科學系及社工系交流[[AI應用]]於社會服務。
-   **在地鏈結與社群平台建構**：
    -   與學會、基金會、學者、醫師及企業等22個單位簽署MOU，形成[[社群平台]]。
    -   啟動『[[產業出題，學校承接]]』[[產學鏈結]]模式，鏈結[[病友需求]]、[[台灣產業]]與[[學校師生]]的[[學研產]]合作。
-   **設計產出與服務實踐**：
    -   產出70件[[照護輔具]]與[[智慧溝通]]設計。
    -   產出21件兼具美感與功能的[[病理服飾設計]]，並延伸至[[重症]]、[[高齡照護]]領域。
    -   產出15件[[社會教育影音設計]]，分享[[漸凍症]]心得畫作。
    -   收錄20位[[漸凍病友]]聲音，建立[[病友聲音銀行]]與[[語音再現]]系統。
    -   優化[[個案管理]]流程，產出20件專題；[[志工團隊]]出訪95人次、42次家訪、16次團督。
    -   舉辦四場[[悲傷與生命意義家庭輔導]]工作坊。
-   **成果展演與推廣**：
    -   舉辦3場[[漸凍人科技生活產品設計展]]，展出91件設計作品。
    -   發行2本[[漸凍人科技生活設計專刊]]。
    -   舉辦1場[[脊髓病理服走秀展]]。
    -   10家企業參與活動與關注。
    -   舉辦16場[[社會參與場域活動]]。
-   **榮譽與成效評估**：
    -   榮獲遠見雜誌『2025 USR 楷模獎』。
    -   教師自評高度認同USR計畫有助於教學架構、深化[[跨域學習]]與[[同理學習]]。
    -   學生回饋「[[專業與社會實踐]]」得分最高，顯示能將學習與社會議題連結。
    -   利害關係人肯定活動實用性、提升[[病友生活品質]]、降低[[照顧壓力]]、促進[[跨域學習]]，並提升大眾對議題的關注與支持度。

## 核心概念與連結

[[漸凍病症]] — 本計畫主要服務對象，透過科技設計改善其生活品質。
[[相似病徵病友]] — 計畫服務對象的擴展，涵蓋更多有類似需求的群體。
[[科技生活設計]] — 運用科技手段，為病友提供創新且實用的生活解決方案。
[[生活福祉]] — 計畫的核心關懷，旨在提升病友的整體生活品質與尊嚴。
[[深耕在地鏈結]] — 與在地機構、社區建立長期合作關係，形成支持網絡。
[[社群平台]] — 透過MOU合作夥伴，建立跨領域、跨機構的資源共享與協作平台。
[[進階人才培訓]] — 透過微學程、工作營等方式，培育學生具備跨領域[[智慧照護]]設計能力。
[[跨領域微學程]] — 整合不同學科專業，提供學生系統性的學習路徑。
[[產業出題，學校承接]] — 一種[[產學鏈結]]模式，將業界實際需求導入教學與研究。
[[產學鏈結]] — 促進學術界與產業間的合作，將研究成果轉化為實際應用。
[[AI科技]] — 導入人工智慧技術於產品設計與社會服務應用。
[[病友需求]] — 所有設計與服務的核心出發點，強調以人為本。
[[照護輔具]] — 為病友設計的實用工具，提升其自理能力與生活便利性。
[[智慧溝通]] — 透過科技輔助，改善病友與外界的溝通效率。
[[病理服飾設計]] — 結合美感與功能，為病友提供舒適且具尊嚴的穿戴解決方案。
[[高齡照護]] — 計畫成果可延伸應用至高齡族群的照護需求。
[[病友聲音銀行]] — 收集病友聲音，透過[[語音再現]]技術，保留其獨特聲音。
[[個案管理]] — 提供個別化的支持與服務，優化病友及其家庭的照護流程。
[[志工團隊]] — 學生與社會人士參與服務，提供陪伴與協助。
[[悲傷與生命意義家庭輔導]] — 提供心理支持，協助病友家庭面對疾病挑戰。
[[設計展演]] — 公開展示學生設計成果，促進社會大眾對議題的認識與關注。
[[社會參與場域活動]] — 透過多元活動，促進病友與社會的互動。
[[跨域學習]] — 鼓勵學生整合不同領域知識，解決複雜社會問題。
[[同理學習]] — 培養學生設身處地理解病友處境的能力。
[[專業與社會實踐]] — 將學術專業知識應用於解決真實社會問題。
[[病友生活品質]] — 計畫最終目標，透過多面向介入提升病友生活品質。
[[照顧壓力]] — 透過支持服務與輔具設計，減輕病友家庭的照顧負擔。
[[健康促進]] — 本計畫的核心議題，旨在提升特定群體的健康與福祉。
[[SDG1]] — 消除貧窮，透過改善病友生活品質間接減少其家庭負擔。
[[SDG3]] — 良好健康與福祉，直接關聯病友的健康與生活品質提升。
[[SDG10]] — 減少不平等，關注弱勢群體，促進社會公平。
[[臺北市]] — 計畫主要實踐場域所在的縣市。
[[中山區]] — 計畫主要實踐場域所在的鄉鎮市區。
[[中華民國運動神經元疾病病友協會]] — 計畫主要合作與實踐場域機構。
[[實踐大學]] — 計畫執行學校。
[[台北大學]] — 合作學校，參與跨領域工作營。
[[東吳大學]] — 合作學校，參與跨領域工作營及AI應用交流。
