# 以淺山茶產業為載體之韌性農村社會實踐人才培力計畫

| 欄位 | 內容 |
|------|------|
| 執行學校 | 國立雲林科技大學 |
| 計畫類型 | 深耕型 |
| SDG 關聯 | [[SDG11]]、[[SDG12]]、[[SDG13]] |
| 計畫議題 | [[產業鏈結與經濟永續]]、[[韌性農村]]、[[智慧防災]]、[[人才培育]] |
| 實踐場域 | [[雲林縣]]、[[古坑鄉]]、[[桂林社區]] |

## 執行目標

本計畫旨在強化[[雲林縣]][[古坑鄉]][[桂林社區]]的[[韌性與永續發展]]，透過[[淺山茶產業]]的創新與升級，建立可複製的[[地方創生]]與[[人才培育]]模式，打造具[[防災能力]]、[[產業創新]]與[[社會凝聚力]]的[[韌性農村]]典範。

## 主要活動與成果

-   **韌性環境：**
    -   完成即時[[雨量感測站]]與[[無人機]]航線規劃，啟動[[地貌監控]]及荔枝椿象、獼猴監測。
    -   設置[[微氣象站]]進行[[茶園環境監控]]，為[[智慧防災]]與[[永續農業]]奠定基礎。
-   **韌性產業：**
    -   與[[茶改場]]合作設立[[自然農法]]實驗茶園，推動[[茶園病蟲害資料庫]]與[[專業製茶訓練]]。
    -   研發凍乾冷泡紅茶、台日/台馬拼配茶等[[創新產品]]，並結合工藝開發[[茶具週邊]]，提升[[在地經濟韌性]]。
-   **韌性陪伴：**
    -   於苦苓腳與蟾蜍嶺推動[[長輩陪伴]]與[[長青食堂]]計畫，並以[[青聚點]]與[[樂齡據點]]為核心。
    -   辦理[[青年增能課程]]及兒童「淺山四季釀」[[食農教育]]，透過[[雨笙音療]]等活動，建立[[跨世代共學]]的[[社會支持網絡]]。
-   **韌性意識：**
    -   舉辦[[台灣馬來西亞跨國讀書會]]與居民深度訪談，推動[[藥草食療工作坊]]。
    -   強化居民的[[環境感知]]與[[自主學習能力]]，培養面對變遷的[[自我調適力]]。
-   **總計畫與人才培育：**
    -   導入[[OGSM]]與[[SROI]]進行[[專案管理]]與效益評估。
    -   建構「[[社會實踐學分學程]]」，自114學年度起招生，培育具行動力與[[永續思維]]的[[社會實踐人才]]。
    -   深化[[國際鏈結]]，與[[馬來西亞拉曼大學]]及11個地方組織建立夥伴關係，[[國際合作]]模式榮獲2025亞太永續行動獎銅獎，展現[[USR]]領域的[[國際影響力]]。

## 核心概念與連結

[[雲林縣]] — 本計畫的實踐縣市。
[[古坑鄉]] — 本計畫的實踐鄉鎮。
[[桂林社區]] — 本計畫主要深耕的[[淺山農村]]社區，是[[地方創生]]與[[韌性農村]]的實踐場域。
[[產業鏈結與經濟永續]] — 本計畫的核心議題，透過茶產業創新與升級，促進地方經濟發展。
[[韌性農村]] — 計畫旨在透過多面向策略，提升農村面對環境變遷與災害的調適能力。
[[智慧防災]] — 透過科技應用（如[[雨量感測站]]、[[無人機]]、[[微氣象站]]），建立農村的災害預警與應變機制。
[[人才培育]] — 透過[[社會實踐學分學程]]與[[青年增能課程]]，培養具備[[地方創生]]與[[永續發展]]能力的學生與在地青年。
[[SDG11]] — 永續城市及社區：透過強化社區韌性、[[地方創生]]與[[跨世代共學]]，提升社區的永續發展能力。
[[SDG12]] — 負責任的消費及生產：推動[[自然農法]]、[[茶產業創新]]與[[循環經濟]]概念，促進永續生產與消費模式。
[[SDG13]] — 氣候行動：透過[[智慧防災]]、[[環境監測]]與[[韌性環境]]建構，提升社區應對氣候變遷的調適能力。
[[自然農法]] — 在茶園管理中推廣的永續農業方法，減少對環境的衝擊。
[[茶改場]] — 合作夥伴，提供茶產業專業技術支援。
[[青銀共創]] — 透過[[長輩陪伴]]、[[長青食堂]]與[[青年增能課程]]，促進跨世代的交流與合作。
[[社區陪伴]] — 透過[[長輩關懷]]、[[食農教育]]等活動，建立社區內的[[社會支持網絡]]。
[[食農教育]] — 透過「淺山四季釀」等課程，提升學童對在地農業與飲食文化的認識。
[[地方創生]] — 透過產業升級、[[人才培育]]與社區營造，活化地方發展。
[[在地知識]] — 透過[[藥草食療工作坊]]、居民訪談等，挖掘與傳承地方智慧。
[[永續發展]] — 貫穿計畫的核心理念，旨在實現環境、社會與經濟的長期平衡。
[[國際合作]] — 與[[馬來西亞拉曼大學]]等夥伴的交流，拓展[[USR]]的國際影響力。
[[OGSM]] — 目的、目標、策略、衡量：計畫採用的策略管理工具，確保目標達成。
[[SROI]] — 社會投資報酬率：計畫用於評估社會效益的工具。
[[社會實踐學分學程]] — 國立雲林科技大學為培育[[社會實踐人才]]而設立的課程體系。
[[馬來西亞拉曼大學]] — 本計畫的國際合作夥伴。
[[雨量感測站]] — 韌性環境的重要設施，用於監測降雨量以預防災害。
[[無人機]] — 用於地貌監控、荔枝椿象及獼猴監測等，提升[[智慧防災]]能力。
[[微氣象站]] — 用於茶園環境監控，提供精準農業數據。
[[茶園病蟲害資料庫]] — 協助茶農進行病蟲害防治，推動[[永續農業]]。
[[專業製茶訓練]] — 提升在地茶產業的技術水準與產品品質。
[[創新產品]] — 透過研發凍乾冷泡紅茶、跨國拼配茶等，增加茶產業附加價值。
[[茶具週邊]] — 結合工藝開發，延伸茶產業鏈。
[[長輩陪伴]] — 透過活動關懷社區長者，建立社會支持。
[[長青食堂]] — 提供長者共餐服務，促進社會互動與營養均衡。
[[青年增能課程]] — 提升在地青年技能，鼓勵返鄉與[[地方創生]]。
[[社區世代連結]] — 透過跨世代活動，強化社區凝聚力。
[[青聚點]] — 青年聚集與活動的據點。
[[樂齡據點]] — 長者活動與服務的據點。
[[雨笙音療]] — 創新的陪伴活動形式。
[[跨世代共學]] — 促進不同世代間的知識與經驗交流。
[[社會支持網絡]] — 透過社區活動建立的互助系統。
[[台灣馬來西亞跨國讀書會]] — 國際交流與文化理解的活動。
[[藥草食療工作坊]] — 傳承[[在地知識]]，提升居民健康意識。
[[自助]] — 培養居民自我解決問題的能力。
[[環境認知能力]] — 提升居民對在地環境的理解與保護意識。
[[環境感知]] — 居民對周遭環境變化的敏感度。
[[自主學習能力]] — 居民主動獲取知識與技能的能力。
[[自我調適力]] — 面對變遷時，個人或社區的適應能力。
[[專案管理]] — 運用[[OGSM]]等工具，有效規劃、執行與監控計畫。
[[USR]] — 大學社會責任，本計畫的核心實踐領域。
[[國際影響力]] — 透過[[國際合作]]，擴大[[USR]]實踐的範疇與效益。
