# 智慧城市之淨零轉型與電動運具科普推廣實踐計畫

| 欄位 | 內容 |
|------|------|
| 執行學校 | 樹德科技大學 |
| 計畫類型 | 大學特色類萌芽型 |
| SDG 關聯 | [[SDG4]]、[[SDG9]]、[[SDG11]] |
| 計畫議題 | [[淨零轉型]]、[[智慧城市]]、[[產業鏈結與經濟永續]]、[[電動運具]] |
| 實踐場域 | [[高雄市]]、[[燕巢區]]、[[大社區]] |

## 執行目標

本計畫旨在響應國家「2050年淨零排放」與「2030年公車全面電動化」政策，並配合[[橋頭科學園區]]電動車產業聚落發展。其核心目標為推動南台灣[[電動運具]]產業[[人才培育]]與[[科普推廣]]服務，以具體實踐[[大學社會責任]]。

## 主要活動與成果

-   **專業能力深化**：團隊成員取得27張國際[[淨零轉型]]相關專業證照，包含[[ISO 14067產品碳足跡主導查證員]]及[[ESG永續管理師]]。
-   **創新技術研發**：師生團隊開發之《整合[[區塊鏈]]與[[車聯網]]之[[智慧綠色運輸]]碳排放監測與管理系統》榮獲「2025交通部公路局資料創新應用競賽」創新獎，並取得新型專利。
-   **課程與人才培育**：
    -   開設「車用電子概論」等課程，超過267人次修課。
    -   開設「[[碳足跡]]與[[碳排查]]法規與技術」及「[[大學社會責任]]素養與實踐課程」，修課人數達50位。
    -   與[[高雄高工]]合辦全國教師[[電動運具]]研習營。
    -   參與[[高雄市教育局]]新興科技教育遠距示範服務計畫，進行[[電動運具]]教案編審。
-   **在地與產業連結**：
    -   帶領師生參訪[[智慧城市展]]，了解最新[[智慧城市]]與[[綠色運輸]]發展。
    -   媒合[[楠梓產業園區]]產學實習機會。
    -   與[[高雄市交通局]]、[[高雄市區公車聯管會]]合辦[[電動巴士]]防災座談會。
    -   與[[車輛研究測試中心 (ARTC)]]合作辦理[[人才培育]]課程。
    -   獲得[[亞東通信工業]]捐贈2套智能充電樁，[[永盛車電公司]]捐贈教學圖書，深化[[產學合作]]。
-   **社會[[科普推廣]]**：
    -   與[[台灣網路智能學會]]合辦[[電動運具]]發展新知座談會。
    -   與[[高雄市西區扶輪社]]於[[駁二藝術特區]]共同辦理「您知道以及您不知道的[[電動運具]]大小事」[[科普推廣]]活動。
    -   於[[燕巢區電動運具科普推廣據點]]與[[大社區電動運具科普推廣據點]]進行在地推廣活動。

## 核心概念與連結

[[大學社會責任]] — 本計畫透過[[人才培育]]、[[科普推廣]]與[[產學合作]]，回應國家[[淨零轉型]]政策，展現大學對區域[[永續發展]]的貢獻。
[[淨零轉型]] — 計畫核心目標之一，透過[[電動運具]]推廣、[[碳足跡]]與[[碳排查]]技術應用，支持台灣達成2050年[[淨零碳排放]]目標。
[[智慧城市]] — 透過[[電動運具]]、[[車聯網]]及[[區塊鏈]]技術的整合應用，推動城市交通的智慧化與[[綠色運輸]]發展。
[[電動運具]] — 計畫主要推廣與[[人才培育]]的焦點，涵蓋[[電動車]]與[[電動巴士]]，是實現[[淨零轉型]]的關鍵。
[[產業鏈結與經濟永續]] — 透過與[[橋頭科學園區]]、[[楠梓產業園區]]及相關企業（如[[亞東通信工業]]、[[永盛車電公司]]）的[[產學合作]]，促進[[電動運具]]產業發展與經濟[[永續發展]]。
[[科普推廣]] — 透過研習營、座談會及在地活動，向師生、產業與社會大眾普及[[電動運具]]與[[淨零轉型]]相關知識。
[[人才培育]] — 透過課程開設、證照輔導、競賽參與及產學實習，培養[[電動運具]]與[[淨零轉型]]領域的專業人才。
[[產學合作]] — 與[[車輛研究測試中心 (ARTC)]]、[[亞東通信工業]]、[[永盛車電公司]]等產業夥伴合作，將學術研究與產業實務結合。
[[在地連結]] — 在[[高雄市]]的[[燕巢區]]、[[大社區]]及[[駁二藝術特區]]等地舉辦活動，深化與地方社區的互動與影響。
[[跨域合作]] — 結合校內資訊、企管等多元領域師生，並與[[高雄高工]]、[[台灣網路智能學會]]、[[高雄市交通局]]、[[高雄市區公車聯管會]]、[[高雄市西區扶輪社]]、[[高雄市教育局]]等跨單位合作。
[[區塊鏈]] — 應用於[[智慧綠色運輸]]碳排放監測與管理系統，提升數據透明度與可信度。
[[車聯網]] — 應用於[[智慧綠色運輸]]碳排放監測與管理系統，實現車輛間及車輛與基礎設施間的智慧通訊。
[[碳足跡]] — 透過相關課程與證照培訓，提升師生對產品與服務[[碳足跡]]計算與管理的專業能力。
[[碳排查]] — 透過相關課程與證照培訓，協助企業與組織進行溫室氣體排放盤查，支持[[淨零轉型]]。
[[ESG]] — 團隊成員取得[[ESG永續管理師]]證照，將環境、社會、公司治理理念融入計畫執行。
[[綠色運輸]] — 透過[[電動運具]]的推廣與[[智慧綠色運輸]]系統的開發，促進環境友善的交通模式。
[[永續發展]] — 本計畫的終極目標，旨在透過[[淨零轉型]]與[[智慧城市]]建設，實現環境、社會與經濟的長期平衡發展。
[[SDG4]] — 確保有教無類、公平以及高品質的教育，及提倡終身學習。本計畫透過[[人才培育]]、課程開設及[[科普推廣]]，提升[[電動運具]]與[[淨零轉型]]相關知識與技能。
[[SDG9]] — 建立具有韌性的基礎建設，促進包容且[[永續發展]]的工業，並推動創新。本計畫透過[[智慧綠色運輸]]系統研發、[[產學合作]]及[[電動運具]]產業[[人才培育]]，支持產業創新與基礎建設升級。
[[SDG11]] — 建立具包容、安全、韌性及[[永續發展]]的城市與人類住居。本計畫透過[[智慧城市]]概念、[[電動運具]]推廣及[[在地連結]]，促進城市[[綠色運輸]]與[[淨零轉型]]，提升城市[[永續發展]]韌性。
[[高雄市]] — 本計畫的主要實踐場域，透過在[[燕巢區]]、[[大社區]]及[[駁二藝術特區]]等地的活動，深化對地方的影響。
[[燕巢區]] — [[高雄市]]的實踐場域之一，設有[[電動運具科普推廣據點]]。
[[大社區]] — [[高雄市]]的實踐場域之一，設有[[電動運具科普推廣據點]]。
[[駁二藝術特區]] — [[高雄市]]的重要文化場域，曾舉辦[[電動運具]][[科普推廣]]活動。
[[楠梓產業園區]] — 重要的產業合作夥伴，提供產學實習機會。
[[橋頭科學園區]] — 計畫響應其[[電動運具]]產業聚落發展，作為[[淨零轉型]]的區域策略。
[[樹德科技大學]] — 本計畫的執行學校，整合校內外資源推動[[智慧城市]]與[[淨零轉型]]相關[[大學社會責任]]實踐。
[[高雄高工]] — 合作夥伴，共同辦理全國教師[[電動運具]]研習營，推動技職教育[[人才培育]]。
[[台灣網路智能學會]] — 合作夥伴，共同舉辦[[電動運具]]發展新知座談會。
[[高雄市交通局]] — 合作夥伴，共同辦理[[電動巴士]]防災座談會，推動[[綠色運輸]]政策。
[[高雄市區公車聯管會]] — 合作夥伴，共同辦理[[電動巴士]]防災座談會。
[[車輛研究測試中心 (ARTC)]] — 產業合作夥伴，共同辦理[[人才培育]]課程，提升專業技術。
[[亞東通信工業]] — 產業合作夥伴，捐贈智能充電樁，支持[[電動運具]]基礎設施建設。
[[永盛車電公司]] — 產業合作夥伴，捐贈教學圖書，支持[[電動運具]][[人才培育]]。
[[高雄市西區扶輪社]] — 在地社群合作夥伴，共同辦理[[科普推廣]]活動，擴大社會影響力。
[[高雄市教育局]] — 合作夥伴，參與新興科技教育遠距示範服務計畫，進行[[電動運具]]教案編審。
