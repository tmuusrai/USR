# 三生有興：大學與社區的在地共創計畫

| 欄位 | 內容 |
|------|------|
| 執行學校 | 國立臺東大學 |
| 計畫類型 | 萌芽型 |
| SDG 關聯 | [[SDG3]]、[[SDG11]]、[[SDG12]] |
| 計畫議題 | [[在地關懷]]、[[地方創生]]、[[高齡照護]]、[[食農教育]]、[[循環經濟]] |
| 實踐場域 | [[臺東縣]]、[[臺東市]]、[[建農里]] |

## 執行目標

本計畫旨在以[[課程驅動社會實踐]]模式，將大學教學、研究與在地實踐整合，透過[[學門跨域]]與[[場域跨界]]的協作網絡，促進[[臺東縣]][[建農里]]的[[在地安居]]與[[社區賦權]]，並以[[永續發展]]目標為指引，解決在地公共問題。

## 主要活動與成果

-   **[[課程驅動社會實踐]]機制建立：** 建立「課程界定公共問題、場域驗證行動路徑、行政制度固化回饋」的滾動修正模式，將USR從「活動管理」升級為「[[知識治理]]」。
-   **[[食農技術]]與社會應用：**
    -   發展[[在地知識]]：[[樹豆]]零農廢技術鏈（採收、資材循環、育苗定植、莖/根加工）。
    -   將技術轉譯為[[復健型菜園]]的植物選單與低資材工法，支援長者日常[[健康促進]]。
-   **[[社會設計]]工具化：**
    -   開發多款桌遊、教案與心理測驗網站，並經「可理解性／可操作性／場域適配度」檢核。
    -   推動教材[[二次使用]]，使外部夥伴成為教材共作者。
-   **[[健康促進]]落地：**
    -   據點連續進場，完成多場[[樂齡活動]]、教學方案與同儕觀課機制，提升長者社交與參與度。
    -   將[[休閒治療]]轉化為服務模型，透過「需求評估—帶領—同儕觀課—反思修正」迭代。
-   **科學與治理底盤：**
    -   建立「田間問題—實驗鑑定—回田報告」證據鏈，導入禁限用藥辨識與[[生物防治]]（如Bacillus amyloliquefaciens H3）。
    -   降低[[分子病理]]學參與門檻，強化[[農安]]。
-   **文化與公共敘事：**
    -   透過心智圖、案例討論與音樂演出增進[[社群凝聚]]，並以[[美感教育]]強化[[世代連結]]。
    -   舉辦與[[馬來西亞拉曼大學]]的[[跨國工作坊]]，擴大公共對話與比較視角。
-   **國際合作與擴散：**
    -   與[[馬來西亞拉曼大學]]規劃雙聯學位、暑期田野與實習，建構可複製、可擴散的USR行動系統。
    -   將地方經驗轉譯為[[跨文化對話]]與制度設計的能力指標。
-   **成效評估機制：** 採用「投入—活動—產出—成效」邏輯模式，透過參與人次、作品數量、觀課紀錄、學習札記、展演、焦點訪談、SOP化、二次使用率與場域採納度進行滾動循環評估。

## 核心概念與連結

[[臺東縣]] — 本計畫實踐的地理範圍。
[[臺東市]] — 本計畫實踐的鄉鎮市區。
[[建農里]] — 本計畫的核心實踐場域。
[[在地關懷]] — 計畫的核心議題，關注在地社區的發展與福祉。
[[地方創生]] — 透過大學與社區共創，促進地方發展與活力。
[[高齡照護]] — 透過復健型菜園、健康促進活動等，提升長者健康與生活品質。
[[食農教育]] — 發展在地食農技術，並應用於健康促進與社區教育。
[[循環經濟]] — 實踐零農廢技術，促進資材循環利用。
[[SDG3]] — 透過健康促進、高齡照護等活動，促進良好健康與福祉。
[[SDG11]] — 致力於[[永續城鄉]]與社區發展，提升在地安居品質。
[[SDG12]] — 透過零農廢技術與資材循環，推動負責任的消費及生產。
[[馬來西亞拉曼大學]] — 本計畫的國際合作夥伴。
[[課程驅動社會實踐]] — 本計畫的核心運作機制，將教學與實踐緊密結合。
[[學門跨域]] — 整合不同學術領域（公共與文化、社會設計、運動與健康、美感教育、植物病理等）的專業知識。
[[場域跨界]] — 串聯大學與在地NPO、關懷據點、小農與設計團隊等不同場域夥伴。
[[青銀共創]] — 透過樂齡活動、復健型菜園等，促進不同世代的共同參與與學習。
[[社區陪伴]] — 透過據點進場、健康促進落地等活動，長期陪伴社區居民。
[[在地知識]] — 發展[[樹豆]]零農廢技術鏈等，累積在地特有的技術與經驗。
[[永續發展]] — 以SDGs為指引，追求環境、社會與經濟的長期平衡發展。
[[社區賦權]] — 透過學習型社區模式，提升在地社區自主解決問題的能力。
[[健康促進]] — 透過多元活動與方案，提升社區居民（特別是長者）的健康水平。
[[社會設計]] — 將複雜議題轉化為可操作的工具（桌遊、教案、網站），促進社會參與。
[[生物防治]] — 應用科學方法（如Bacillus amyloliquefaciens H3）進行病蟲害管理，減少化學農藥使用。
[[世代連結]] — 透過美感教育、樂齡活動等，促進不同世代之間的互動與理解。
[[跨文化對話]] — 與國際夥伴（如拉曼大學）交流，將地方經驗轉譯為跨文化視角。
[[知識治理]] — 將USR從一次性動員轉變為以真問題牽引、多源證據校準、制度化回饋的系統性知識產出。
