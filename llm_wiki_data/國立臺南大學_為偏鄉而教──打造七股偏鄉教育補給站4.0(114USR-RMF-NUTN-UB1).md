# 為偏鄉而教──打造七股偏鄉教育補給站4.0

| 欄位 | 內容 |
|------|------|
| 執行學校 | 國立臺南大學 |
| 計畫類型 | 大學特色類深耕型 |
| SDG 關聯 | [[SDG4]]、[[SDG10]]、[[SDG11]] |
| 計畫議題 | [[在地關懷]]、[[永續教育]] |
| 實踐場域 | [[臺南市]]、[[七股區]]、[[七股區十所國小]] |

## 執行目標

本計畫旨在透過[[深耕偏鄉永續教育]]，優化[[師資培育]]人才、彰顯[[偏鄉特色]]、翻轉學生學習、締造共好價值。核心目標為[[人才培育永續]]、[[校園文化永續]]及[[教育價值永續]]，期能將偏鄉教育實踐制度化、永續化，並成為大學服務社會的參考案例。

## 主要活動與成果

-   **課程與教材研發**：
    -   協助[[篤加國小]]自主發展縱貫六個年級的系列性[[戶外教育課程]]，並與[[南大師資生]]共備教材。
    -   辦理6場[[SDGs融入統整性探究課程]]，使[[篤加國小]]入圍2025年第五屆[[台灣地域振興大賞]]教育創生組。
    -   規劃[[地方本位環境教育課程]]，辦理4場96小時[[環境教育營隊]]及24小時[[自然科學營隊]]，並發展3件校本特色教材。
    -   協助[[大文國小]]推動[[綠色能源教學]]。
    -   完成「濱海植物研究」、「島嶼的永續智慧學習之旅」共6單元模組課程，引導學校申請教育部計畫。
-   **師資培育與專業增能**：
    -   強化[[偏鄉師資培育微學程]]教學品質，邀請偏鄉學校師長協同開課，深化[[場域教學]]。
    -   新開設[[社會情緒學習]]課程，培養師資生情緒調節與特殊生輔導能力，114年開設17門課程，799位學生修課，教學滿意度平均達4.5分。
    -   建構[[城鄉教師合作平台]]，推動[[戶外教育]]與[[專業交流]]，促進[[跨校共備]]與[[專業增能]]。
    -   因計畫推廣，師資生投入偏鄉服務人數日增，114年累計16人至偏遠學校進行半年教育實習，其中包含2位公費生及2位至[[七股區光復實小]]實習。
-   **學生學習與輔導**：
    -   推動[[偏鄉自主學習計畫]]，輔導學生完成11案，並辦理成果發表會1場。
    -   強化[[個別化教學輔導]]，建置30例偏鄉特殊學童學習困難案例，本校學生參與達330人次，受輔學生輔導時數達1728小時。
    -   強化[[科技輔助適性化學習]]，以[[英語科技跨領域營隊]]方式推動偏鄉學校科技教育，114年辦理暑期營隊共6場。
-   **場域深化與行動擴展**：
    -   延伸服務至[[關廟區]]、[[將軍區]]、[[北門區]]，合作偏鄉小校包括[[文和國小]]、[[鯤鯓國小]]、[[長平國小]]、[[三慈國小]]。
    -   積極與在地光電媒合，協助[[七股區樹林國小]]獲87,800元電協金補助，用於[[機器人教室]]開拓計畫。
    -   啟動「[[七股校園復原行動]]」，於丹娜絲颱風重創[[臺南市]]七股時，立即協助清理校園，展現對在地場域問題的即時行動力。
-   **計畫榮譽與永續**：
    -   榮獲2025年第六屆《[[遠見]]》USR大學社會責任獎[[人才共學組]]「楷模獎」，展現[[成果永續]]。
    -   透過[[PDCA]]檢核表、課程品保、自主學習推動、教材研發、個別化教學、多元展能及校務分析等機制，確保計畫品質與[[永續發展]]。
