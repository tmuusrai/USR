# 田寮區

## 定義與背景

[[田寮區]]是[[高雄市]]重要的[[USR]]實踐場域之一，以其獨特的[[月世界]]惡地地貌與淺山環境聞名。此區域同時面臨[[人口老化]]及[[產業轉型]]等挑戰，成為大學[[USR]]計畫關注[[地方創生]]與[[永續發展]]的焦點。其地理與社會特性，為多元的[[USR]]實踐提供了豐富的脈絡。

## 主要實踐樣貌

*   整合[[惡地]]地景與[[生態]]資源，建構[[區域韌性]]與[[綠色網絡]]，促進[[共融淺山生活圈]]。
*   推動[[在地產業轉型]]，特別是[[畜產業]]的創新發展，如[[古力豬]]品牌建立與[[農產新食力]]。
*   關注[[高齡化社會]]議題，透過[[山城農村協進會]]與[[老人福利協進會]]，促進[[社區共榮]]與[[老人福利]]。
*   發展[[在地永續人才培育]]，並將[[科學教育]]擴展至[[偏鄉]]學校，如[[田寮國中]]。
*   協助[[農村]]與[[山城]]地區的[[永續城鄉]]發展，促進[[產業轉型]]與[[在地永續]]。

## 核心連結概念

*   [[惡地地貌]]：[[田寮區]]最顯著的地理特色，為[[USR]]計畫提供獨特的[[生態]]與[[文化]]場域。
*   [[產業轉型]]：因應[[人口老化]]與[[地方創生]]需求，[[畜產業]]等在地產業面臨轉型挑戰與機會。
*   [[在地永續人才培育]]：透過教育與培力，提升在地居民能力，促進[[地方發展]]與[[永續]]。
*   [[區域韌性]]：在[[惡地]]淺山環境中，建構面對環境變遷與社會挑戰的[[共融淺山生活圈]]能力。
*   [[高齡化社會]]：[[田寮區]]面臨的社會議題，促使[[USR]]計畫關注[[老人福利]]與[[社區照顧]]。
