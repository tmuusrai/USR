# 食農教育

## 定義與背景

「食農教育」在[[台灣]] [[USR]] 脈絡中，核心在於透過多元活動與課程，提升大眾對食物來源、農業生產、環境永續及[[在地文化]]的認識與連結。其旨在推廣[[環境友善]]的農業實踐，促進[[健康飲食]]與[[食品安全]]，並最終達成[[永續發展]]的目標。此概念強調從產地到餐桌的全面理解，培養公民的[[生態意識]]與[[負責任的消費及生產]]觀念。

## 主要實踐樣貌

*   **農耕實作與體驗：** 透過實際栽種[[原民作物]]、[[阿里山油菊]]、黑豆或[[有機作物]]，讓參與者親身體驗農業生產過程，連結食物與土地。
*   **課程與活動設計：** 運用桌遊、繪本、工作坊、遊程及[[跨域課程]]，將[[食農知識]]融入教學，例如菇類生產、[[在地食材]]菜單設計、[[地酒原料]]認識。
*   **社區與高齡參與：** 結合[[青銀共耘]]、[[長輩關懷]]及[[高齡健康促進]]，透過[[在地食農技術]]發展與推廣，促進社區[[社會支持網絡]]與[[健康促進]]。
*   **永續與惜食推廣：** 實踐[[慢食行動]]、[[惜食教育]]，推廣[[永續消費與生產]]觀念，並連結[[國小營養午餐]]，改善[[學校午餐品質]]。
*   **文化與在地連結：** 結合[[在地文化]]、[[民族植物]]、[[馬卡道文化]]及[[台灣地酒文化]]，深化對[[在地知識]]與[[飲食文化]]的理解。
*   **智慧科技應用：** 將[[智慧農業]]技術融入[[食農教育]]課程，提升對農業環境的認識，並促進[[農業數位轉型]]與[[產業創生]]。

## 核心連結概念

*   [[永續發展]]：食農教育是實現[[永續農業]]、[[零飢餓]]及[[負責任的消費及生產]]的重要途徑。
*   [[健康飲食]]與[[食品安全]]：透過推廣[[在地食材]]、[[高齡適口性飲食]]及[[食品安全管理]]，提升民眾飲食知識與健康。
*   [[環境友善]]與[[生態保育]]：強調[[環境友善]]的農業實踐，提升[[生態意識]]，並與[[生態保育]]、[[公民科學]]結合。
*   [[在地文化]]與[[地方創生]]：作為[[文化永續]]與[[地方創生]]的核心，連結[[在地知識]]、[[飲食文化]]與社區發展。
*   [[人才培育]]與[[教育品質]]：透過[[跨域課程]]、[[職能培訓]]與[[蒙特梭利教育]]，提升[[教育品質]]並培育[[綠領人才]]。
*   [[智慧農業]]：將[[智慧農業]]技術融入教學與實踐，促進[[農業數位轉型]]與[[產業創生]]。
