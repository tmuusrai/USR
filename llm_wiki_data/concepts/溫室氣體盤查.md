# 溫室氣體盤查

## 定義與背景

在[[台灣]] [[USR]] 脈絡中，[[溫室氣體盤查]]是評估與管理[[碳排放]]的科學方法，為量化[[減碳]]成效、推動[[淨零]]目標及評估[[環境影響]]的核心工具。它不僅是技術實踐，更是[[永續發展]]與[[環境韌性]]建構的基礎，廣泛應用於[[在地社區]]、[[產業]]及[[校園]]的[[淨零轉型]]。

## 主要實踐樣貌

*   量化[[減碳]]成效與[[碳足跡分析]]，支持[[在地社區農業碳中和]]等目標。
*   強化[[永續發展課程]]中[[人才培育]]，提升學生[[職涯發展]]與[[永續領域]]專業基礎，例如講授[[溫室氣體盤查理論]]、[[法規]]與[[碳管理產業]]人才需求。
*   協助[[產業]]進行[[碳足跡管理]]，降低[[碳排]]，邁向[[淨零]]目標，如[[雲林地區家禽羽毛廢棄物資源循環再生]]。
*   作為[[碳經濟]]實踐的科學基礎，支持[[永續消費]]與[[韌性社區]]建構。
*   評估[[綠生農場]]等場域的[[環境影響]]，推動[[淨零轉型]]與[[文化永續]]。

## 核心連結概念

*   [[碳足跡分析]] / [[碳足跡管理]]：透過盤查結果，進一步分析產品或服務的生命週期碳排放。
*   [[淨零]] / [[淨零轉型]] / [[淨零碳排]]：盤查是達成這些終極目標的基礎步驟，用以衡量進度。
*   [[減碳]]：盤查提供量化依據，以評估減碳策略的成效。
*   [[碳經濟]]：將碳排放數據納入經濟活動考量，推動[[永續消費]]與[[碳權]]交易。
*   [[人才培育]] / [[永續發展課程]]：將盤查理論與實務納入教學，培養[[永續領域]]專業人才。
*   [[環境影響評估]]：作為評估特定計畫或場域環境衝擊的重要指標。
