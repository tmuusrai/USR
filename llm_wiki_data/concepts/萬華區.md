# 萬華區

## 定義與背景

[[萬華區]]是[[臺北市]]歷史悠久的行政區，在[[台灣大學社會責任]]（USR）實踐脈絡中，被視為重要的[[在地實踐場域]]。由於其獨特的[[人口結構]]與[[社區發展]]特性，[[萬華區]]成為多所大學推動[[高齡化社會]]議題（如[[青銀共好]]、[[健康促進]]、[[安寧照護]]、[[孤獨處方箋]]）及[[青少年培力]]等計畫的核心區域。其豐富的[[社區資源]]與明確的[[社會需求]]，使其成為大學與地方共創[[永續發展]]的關鍵節點。

## 主要實踐樣貌

*   **[[青少年培力]]與[[科技共創]]**：透過[[共學]]、[[共玩]]、[[共創]]模式，提升[[青少年]]的[[數位素養]]與[[創新能力]]。
*   **[[青銀共好]]與[[健康促進]]**：推動[[跨世代交流]]，促進[[高齡者]]與[[青年]]的[[身心健康]]，建立[[永續健康]]的[[社區網絡]]。
*   **[[醫養結合]]與[[高齡照護]]**：結合[[醫療]]與[[長照]]資源，發展[[社會處方箋]]，提供[[高齡者]]全面的[[健康增齡]]服務，並關注[[安寧終老]]與[[孤獨處方箋]]等議題。
*   **[[社區據點]]深耕**：以[[華江里]]、[[莒光健康增齡賦能中心]]等[[社區據點]]為核心，進行[[在地服務]]與[[資源鏈結]]。

## 核心連結概念

*   **[[高齡化社會]] / [[超高齡社會]]**：[[萬華區]]作為[[臺北市]]高齡人口比例較高的區域，是探討[[高齡化]]挑戰與機會的重要場域。
*   **[[青銀共好]]**：強調[[跨世代合作]]與[[共融]]，是多項USR計畫的核心目標。
*   **[[社區健康]] / [[健康促進]]**：透過[[醫養結合]]與[[在地服務]]，提升居民的[[健康福祉]]。
*   **[[社會處方箋]]**：一種創新的[[健康服務模式]]，旨在透過非藥物介入改善[[社區健康]]。
*   **[[在地實踐]] / [[場域深耕]]**：USR計畫強調大學與地方的深度連結，將[[萬華區]]視為長期投入的[[實踐場域]]。

## 代表性計畫與學校

*   **中國文化大學** — 青少年培力：共學、共玩、共創科技新未來
*   **國立臺北護理健康大學** — 鏈結資源永續健康-「北護護你健康、青銀共好深耕計畫」
*   **國立臺灣大學** — 超高齡社會幸福學──在地青銀共好實踐
*   **臺北市立大學** — 醫養結合與高教的視域的融合與擴散：建構社會處方箋與連結工作者創新研發基地
*   **臺北醫學大學** — 第三人生的創新提案：超高齡社會的孤獨處方箋
