# SROI

## 定義與背景

[[社會投資報酬率]]（SROI）在台灣 [[USR]] 脈絡中，是一種廣泛採用的評估框架與量化工具。它旨在衡量並呈現大學社會責任計畫所創造的[[社會影響力]]、[[社會效益]]與[[永續發展]]價值，將非財務成果貨幣化，以科學化方式檢視資源投入的效益。

## 主要實踐樣貌

*   量化計畫成果與[[永續發展]]效益，作為[[成效評估機制]]。
*   評估計畫[[社會影響力]]與價值，將非財務成果貨幣化，並優化[[專案設計]]。
*   衡量計畫所產生的社會、環境與經濟價值，確保資源運用效率。
*   評估[[利害關係人]]的實質影響力與計畫的[[社會價值]]。
*   提供客觀數據驗證模式，以評估對在地[[永續發展]]的貢獻。

## 核心連結概念

*   [[社會影響力]]：SROI的核心評估對象，旨在量化與質化計畫對社會的改變。
*   [[永續發展]]：SROI常被用於衡量計畫對環境、社會及經濟層面永續性的貢獻。
*   [[社會效益]]：SROI透過將非財務成果貨幣化，具體呈現計畫所創造的社會價值。
*   [[成效評估機制]]：SROI是[[USR]]計畫中用以檢視資源投入與成果轉化的重要工具。
*   [[利害關係人]]：SROI分析過程中，需考量計畫對不同[[利害關係人]]群體的影響。
