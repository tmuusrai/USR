# 世代交流

## 定義與背景

在[[台灣]] [[USR]] 脈絡中，[[世代交流]] 旨在促進不同年齡層之間的互動、理解與合作，以打破[[世代隔閡]]。其核心目標是透過[[大學]]的資源與專業，推動[[知識與文化傳承]]、[[技能傳承]]，並共同解決[[高齡社會]]等當代社會議題，實踐[[大學社會責任]]。

## 主要實踐樣貌

*   透過[[青銀共學]]或[[跨世代共學]]課程與活動，促進不同世代間的理解與合作。
*   學生參與[[社區實作]]，與[[長者]]互動，提供[[專業培力]]並提升[[社會責任]]。
*   與[[部落耆老]]合作，進行[[知識與文化傳承]]，並結合[[地方創生]]與[[青創培力]]。
*   引導[[長者]]參與[[手作活動]]（如舊衣製作），增進[[認知功能]]、[[成就感]]與[[技能傳承]]。
*   促進不同年齡層的互動與理解，共同創造[[長者幸福人生]]。

## 核心連結概念

*   [[青銀共學]]：最直接的實踐形式，透過共同學習促進理解與合作。
*   [[跨世代共學]]：與[[青銀共學]]相似，強調不同世代間的共同學習與合作。
*   [[知識與文化傳承]]：透過世代交流，將傳統智慧與文化經驗傳遞給年輕一代。
*   [[技能傳承]]：在實作活動中，促進不同世代間的技能交流與學習。
*   [[高齡社會]]：世代交流是應對[[超高齡社會]]挑戰、解決[[長者孤獨]]的重要策略。
*   [[大學社會責任]]：透過世代交流，[[大學]]實踐其對社會的承諾與貢獻。

## 代表性計畫與學校

*   **[[國立中正大學]]** — 共創長者幸福人生:科際整合人權實踐方案
*   **[[國立宜蘭大學]]** — 大南澳地區實踐青創培力與六級化發展
*   **[[國立臺北護理健康大學]]** — 足感心～全方位樂齡關懷培力計畫
*   **[[國立臺灣師範大學]]** — 時光共融：高齡長健與跨世代共學計畫
*   **[[臺北醫學大學]]** — 第三人生的創新提案：超高齡社會的孤獨處方箋
