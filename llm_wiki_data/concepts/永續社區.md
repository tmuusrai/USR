# 永續社區

## 定義與背景

在台灣 [[USR]] 脈絡中，[[永續社區]] 是一個核心目標，旨在透過大學的專業知識與在地資源結合，建構具備社會、經濟、環境與文化韌性的社區。它不僅回應了聯合國 [[永續發展目標]] (SDGs) 中「[[永續城市及社區]]」的精神，更是大學實踐[[社會責任]]、促進[[地方創生]]的具體展現。

## 主要實踐樣貌

[[永續社區]] 的實踐樣貌多元，主要透過以下面向達成：

*   **文化傳承與發展**：促進[[在地知識]]傳承、[[文化發展]]與[[文化永續]]，如[[原民技藝文化推廣]]、活化[[西港慶安老屋]]。
*   **高齡健康與福祉**：推動[[在地老化]]、[[活躍老化]]、[[高齡友善]]空間改善，建立[[健康促進]]與[[智慧照護]]模式，實現[[青銀共好]]。
*   **地方創生與經濟活化**：結合[[地方創生]]策略，發展特色產業如[[音樂×農業]]市集，提升社區經濟活力。
*   **環境友善與防災韌性**：致力於[[環境友善]]、[[自主防災]]能力的建構，並透過[[公民參與]]共護在地生態環境，如[[頭前溪]]。
*   **社區陪伴與公民參與**：透過[[社區陪伴]]與[[公民參與]]機制，強化居民的[[健康素養]]與[[自我照護能力]]，共同建構具[[韌性]]的社區。

## 核心連結概念

*   **[[地方創生]]**：透過活化在地產業、吸引人才回流，為[[永續社區]]注入經濟與社會活力。
*   **[[高齡友善]]**：在超高齡社會背景下，建構適合長者居住、活動的環境與服務，是[[永續社區]]的重要面向。
*   **[[文化永續]]**：保存與推廣在地文化資產，強化社區認同與凝聚力，是[[永續社區]]韌性的基石。
*   **[[社區陪伴]]**：大學與社區建立長期合作關係，提供專業支持與資源，促進社區自主發展。
*   **[[韌性]]**：指社區面對挑戰時的適應與恢復能力，是[[永續社區]]追求的最終狀態。
