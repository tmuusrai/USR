# 生態復育

## 定義與背景
在[[台灣大學社會責任]]（USR）的脈絡中，[[生態復育]]是指透過系統性的介入，恢復受損或退化的[[生態系統]]，使其恢復原有的功能與服務。這不僅是為了提升[[環境韌性]]與[[永續發展]]，更是回應[[氣候變遷]]挑戰，並促進在地[[社區]]與[[自然環境]]共榮共存的關鍵實踐。

## 主要實踐樣貌
[[生態復育]]在USR計畫中展現多元的實踐方式，旨在達成環境永續與地方共榮：
*   **提升環境韌性與自我恢復能力**：如針對特定[[流域]]（例：[[種瓜溪流域]]）進行復育，強化其面對環境變遷的抵禦與恢復力。
*   **兼顧[[物種多樣性]]與[[森林保護]]**：透過[[山林守護]]與[[森林保護]]行動，確保[[生態系統]]的完整性與生物多樣性，並需長期投入。
*   **結合[[社區參與]]與跨域合作**：強調[[社區]]在復育過程中的參與，並結合[[綠色設計]]、[[循環經濟]]等思維，促進整體環境永續。
*   **連結[[碳經濟]]與[[森林碳匯]]潛力**：探討[[森林碳匯]]在[[氣候治理]]中的角色，將[[生態復育]]與[[碳權交易]]、[[碳經濟]]發展結合，創造環境與經濟雙贏。

## 核心連結概念
*   [[環境韌性]]：提升[[生態系統]]面對環境變遷的適應與恢復能力。
*   [[永續發展]]：追求環境、社會與經濟的長期平衡與共榮。
*   [[物種多樣性]]：維護[[生態系統]]中生物種類的豐富性與平衡。
*   [[山林守護]] / [[森林保護]]：透過保育行動維護[[森林]]生態的健康與功能。
*   [[社區參與]]：鼓勵在地居民投入[[生態復育]]與環境管理。
*   [[碳經濟]] / [[森林碳匯]]：將[[森林]]吸收二氧化碳的能力轉化為經濟價值，應對[[氣候變遷]]。
*   [[流域治理]]：針對特定水域生態系統進行整體規劃與復育。
