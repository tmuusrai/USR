# 新市區

## 定義與背景
[[新市區]]是[[臺南市]]的一個行政區，在台灣[[大學社會責任]]（USR）實踐脈絡中，常作為大學與在地社區合作的核心場域。它代表了大學將學術資源與專業知識導入地方，推動[[在地關懷]]與[[永續發展]]的具體實踐基地。

## 主要實踐樣貌
在[[新市區]]的USR實踐主要體現於以下面向：
*   **社區文化與記憶活化**：透過[[在地關懷]]與[[共學共創]]，點亮社區美好記憶，促進地方認同與發展。
*   **高齡健康與福祉**：與[[永就社區發展協會]]、[[大社社區發展協會]]、[[社內社區發展協會]]等在地組織合作，推動[[高齡咀嚼健康餐飲]]與[[肌力增進]]等創新服務。
*   **淨零永續城市實踐**：在[[社內里]]、[[永就里]]、[[大營里]]等社區，實踐[[淨零永續城市]]的理念，推動環境友善與永續發展。

## 核心連結概念
*   [[臺南市]]：[[新市區]]所屬的行政區域，為計畫提供地理與行政背景。
*   [[社區發展協會]] / [[里]]：大學USR計畫在[[新市區]]進行在地實踐時，不可或缺的在地合作夥伴。
*   [[在地關懷]]：USR計畫的核心精神，強調對地方議題的關注與投入。
*   [[高齡照護]] / [[健康促進]]：針對[[新市區]]高齡人口的具體服務面向。
*   [[永續發展]] / [[淨零城市]]：USR計畫在[[新市區]]推動環境友善與未來發展的目標。
