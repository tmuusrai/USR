# 利害關係人

## 定義與背景

在台灣 [[USR]] 脈絡中，「利害關係人」泛指所有與大學社會責任計畫相關、受其影響或其參與對計畫成敗至關重要的個人或群體。他們是 [[USR]] 計畫得以推動、深化 [[社會影響力]] 並達成 [[永續發展]] 目標的核心。透過識別與 engagement，大學能確保計畫的 [[成效評估]] 更為全面且具代表性。

## 主要實踐樣貌

*   **計畫互動與合作對象**：作為 [[USR]] 計畫直接互動、共同參與的夥伴，例如 [[國立臺灣海洋大學]] 的養殖戶、漁民、村長，或 [[德明財經科技大學]] 的公益團體、紡織企業。
*   **計畫成效評估對象**：其意見、滿意度或所受影響是衡量計畫成果的關鍵指標，如 [[元智大學]] 的長者、學生、教師，及 [[靜宜大學]] 收集意見的對象。
*   **計畫影響的各方群體**：包含受計畫直接或間接影響的廣泛社群，如 [[東海大學]] 的社區居民、公部門、企業，或 [[國立臺北大學]] 的社會大眾。
*   **意見與參與關鍵群體**：其觀點和投入對計畫方向與成功至關重要，如 [[實踐大學]] 強調的各方群體，以及 [[德明財經科技大學]] 關注的參與和滿意度。
*   **社會價值評估標的**：作為 [[社會投資報酬率分析方法]] 中，評估實質影響力與社會價值的對象，如 [[弘光科技大學]] 的應用。

## 核心連結概念

*   [[USR]]：利害關係人是大學社會責任實踐的基石，確保計畫回應真實社會需求。
*   [[成效評估]]：透過收集利害關係人的意見與滿意度，全面衡量計畫的達成度與影響。
*   [[社會影響力]]：利害關係人是計畫產生正面影響的直接受益者或參與者，其改變是影響力的體現。
*   [[永續發展]]：與利害關係人的長期合作與共創，是確保計畫成果能持續發展的關鍵。
*   [[社區參與]]：許多 [[USR]] 計畫的利害關係人即是社區居民、在地組織，其參與是社區共榮的基礎。
*   [[社會投資報酬率]]：一種量化利害關係人所獲益處，以評估計畫社會價值的工具。
