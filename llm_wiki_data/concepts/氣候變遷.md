# 氣候變遷

## 定義與背景

在[[台灣大學社會責任]]（USR）脈絡中，[[氣候變遷]]被視為對[[環境]]、[[社會]]與[[經濟]]構成深遠挑戰的核心議題。USR計畫旨在透過跨領域合作，提升[[社區]]、[[產業]]及[[個人]]應對[[氣候變遷]]衝擊的[[韌性]]與[[調適能力]]，並積極推動[[減碳]]與[[淨零]]轉型。

## 主要實踐樣貌

*   **意識提升與環境教育：** 舉辦[[國際論壇]]、[[青年氣候行動團]]、將[[氣候變遷]]議題融入[[社區]]課程，提升[[環境意識]]與[[環境關懷]]。
*   **減緩與淨零排放：** 推廣[[太陽光電]]、[[節能減碳]]、[[藍碳固碳]]、[[混農林業]]提升[[碳匯]]，並透過[[廢棄物資源循環再生]]實現[[減碳]]與[[淨零]]目標。
*   **調適與韌性建構：** 協助[[文化遺產]]、[[農業]]、[[沿海社區]]建立[[環境韌性]]，導入[[碳盤查]]與[[感測系統]]，並透過[[防災地圖]]、[[災害回報系統]]強化[[社區]]因應[[氣候變遷]]與災害的能力。
*   **永續農法與產業轉型：** 推廣[[微生物農法]]、[[自然農法]]，協助[[農業]]（如[[花卉產業]]）在[[氣候變遷]]下進行[[永續轉型]]，減少環境負擔。
*   **跨域合作與治理：** 促進[[青銀共創]]、[[社區協力平台]]，協助[[企業]]與[[醫院]]建立應對[[氣候變遷]]風險與機會的能力，並推動[[水資源治理]]。

## 核心連結概念

*   [[減碳]] / [[淨零]] / [[低碳]]：透過多種策略減少溫室氣體排放，達成永續發展目標。
*   [[韌性]] / [[調適]]：指面對[[氣候變遷]]衝擊時，[[社區]]、[[產業]]或[[生態系統]]的恢復與應變能力。
*   [[永續]]：強調環境、社會與經濟的平衡發展，確保後代福祉。
*   [[環境教育]]：透過課程、活動等方式，提升大眾對[[氣候變遷]]議題的認識與行動力。
*   [[社區]]：USR計畫常以在地[[社區]]為實踐場域，共同面對[[氣候變遷]]挑戰。
*   [[農業]]：[[氣候變遷]]對[[農業]]影響深遠，USR計畫致力於推動[[永續農法]]與[[產業調適]]。
*   [[碳匯]] / [[碳盤查]]：評估與提升自然或人為系統吸收[[碳排放]]的能力，並量化其碳足跡。
*   [[綠能]] / [[太陽光電]]：發展與應用再生能源，作為[[減碳]]的重要途徑。

## 代表性計畫與學校

*   **國立彰化師範大學** — 韌性彰濱 :氣候變遷下彰化濱海環境與產業永續計畫
*   **國立成功大學** — 曾文溪的美麗與哀愁：從水文與人文歷史、特色產業、到人工智慧數位永續系統的建置與驗證
*   **國立政治大學** — 韌性山村 • 永續翡翠
*   **國立清華大學** — 清華大學環境韌性與永續地方創生計畫
*   **弘光科技大學** — 共築中部沿海里仁淨零之美 深耕低碳+韌性+永續家園
