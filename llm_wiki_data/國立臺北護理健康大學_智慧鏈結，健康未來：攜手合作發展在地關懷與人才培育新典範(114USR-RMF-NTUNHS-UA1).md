# 智慧鏈結，健康未來：攜手合作發展在地關懷與人才培育新典範

| 欄位 | 內容 |
|------|------|
| 執行學校 | 國立臺北護理健康大學 |
| 計畫類型 | 大學特色類萌芽型 |
| SDG 關聯 | [[SDG3]]、[[SDG4]]、[[SDG8]] |
| 計畫議題 | [[在地關懷]]、[[高齡照護]]、[[幼兒發展]]、[[心理健康]]、[[人才培育]] |
| 實踐場域 | [[臺北市]]、[[北投區]] |

## 執行目標

本計畫旨在透過[[智慧健康管理]]與[[跨域合作]]，提升[[高齡照護]]品質及[[幼兒發展]]環境，並擴展[[心理健康服務]]以支持中壯年族群。同時，透過[[國際交流]]與[[人才培育]]，強化學生專業知能，深化[[在地關懷]]與[[永續發展]]影響力。

## 主要活動與成果

*   **高齡者身心健康促進**：
    *   以[[功能性體適能]]檢測為基礎，結合[[智慧健康管理]]系統，提供[[個別化運動處方]]。
    *   推動肌力、平衡與柔軟度訓練，並舉辦衛教講座，強化長者自我健康管理。
    *   累計辦理多場社區活動，服務逾千人次。
*   **中壯年心理健康支持**：
    *   擴增[[心理健康服務]]，於[[癒心鄉心理諮商中心]]等場域辦理自我探索、溝通、壓力管理、放鬆等主題課程與團體活動。
    *   串聯社區資源，形成支持網絡，提升中壯年族群[[心理健康]]意識。
*   **幼兒感覺統合與動作發展**：
    *   實施[[感覺統合]]與[[動作發展]]主題活動，並舉辦幼保系學生/家長工作坊。
    *   產出可操作應用的活動[[教案開發]]與指引，提升親師對[[幼兒發展]]的理解。
*   **人才培育與國際交流**：
    *   學生由「協助者」進階為「帶領者」，帶領22場社區活動，累積企劃、流程設計、場域引導等能力。
    *   透過[[跨系協作]]培育種子助教，學生完成服務學習與學程修課，精進專業能力與[[在地連結]]。
    *   安排外籍學生參訪、場域導覽與課程觀摩，強化[[多元文化理解]]與[[國際交流]]。
    *   擴充計畫網站內容，製作雙語活動花絮影片，提升計畫能見度。
*   **合作夥伴**：
    *   與[[國立臺北護理健康大學生死與健康心理諮商系系友會]]、[[菲特邦]]、[[盤古銀髮]]、[[華民幼兒園]]、[[童博健康管理工作室]]、[[中華民國玄牝太極健康引導學會]]等單位[[跨界合作]]，提供專業服務與資源。

## 核心概念與連結

[[在地關懷]] — 本計畫深耕[[北投區]]，透過健康促進與[[人才培育]]，致力提升在地居民的生活品質。
[[高齡照護]] — 針對高齡者提供[[功能性體適能]]檢測、[[智慧健康管理]]與[[個別化運動處方]]，促進其身心健康。
[[幼兒發展]] — 透過[[感覺統合]]與[[動作發展]]活動及[[教案開發]]，支持幼兒健康成長並提升親師知能。
[[心理健康]] — 擴展[[心理健康服務]]，提供中壯年族群壓力管理、自我探索等課程，建立社區支持網絡。
[[人才培育]] — 學生從協助者轉變為活動帶領者，透過實作與[[跨系協作]]，提升專業能力與[[在地連結]]。
[[SDG3]] — 良好健康與福祉：本計畫直接透過高齡、中壯年及幼兒的健康促進活動，提升社區整體健康水平。
[[SDG4]] — 優質教育：透過學生參與[[USR]]活動、[[教案開發]]及[[國際交流]]，提供優質的實踐教育與學習機會。
[[SDG8]] — 合宜工作與經濟成長：透過[[人才培育]]與專業技能提升，為學生未來投入健康相關領域奠定基礎。
[[臺北市]] — 本計畫的主要實踐場域，特別是[[北投區]]。
[[北投區]] — 本計畫深耕的在地社區，與多個在地單位協作。
[[癒心鄉心理諮商中心]] — 國立臺北護理健康大學校內場域，提供[[心理健康服務]]。
[[國立臺北護理健康大學生死與健康心理諮商系系友會]] — 合作夥伴，提供心理諮詢及相關活動支援。
[[菲特邦]] — 合作夥伴，提供高齡運動指導等專業資源。
[[童博健康管理工作室]] — 合作夥伴，共同推動幼兒體適能與親子活動。
[[中華民國玄牝太極健康引導學會]] — 合作夥伴，提供場地及教練資源，辦理健康促進專業人力培訓。
[[盤古銀髮]] — 合作夥伴，提供高齡運動指導與認知障礙照護專業課程。
[[華民幼兒園]] — 合作夥伴，共同推動幼兒體適能與親子活動。
[[智慧健康管理]] — 運用科技系統，為高齡者提供個人化的健康監測與運動建議。
[[功能性體適能]] — 評估高齡者日常活動能力的重要指標，本計畫以此為基礎設計運動處方。
[[個別化運動處方]] — 根據高齡者體適能檢測結果，量身打造的運動計畫。
[[心理健康服務]] — 針對中壯年族群提供的心理諮詢、壓力管理與團體活動。
[[感覺統合]] — 幼兒發展的重要環節，本計畫透過主題活動促進其發展。
[[動作發展]] — 幼兒身體活動能力與協調性的發展，本計畫設計活動加以強化。
[[教案開發]] — 學生與教師共同設計活動方案，用於高齡者與幼兒的健康促進。
[[國際交流]] — 邀請國際學生參訪與參與活動，並與南向國家大專院校交流，促進多元文化理解。
[[人才培育]] — 透過實作、課程與[[跨系協作]]，提升學生專業知能與實踐能力。
[[跨域合作]] — 整合校內三系專業教師、研究生及行政人員，並結合校外專業夥伴共同推動計畫。
[[社區陪伴]] — 透過長期且扎實的社區活動推展，建立與在地居民的信任與連結。
[[多元文化理解]] — 透過國際學生參與社區活動，促進不同文化背景的交流與認識。
[[永續發展]] — 本計畫透過建立評估機制與跨部門協作，確保計畫的長期效益與社會影響力。
