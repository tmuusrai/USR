# 環境認知調研與空間裝置實作之社會性實踐-以基隆為行動基地

## 執行目標

本計畫旨在延續前期成果，透過「展演」加深「[[在地成果記憶]]」，並以「[[培力]]」、「[[傳承]]」、「[[永續]]」為軸，引導社區自主轉動。核心目標為透過[[場域創作]]與[[設計共創]]，協助地方空間需求，達成「設計 x 參與 x 共創」整合，並以[[人本環境]]建構為目標，重塑[[基隆市]]的[[委託行街區]]與[[和平島街區]]，帶動地方[[永續發展]]與經濟成長。

## 主要活動與成果

*   **課程實踐與在地連結**：
    *   中華科技大學建築系師生團隊將課堂學習延伸至[[委託行街區]]與[[和平島街區]]的[[空間裝置實作]]，為街區重塑[[人本友善環境]]。
    *   透過[[實際場域操作]]，改變傳統建築設計課程模式，提升學生掌握[[建築經營策略]]與[[業主需求溝通]]能力。
*   **街區願景規劃與設計**：
    *   針對[[委託行街區]]，提出「[[基隆之門]]」整體發展願景，包含六個方案，旨在重塑[[人本友善環境]]，打造「吃、住、玩」的新標的。
    *   針對[[和平島街區]]，以港灣環境改造為題，提升遊客容受力，改善車與人動線，並發展串聯[[和平島地質公園]]、教堂遺址、天后宮、天顯宮等重要節點的[[人本友善環境]]帶狀願景。
    *   和平島內陸區聚焦[[生活機能]]與[[文化脈絡]]活化，提出「山與海之景」、「宿人美景」、「諸聖教堂博物館」、「再建和平島市場」等四個提案。
    *   和平島沿岸區則從海港特色出發，提出複合式港區空間、翻新魚市場與橋頭商店街、設立腳踏車租借與休憩廣場、改造觀海基地等六大空間再造方案。
*   **社區參與與成果展現**：
    *   辦理階段性設計概念作品展示，邀請[[在地知識]]提供者（耆老、專家）共同提供修正建議，確保設計符合[[在地需求]]。
    *   於[[基隆市]]及校內展廳舉辦大型成果展，邀請各級長官、文化及空間發展團體、[[在地居民]]參與活動及票選，為計畫延伸未來合作可能性。
    *   在[[基隆太平山城計畫據點]]（原太平國小）進行展演，深化[[在地擾動]]，促使居民關注地區未來規劃。
    *   創建臉書粉絲頁、發佈媒體與新聞，廣納意見並由學生完整紀錄執行歷程。
*   **知識傳承與評估**：
    *   建造[[和平島街區]]及[[委託行街區]]整體空間模型，協助街區未來發展延伸討論。
    *   碩士研究生協助計畫進行「建築設計場域式課程教學目標與執行歷程之師生對位探討」及「[[SROI]] 檢討模式」研究。
    *   出版成果冊，建立回饋社區共享機制，同步紀錄作業歷程，並以大型圖說解讀設計、大尺度模型提供民眾觀覽。
    *   透過[[社會投資報酬率]]（[[SROI]]）評估，本活動展現具體且具潛力的[[社會價值]]，SROI 達 1:1.85，有效提升民眾對社區現況的理解及學校與社區的連結。

[[SDG9]] — 透過空間裝置實作與設計方案，促進街區產業活化與基礎設施改善。

[[產業創新]] — 透過設計方案與空間改造，帶動街區產業活化與創新。
