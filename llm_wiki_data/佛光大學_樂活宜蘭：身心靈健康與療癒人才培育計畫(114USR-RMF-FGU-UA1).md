# 樂活宜蘭：身心靈健康與療癒人才培育計畫

| 欄位 | 內容 |
|------|------|
| 執行學校 | 佛光大學 |
| 計畫類型 | 萌芽型 |
| SDG 關聯 | [[SDG3]]、[[SDG4]]、[[SDG10]] |
| 計畫議題 | [[健康促進與食品安全]]、[[高齡照護]]、[[地方創生]] |
| 實踐場域 | [[宜蘭縣]]、[[礁溪鄉]]、[[財團法人宜蘭縣私立蘭陽仁愛之家]] |

## 執行目標

本計畫旨在透過[[跨領域合作]]，培育[[身心靈健康]]與[[療癒人才]]，並將專業服務導入[[宜蘭縣]]各[[長照據點]]及社區，以提升在地民眾的[[身心靈全人健康]]，最終將[[宜蘭]]打造成為健康療癒的[[樂活之鄉]]。

## 主要活動與成果

-   **樂活人才培育：**
    -   開設校內學士班與碩士班課程，並提供從業人員進修培訓，提升[[專業素養]]。
    -   成果：[[計畫參與師生]] 303 位，[[從業人員進修參與人數]] 153 人。
-   **樂活社區專業服務：**
    -   以單次服務及長期固定課程模式，將各式[[輔助療法]]與[[健康促進]]課程導入社區及[[長照據點]]，實踐[[社區陪伴]]。
    -   成果：辦理場次 251 場，[[社區服務民眾人數]] 640 位，[[計畫參與師生]] 94 位，[[計畫參與校友業師]] 9 位，[[社區場域夥伴]] 14 位。學生[[實務能力提升]]、[[社會責任感]]增強，並促進[[自我成長]]。
-   **身心靈旅療：**
    -   開發多元[[身心靈旅療]]體驗方案，推廣[[身心靈全人健康]]觀念與方法予一般民眾。
    -   成果：辦理場次 8 場，[[參與民眾人次]] 324 位。
-   **創新亮點：**
    -   提供多元[[輔助療癒]]服務內容，包含[[音樂療癒]]、[[藝術手作]]、[[表達性藝術]]、[[芳香療法]]、[[經絡保健]]、[[外丹功]]、[[化妝療癒]]、[[健康促進體適能]]、[[健康飲食]]、[[頌缽]]、[[溫泉養生]]、[[茶禪]]、[[氣功]]、[[冒險療癒]]等。
    -   成功推動[[跨領域合作]]案例「百膳孝為先」方案，結合[[蔬食營養]]、[[共煮共食]]、[[友善農業]]、[[家庭倫理]]、[[文化永續]]等多重價值，實踐[[永續發展]]。

## 核心概念與連結

[[宜蘭縣]] — 本計畫主要實踐場域，目標將其打造成健康療癒的樂活之鄉。
[[礁溪鄉]] — [[宜蘭縣]]內重要的實踐場域之一。
[[財團法人宜蘭縣私立蘭陽仁愛之家]] — 本計畫長期合作的[[長照據點]]夥伴。
[[SDG3]] — 良好健康與福祉：透過身心靈健康服務與人才培育，直接提升民眾健康福祉。
[[SDG4]] — 優質教育：透過校內課程與從業人員培訓，提供優質的樂活產業教育。
[[SDG10]] — 減少不平等：將健康服務推廣至社區及長照據點，縮小健康資源差距。
[[健康促進與食品安全]] — 本計畫的核心議題，透過多元課程與活動提升民眾健康意識與實踐。
[[高齡照護]] — 本計畫服務對象之一，重點關注[[長照據點]]及高齡民眾的身心靈健康。
[[地方創生]] — 透過在地人才培育與社區服務，活絡地方發展，提升宜蘭的宜居性與特色。
[[輔助療法]] — 本計畫提供多種非藥物性療癒方式，如音樂、芳香、藝術等，以促進身心健康。
[[健康促進]] — 透過體適能、健康飲食等活動，鼓勵民眾主動維護自身健康。
[[身心靈旅療]] — 結合旅遊與身心靈療癒體驗，推廣全人健康概念。
[[人才培育]] — 透過校內外課程，培養樂活產業的專業人才，為社區服務提供人力資源。
[[社區陪伴]] — 透過長期駐點服務與課程，與社區建立連結，提供持續性的關懷與支持。
[[跨領域合作]] — 整合不同專業領域師資與資源，提供多元且深度的身心靈健康服務。
[[身心靈健康]] — 本計畫的核心目標，強調身體、心理、靈性層面的全面健康。
[[全人健康]] — 與身心靈健康概念相符，旨在促進個體各面向的完整健康。
[[在地連結]] — 透過與宜蘭在地社區、機構的合作，將大學資源與地方需求緊密結合。
[[永續發展]] — 透過計畫的長期推動與跨領域合作，追求環境、社會、經濟的平衡與永續。
[[實務能力提升]] — 學生透過參與社區服務，將所學應用於真實情境，增強解決問題能力。
[[社會責任感]] — 學生在服務過程中體認到回饋社會的重要性，培養公民意識。
[[自我成長]] — 學生在服務與學習中，經歷個人能力與心智的發展與突破。
[[專業素養提升]] — 透過課程與培訓，提升從業人員在樂活產業的專業知識與技能。
[[音樂療癒]] — 運用音樂元素促進身心放鬆與情緒平衡的輔助療法。
[[藝術手作]] — 透過創作活動，促進表達與心靈療癒。
[[表達性藝術]] — 運用藝術形式（如繪畫、戲劇、舞蹈）來探索與表達內在情感。
[[芳香療法]] — 運用植物精油來改善身心健康的輔助療法。
[[經絡保健]] — 結合中醫理論，透過按摩等方式疏通經絡，促進身體健康。
[[外丹功]] — 一種結合呼吸與動作的養生功法，有助於身心平衡。
[[化妝療癒]] — 透過化妝技巧與過程，提升自信與愉悅感。
[[健康促進體適能]] — 透過運動與體能訓練，提升身體健康與活力。
[[健康飲食]] — 推廣均衡營養與健康烹飪，作為身心健康的重要基礎。
[[頌缽]] — 運用頌缽的聲波振動，達到身心放鬆與療癒的效果。
[[溫泉養生]] — 結合宜蘭在地溫泉資源，提供身心放鬆與健康促進的體驗。
[[茶禪]] — 透過品茶與禪修，達到心靈平靜與專注。
[[氣功]] — 透過呼吸、意念與動作的練習，調理氣血，增強體質。
[[冒險療癒]] — 結合戶外活動與挑戰，促進個人成長與心理韌性。
[[蔬食營養]] — 推廣植物性飲食的營養知識與健康益處。
[[共煮共食]] — 透過共同烹飪與用餐，促進人際互動與情感連結。
[[友善農業]] — 支持環境友善的農業生產方式，連結食物來源與永續發展。
[[家庭倫理]] — 在「百膳孝為先」方案中，強調家庭成員間的關愛與連結。
[[文化永續]] — 透過結合在地文化元素與傳統價值，促進文化的傳承與發展。
