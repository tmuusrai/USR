# 夜市 YES－中壢觀光夜市低碳永續教育與實踐

| 欄位 | 內容 |
|------|------|

| 計畫類型 | 萌芽型 |
| SDG 關聯 | [[SDG3]]、[[SDG11]]、[[SDG12]] |
| 計畫議題 | [[產業鏈結與經濟永續]]、[[低碳轉型]]、[[永續發展]]、[[循環經濟]] |
| 實踐場域 | [[桃園市]]、[[中壢區]]、[[中壢觀光夜市]] |

## 執行目標

本計畫以[[中壢觀光夜市]]為示範場域，旨在透過教育、實務與社區合作，推動[[低碳轉型]]、[[環保循環]]、[[廢棄物利用]]與[[綠色飲食]]，建立[[永續發展]]示範模式。同時，透過開設永續綠色餐飲學程，培育學生具備[[社會責任]]、[[環境管理]]、[[資源循環]]與[[創新設計]]的能力。

## 主要活動與成果

-   開設「永續綠色餐飲學分學程」，涵蓋[[青年社會責任實踐]]、[[淨零碳規劃管理]]、[[永續飲食與食材]]等六門課程，累計 368 名學生參與，培育學生[[社會責任]]、[[永續飲食]]及[[低碳管理]]能力。
-   於[[中壢觀光夜市]]周邊[[光明里]]及[[興福里]]社區活動中心舉辦 16 場宣導教育課程與實作體驗活動，總計 598 人次參與，加強里民對[[低碳永續]]及[[資源循環]]的理解與參與意願。
-   成功邀請 8 家[[夜市攤商]]參與[[低碳淨零輔導]]，逐步實現[[低碳轉型]]及[[廢棄物循環利用]]。
-   安排多場高中職學生[[低碳永續]]宣導教育活動，累計 487 位參與，提升學生對[[低碳永續發展]]及[[剩食再利用]]的認知與實務能力。
-   運用[[剩食再利用]]研發豆渣低升糖指數糕點，獲得[[衛生福利部樂生療養院]]肯定並簽署合作意向書，將由學生製作糕點提供[[糖尿病患者]]食用，落實[[低碳永續飲食]]理念。
-   將[[夜市]]回收之[[廢油]]、餐廳回收[[咖啡渣]]等進行[[再利用]]，製作肥皂與洗手液，將[[廚餘循環]]與[[夜市環保]]再利用落實於實務。
-   建立與[[中壢觀光夜市管理委員會]]、[[光明里]]、[[興福里]]里長長期協作機制，共同推動[[夜市]]的[[低碳永續]]發展。

## 核心概念與連結

[[桃園市]] — 計畫的實踐場域，位於台灣北部。
[[中壢區]] — [[桃園市]]的一個行政區，[[中壢觀光夜市]]所在地。
[[中壢觀光夜市]] — 本計畫的核心實踐場域，推動[[低碳轉型]]與[[永續發展]]的示範點。
[[光明里]] — [[中壢觀光夜市]]所在的里，也是社區活動的實踐場域之一。
[[興福里]] — [[中壢觀光夜市]]周邊的里，也是社區活動的實踐場域之一。
[[SDG3]] — 良好健康與福祉：透過[[剩食再利用]]研發低升糖糕點，關懷[[糖尿病患者]]健康。
[[SDG11]] — 永續城市及社區：以[[中壢觀光夜市]]為示範，推動[[低碳轉型]]、[[廢棄物循環利用]]，建立[[永續城市]]與[[社區]]模式。
[[SDG12]] — 負責任的消費及生產：推廣[[永續飲食]]、[[剩食再利用]]、[[廢棄物循環利用]]，引導[[夜市攤商]]及消費者實踐[[負責任的消費及生產]]。
[[產業鏈結與經濟永續]] — 本計畫的核心議題，透過輔導[[夜市攤商]]進行[[低碳轉型]]，促進[[夜市]]經濟的[[永續發展]]。
[[低碳轉型]] — 計畫主要目標之一，協助[[中壢觀光夜市]]攤商減少碳排放，邁向[[淨零碳排]]。
[[永續發展]] — 貫穿計畫的核心理念，旨在建立[[中壢觀光夜市]]在環境、社會、經濟方面的長期[[永續]]模式。
[[循環經濟]] — 透過[[廢棄物利用]]、[[剩食再利用]]、[[廚餘循環]]等方式，將資源循環再利用，減少浪費。
[[環保循環]] — 具體實踐[[循環經濟]]的策略，包括推廣[[循環餐具]]、[[廢棄物回收再利用]]。
[[廢棄物利用]] — 將[[夜市]]產生的[[廚餘]]、[[廢油]]、[[咖啡渣]]等轉化為有價值的資源，如[[廚餘酵素]]、肥皂。
[[綠色飲食]] — 推廣使用[[可持續食材]]、減少[[食物浪費]]、實踐[[剩食再利用]]，引導健康與[[環境友善]]的飲食習慣。
[[社會責任]] — 透過課程與實作，培育學生對[[社會]]和[[環境]]議題的關懷與實踐能力。
[[環境管理]] — 課程內容之一，教導學生如何進行[[淨零碳規劃管理]]及[[綠色經營管理]]。
[[資源循環]] — 課程內容之一，強調[[農業及餐飲業廢棄物循環再利用]]。
[[創新設計]] — 課程內容之一，涉及[[循環環保餐飲器具設計]]。
[[永續飲食]] — 課程與活動推廣的重點，鼓勵健康、[[環境友善]]且減少浪費的飲食方式。
[[低碳管理]] — 透過[[淨零碳規劃管理]]課程及[[夜市輔導]]，協助攤商及學生掌握[[低碳]]營運策略。
[[低碳淨零輔導]] — 針對[[夜市攤商]]提供的專業輔導，協助其達成[[低碳轉型]]與[[淨零碳排]]目標。
[[廢棄物循環利用]] — 將[[夜市]]產生的[[廢棄物]]（如[[廚餘]]、[[廢油]]）轉化為資源，實踐[[循環經濟]]。
[[剩食再利用]] — 將未被食用的食物或食材邊角料，透過創新方式轉化為新產品，減少[[食物浪費]]。
[[衛生福利部樂生療養院]] — 本計畫[[剩食再利用]]成果的合作夥伴，共同推動[[低升糖糕點]]的研發與應用。
[[糖尿病患者]] — 本計畫[[剩食再利用]]研發的[[低升糖糕點]]的潛在受益者，體現[[SDG3]]的關懷。
[[廢油]] — [[夜市]]常見的[[廢棄物]]，本計畫將其回收[[再利用]]製作肥皂。
[[咖啡渣]] — [[夜市]]常見的[[廢棄物]]，本計畫將其回收[[再利用]]製作洗手液。
[[廚餘循環]] — 透過[[廚餘分類]]、[[廚餘酵素製作]]等方式，將[[廚餘]]轉化為有價值的資源。
[[夜市環保]] — 針對[[夜市]]場域推動的[[環保]]措施，包括[[低碳轉型]]、[[廢棄物循環利用]]、[[循環餐具]]等。
[[中壢觀光夜市管理委員會]] — 本計畫的重要合作夥伴，共同推動[[夜市]]的[[低碳永續]]發展。
[[淨零碳排]] — 計畫協助[[夜市攤商]]努力達成的目標，減少溫室氣體排放。
[[循環餐具]] — 推廣在[[夜市]]使用可重複利用的餐具，減少一次性[[廢棄物]]。
[[廚餘酵素]] — 將[[廚餘]]轉化為[[酵素]]，是一種[[廢棄物利用]]的方式。
[[食物浪費]] — 計畫透過[[剩食再利用]]、[[永續飲食]]等方式，減少[[食物浪費]]。
[[環境友善]] — 計畫推動[[綠色飲食]]、[[低碳轉型]]等，旨在實現[[環境友善]]的營運模式。
[[青年社會責任實踐]] — 永續綠色餐飲學程中的一門課程，旨在培養學生參與社會議題的實踐能力。
[[淨零碳規劃管理]] — 永續綠色餐飲學程中的一門課程，教授學生如何規劃與管理碳排放，以達成[[淨零碳排]]目標。
[[永續飲食與食材]] — 永續綠色餐飲學程中的一門課程，探討[[永續飲食]]的原則與[[可持續食材]]的選擇。
[[綠色經營管理與實務]] — 永續綠色餐飲學程中的一門課程，教授[[綠色經營]]的策略與實務應用。
[[農業及餐飲業廢棄物循環再利用]] — 永續綠色餐飲學程中的一門課程，專注於[[農業]]與[[餐飲業]][[廢棄物]]的[[循環再利用]]技術。
[[循環環保餐飲器具設計]] — 永續綠色餐飲學程中的一門課程，探討[[循環餐具]]及[[環保餐飲器具]]的設計與應用。
