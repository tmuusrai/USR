# 3R（USR X CSR X PSR）建構超高齡社會互助心價值

| 欄位 | 內容 |
|------|------|
| 執行學校 | 致理科技大學 |
| 計畫類型 | 大學特色類深耕型 |
| SDG 關聯 | [[SDG3]]、[[SDG4]]、[[SDG11]] |
| 計畫議題 | [[高齡照護]]、[[在地關懷]]、[[青銀共創]] |
| 實踐場域 | [[新北市]] [[板橋區]]、[[桃園市]] [[龜山區]] |

## 執行目標

本計畫旨在透過整合[[USR]]、[[CSR]]、[[PSR]]資源，建構超高齡社會的互助新價值。核心目標為優化[[高齡照護]]服務，促進[[青銀共創]]與[[在地關懷]]，並建立[[數位媒合]]平台，以實現[[永續發展]]的[[一站式服務生態圈]]。

## 主要活動與成果

-   **銀髮就醫陪伴服務**：
    -   培育志工，提供長者就醫陪伴服務，服務範圍擴大至雙北26區及離島。
    -   本期陪伴案數達996案，包含[[失智症]]128案、[[獨居老人]]288案，有效減輕家庭及公部門負擔。
    -   將優質服務機制複製至[[桃園市]][[龜山區]]，與[[龜山區區公所]]合作。
    -   榮獲2025「銀光好居認證」創新服務獎。
-   **職人生活互助服務**：
    -   建立[[在地知識]]人才庫，發掘[[在地老師傅]]。
    -   開辦課程並媒合編織、水電、舒壓等專業服務共20案。
-   **青銀樂活共學**：
    -   推動「橘色產業服務創新」學分學程，結合課程與證照，培育[[銀髮專業]]人才。
    -   輔導學生13人考取相關證照。
    -   組建[[青銀微社群]]10群，共同設計優質方案及教具。
    -   開發[[桌遊]]13案及[[精準運動]]服務5案，並進入[[社區關懷據點]]（如香丘、忠誠里）實踐。
    -   開發「精準運動九式」教案，目標出版專書並成立「[[高齡運動促進師]]」證照。
    -   學生結合科技與環保材質，設計「能量探險球」玩具，促進[[青銀共樂]]。
-   **數位平台建構**：
    -   開發「致理銀髮生活互助服務」三合一數位平台，整合就醫陪伴、職人互助、樂活共學服務。
    -   已啟動就醫陪伴[[數位媒合]]功能，目標建立[[一站式服務生態圈]]。
-   **創新與專利**：
    -   教師指導學生申獲2案專利：「銀髮志工媒合系統」及「藥盒結構」。
-   **榮譽與肯定**：
    -   入圍遠見大學社會責任獎（萌芽期）。
    -   獲選技職力100課程教學團隊（萌芽期）。
    -   獲2025銀光好居創新服務獎（本期）。

## 核心概念與連結

[[USR]] — 大學社會責任，本計畫的核心精神，透過大學資源服務社會，解決高齡化社會問題。
[[CSR]] — 企業社會責任，計畫旨在結合企業資源與合作夥伴，共同推動社會服務，擴大影響力。
[[PSR]] — 公部門社會責任，計畫與公部門（如區公所、醫院）合作，減輕其負擔並擴大服務效益。
[[高齡照護]] — 本計畫主要關注的社會議題，透過就醫陪伴、生活互助、樂活共學等多面向服務長者。
[[青銀共創]] — 透過青銀微社群、學分學程等方式，促進跨世代合作與學習，共同設計服務方案。
[[在地關懷]] — 計畫深耕社區，發掘在地需求，提供貼近長者生活的服務，建立社區互助網絡。
[[永續發展]] — 計畫目標建立一站式服務生態圈，並朝企業化、證照化發展，以實現服務的長期永續性。
[[SDG3]] — 良好健康與福祉，透過就醫陪伴、精準運動等提升長者健康與生活品質。
[[SDG4]] — 優質教育，透過學分學程、證照培訓、青銀共學等提供優質教育機會。
[[SDG11]] — 永續城市及社區，透過社區關懷據點服務、在地職人互助等，建構友善高齡的永續社區。
[[新北市]] — 本計畫主要實踐場域之一。
[[板橋區]] — [[新北市]]的實踐場域，致理科技大學所在地，設有旗艦銀髮社區關懷據點。
[[致理科技大學旗艦銀髮社區關懷據點]] — 本計畫固定實踐場域，提供銀髮服務。
[[桃園市]] — 本計畫服務機制複製與推廣的實踐場域。
[[龜山區]] — [[桃園市]]的實踐場域，與區公所合作推動服務。
[[龜山區區公所]] — [[桃園市]][[龜山區]]的合作機構，協助推廣銀髮就醫陪伴服務。
[[失智症]] — 計畫特別關注的服務對象之一，提供專業的就醫陪伴服務。
[[獨居老人]] — 計畫特別關注的服務對象之一，提供就醫陪伴，減輕其生活負擔。
[[在地知識]] — 透過發掘[[在地老師傅]]，建立職人人才庫，傳承在地技能與經驗。
[[在地老師傅]] — 計畫職人生活互助服務的關鍵資源，其專業技能被媒合提供服務。
[[銀髮專業]] — 計畫透過學分學程、證照培訓，培養學生在高齡服務領域的專業能力。
[[青銀微社群]] — 促進跨世代互動與合作的組織形式，共同設計樂活方案並進入社區服務。
[[桌遊]] — 青銀樂活共學活動中開發的教具，用於促進長者學習、認知與社交互動。
[[精準運動]] — 計畫開發的運動教案，旨在透過科學方法提升長者身體機能與健康。
[[社區關懷據點]] — 計畫實踐青銀樂活共學服務的場域，提供長者活動與交流空間。
[[高齡運動促進師]] — 計畫目標開發的專業證照，旨在培養銀髮動健康領域的專業人才。
[[青銀共樂]] — 透過共同參與活動（如玩玩具、桌遊），促進跨世代的歡樂互動與情感連結。
[[一站式服務生態圈]] — 計畫數位平台整合各項服務的目標，提供便捷完整的銀髮服務。
[[數位媒合]] — 透過數位平台實現服務申請者與志工/職人的快速配對，提升服務效率。
[[永續經營]] — 計畫將服務機制企業化、證照化，以確保長期運作與發展，提供穩定的社會服務。
