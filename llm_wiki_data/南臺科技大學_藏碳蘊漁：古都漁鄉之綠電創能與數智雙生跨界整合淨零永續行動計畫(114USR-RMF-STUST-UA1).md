# 藏碳蘊漁：古都漁鄉之綠電創能與數智雙生跨界整合淨零永續行動計畫

| 計畫類型 | 萌芽型 |

| 計畫議題 | [[環境永續]]、[[淨零減碳]]、[[智慧養殖]]、[[綠電創能]]、[[永續經營]] |
| 實踐場域 | [[臺南市]]、[[安南區]]、[[土城在地養殖魚塭]]、[[七股]]、[[麻豆]]、[[青草國小]] |

## 執行目標

本計畫旨在延續[[人才培育]]主軸，透過[[綠電創能]]與[[智慧養殖]]技術的[[跨域整合]]，深化[[臺南市]]漁鄉的[[在地鏈結]]與[[永續發展]]。目標是培育具備[[綠電數智]]能力的[[跨域人才]]，並將創新技術導入[[場域實踐]]，以推動[[淨零減碳]]與[[永續經營]]，擴大社會影響力。

## 主要活動與成果

-   **前期基礎與制度化**：
    -   前期計畫「藏碳蘊漁：古都土城仔綠電創能與智動養殖之跨界整合永續淨零發展計畫」奠定基礎。
    -   校內正式通過「綠電創能與節能實務學分學程」，建立跨領域教學制度。
    -   強化感測技術與能源實作融入教學課程，提升學生專案開發與問題解決能力。
    -   推動教師社群運作，促進課程共備與經驗交流，形塑協作機制。
    -   榮獲第六屆《遠見》USR大學社會責任獎永續課程組績優獎。

-   **人才培育與課程創新**：
    -   開設17門USR課程、20班次，修課人次達972人，形成多元[[跨域學習]]體系。
    -   課程設計以場域需求為核心，導入[[專題導向學習]]與[[實作學習]]，培養學生分析與解決問題能力。
    -   舉辦課程成果發表會與師生交流活動，促進經驗分享。
    -   學生團隊完成多項[[綠能應用]]與[[智慧化專案]]，如風光互補系統測試、魚塭水質感測船開發，並導入場域驗證。

-   **場域深化與技術導入**：
    -   深化與[[安南區]]、[[七股]]、[[麻豆區]]養殖戶之合作，推動感測裝置應用及技術溝通。
    -   拓展至[[七股]]、[[麻豆]]等新場域，推動[[智慧養殖]]、感測優化及[[能源教育]]推廣。
    -   與[[青草國小]]合作，設計無人機體驗營活動，延伸[[環境教育]]觸角。

-   **創新創業與社會影響**：
    -   學生團隊「源動力」自USR專案延伸發展為創業團隊，成立「[[翎博科技公司]]」，推展[[智慧化水質監測裝置]]商品化，成為USR導向創業的代表案例。
    -   [[教師社群]]串聯跨院系教師，持續舉辦課程共備與成果交流會，形成教學支持網絡。
    -   參與「USR EXPO」、「高雄智慧城市展」及「南方人才永續展」等大型會展，展示[[綠能創新]]與[[養殖實踐]]成果。
    -   結合科普計畫資源推動[[校園環境教育]]，以風能與[[永續議題]]進行推廣講座與示範活動，擴大社會影響力。

-   **成效評估機制**：
    -   以[[社會投資報酬分析]]（SROI）為核心架構，搭配量化與質性資料蒐集，系統性檢視計畫之社會影響與效益。
    -   資料來源包含學生修課前後測問卷、教師與場域夥伴訪談、學生專案成果分析等。
    -   利害關係人涵蓋教師、學生、場域夥伴與在地學校，透過訪談、問卷與成果會議收集意見，形成滾動修正機制。

## 核心概念與連結

[[人才培育]] — 本計畫核心主軸，透過課程與專案實作，培養學生具備綠電數智與永續發展能力。
[[綠電創能]] — 計畫聚焦的技術領域，旨在開發與應用小型綠能系統，為漁鄉提供潔淨能源。
[[智慧養殖]] — 結合感測技術與數據分析，提升養殖效率與環境管理，實現漁業永續。
[[跨域整合]] — 整合校內外不同領域的知識與資源，促進技術與地方需求的對話與實踐。
[[在地鏈結]] — 深化與[[臺南市]]漁鄉（如[[安南區]]、[[七股]]、[[麻豆區]]）的合作，將技術導入在地場域。
[[永續發展]] — 計畫的終極目標，透過綠電、智慧養殖與人才培育，促進地方經濟、社會與環境的平衡。
[[臺南市]] — 計畫的主要實踐場域，特別是其沿海漁業區域。
[[安南區]] — [[臺南市]]的行政區，計畫前期與核心的[[土城在地養殖魚塭]]所在地。
[[土城在地養殖魚塭]] — 計畫主要的固定實踐場域，進行綠電與智慧養殖技術的導入與驗證。
[[七股]] — [[臺南市]]的行政區，計畫後期拓展的新合作場域。
[[麻豆]] — [[臺南市]]的行政區，計畫後期拓展的新合作場域。
[[淨零減碳]] — 計畫的重要議題，透過綠電創能與節能技術，協助漁鄉邁向碳中和。
[[永續經營]] — 透過技術導入與人才培育，協助在地產業與社區實現長期穩健發展。
[[綠電數智]] — 結合綠色能源與數位智慧技術，是本計畫培育[[跨域人才]]的核心能力。
[[場域實踐]] — 將課堂所學與研發技術實際應用於漁鄉場域，解決在地問題。
[[SDG2]] — 零飢餓，透過智慧養殖提升糧食生產效率與永續性。
[[SDG7]] — 可負擔及乾淨能源，推動綠電創能，提供在地潔淨能源解決方案。
[[SDG12]] — 負責任的消費及生產，透過智慧化管理，促進漁業資源的永續利用。
[[跨域學習]] — 鼓勵學生參與不同學科領域的課程與專案，培養多元能力。
[[專題導向學習]] — 以實際問題為導向，引導學生透過專案解決問題的教學方法。
[[實作學習]] — 強調動手實踐，讓學生在實際操作中學習與驗證技術。
[[綠能應用]] — 太陽能、風能等再生能源在漁業場域的實際部署與運用。
[[智慧化專案]] — 學生團隊開發的具備智慧監測、自動控制等功能的技術方案。
[[青草國小]] — 合作夥伴，透過無人機體驗營等活動，推廣[[環境教育]]。
[[能源教育]] — 向在地社區與學童推廣再生能源與節能知識。
[[環境教育]] — 透過科普活動與推廣講座，提升大眾對環境永續議題的認知。
[[翎博科技公司]] — 由學生團隊「源動力」成立的創業公司，將USR專案成果商品化。
[[智慧化水質監測裝置]] — 學生團隊研發並商品化的核心技術，用於提升養殖管理效率。
[[教師社群]] — 跨院系教師組成的協作網絡，促進課程共備與教學創新。
[[校園環境教育]] — 將環境永續議題融入校園教學與推廣活動。
[[永續議題]] — 涵蓋氣候變遷、資源利用、生態保育等與永續發展相關的課題。
[[社會投資報酬分析]] — 一種評估社會計畫效益的方法，用以量化本計畫的社會影響力。
[[跨域人才]] — 具備多領域知識與技能，能應對複雜社會問題的複合型人才。
