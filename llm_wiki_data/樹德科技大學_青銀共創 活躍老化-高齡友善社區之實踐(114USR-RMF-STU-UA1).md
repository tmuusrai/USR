# 青銀共創 活躍老化-高齡友善社區之實踐

| 欄位 | 內容 |
|------|------|
| 執行學校 | 樹德科技大學 |
| 計畫類型 | 萌芽型 |
| SDG 關聯 | [[SDG3]]、[[SDG4]]、[[SDG11]] |
| 計畫議題 | [[在地關懷]]、[[高齡照護]]、[[活躍老化]] |

## 執行目標

樹德科技大學「青銀共創‧活躍老化—高齡友善社區之實踐」計畫，旨在透過[[青銀共創]]與[[智慧照顧]]模式，推動[[高齡照護]]與[[活躍老化]]，建構[[高齡友善社區]]。計畫聚焦於[[高雄市]][[大社區]]及[[梓官區]]，透過教育實踐、社區合作與跨專業整合，達成世代共融與[[永續發展]]的[[在地關懷]]目標。

## 主要活動與成果

-   **模式建立與夥伴關係深化：**
    -   從 USR Hub「幸福老人‧活躍老化」萌芽期發展，形成以「[[青銀共創]]、[[智慧共生]]」為核心的[[在地實踐]]模式。
    -   建立學校與[[高雄市大社區老人文康活動中心]]、[[高雄市梓官區老人兒童活動中心]]等場域的穩定夥伴關係。
    -   推動「學校—社區—公部門」三方[[跨域合作]]模式。
-   **場域建置與社區活動：**
    -   建置「[[青銀共創]]基地」，並設立「梓官青銀美好咖啡蔬果廣場」。
    -   在大社區及梓官日照中心設立示範據點，推動健康促進、共餐共學與數位學習等活動，累計 30 場次、約 1200 人次參與。
-   **在地需求評估與研究：**
    -   完成《智慧共生社區生活需求評估問卷》與實地調查，執行 850 份需求問卷與焦點團體，掌握長者在餐食、交通、健康、社交與數位應用五大需求面向。
-   **跨專業人才培育：**
    -   開設 7 門 USR 相關課程（如《科技智能照顧服務》），修課人次逾 250 人，建立從基礎理論到[[社區實踐]]的學習體系。
    -   建構「學習—實作—就業」鏈結機制，學生投入[[社區服務]]時數超過 1,200 小時。
    -   完成跨院《科技智能照顧服務》課程及《高齡友善社區生活設計工作坊》，提升學生專業實務力與[[社會創新]]思維。
-   **社區賦能與自主治理：**
    -   [[觀音社區協會]]從協力夥伴轉為主動共構者，長輩由「被服務者」轉為「課程提案者」，形成跨世代共學網絡。
    -   促進社區從被動參與轉向自主治理，強化社會連結與[[共生精神]]。
-   **跨校與國際交流：**
    -   與[[北大 USR 團隊]]共學交流，舉辦《USR 共創[[永續未來]]》論壇。
    -   赴馬來西亞進行[[高齡照護]]及社工教育訪交流。
-   **亮點案例：智慧共生社區推動：**
    -   以公民咖啡館形式促進旗艦社區對話，探討[[在地照顧]]、世代互助、[[智慧科技]]導入等五大主題。
    -   成功引發[[高雄市]]地區社區申請共生社區計畫，連結高齡社會白皮書政策。

## 核心概念與連結

[[青銀共創]] — 本計畫核心方法，透過跨世代合作，共同推動[[高齡照護]]與社區發展。
[[活躍老化]] — 本計畫主要目標之一，鼓勵長者積極參與社會活動，提升生活品質。
[[高齡照護]] — 本計畫關注的[[在地關懷]]議題，旨在提供長者完善的照顧服務與友善環境。
[[高齡友善社區]] — 本計畫致力於建構的理想場域，透過多面向服務與設計，滿足長者需求。
[[智慧照顧]] — 本計畫導入[[智慧科技]]，提升[[高齡照護]]服務的效率與品質。
[[智慧共生]] — 本計畫推動的社區發展願景，結合[[智慧科技]]與世代共融，實現社區[[永續發展]]。
[[在地關懷]] — 本計畫的議題主軸，深耕[[高雄市]]在地社區，回應在地長者需求。
[[永續發展]] — 本計畫追求的長期目標，透過[[USR]]實踐，促進社區與社會的持續進步。
[[高雄市]] — 本計畫的主要實踐場域，包含[[大社區]]與[[梓官區]]。
[[大社區]] — [[高雄市]]的實踐場域之一，設有[[高雄市大社區老人文康活動中心]]。
[[梓官區]] — [[高雄市]]的實踐場域之一，設有[[高雄市梓官區老人兒童活動中心]]，並設有「梓官青銀美好咖啡蔬果廣場」。
[[觀音社區協會]] — 本計畫的合作夥伴，透過培力使其從協力者轉為主動共構者。
[[SDG3]] — 良好健康與福祉，本計畫透過健康促進、[[高齡照護]]等活動，提升長者身心健康。
[[SDG4]] — 優質教育，本計畫透過開設USR課程、學生[[社區服務]]，提升學生專業能力與公民素養。
[[SDG11]] — 永續城市及社區，本計畫致力於建構[[高齡友善社區]]、推動[[智慧共生]]，促進社區[[永續發展]]。
[[在地實踐]] — 本計畫將學術知識與在地需求結合，透過實際行動解決社區問題。
[[跨域合作]] — 本計畫整合校內跨院系師資與外部公部門、社區組織，共同推動計畫。
[[智慧科技]] — 本計畫導入科技應用於[[高齡照護]]與社區服務，提升效率與創新性。
[[社區實踐]] — 學生將課堂所學應用於真實社區場域，累積實務經驗。
[[社區服務]] — 學生參與社區活動，提供協助與支持，回饋社會。
[[社會創新]] — 本計畫透過創新的服務模式與[[青銀共創]]，為高齡社會提供解決方案。
[[北大 USR 團隊]] — 本計畫的跨校合作夥伴，共同進行學習交流。
[[在地照顧]] — 本計畫強調在長者熟悉的社區環境中提供照顧服務。
[[共生精神]] — 本計畫透過世代共學與互助，促進社區成員間的連結與和諧。
