# 城市「溪」伴—AI賦能綠色材料發展計畫

| 欄位 | 內容 |
|------|------|
| 執行學校 | 明新科技大學 |
| 計畫類型 | 大學特色類萌芽型 |
| SDG 關聯 | [[SDG6]]、[[SDG11]]、[[SDG12]] |
| 計畫議題 | [[循環經濟]]、[[環境教育]]、[[地方創生]]、[[水資源]] |
| 實踐場域 | [[新竹縣]]、[[竹北市]]、[[麻園里]] |

## 執行目標

本計畫以[[竹北市]][[鳳山溪]]流域為主要場域，透過[[生態調查]]、[[循環經濟]][[綠色材料開發]]及[[社區環境教育]]推廣。結合[[AI賦能]]技術與[[跨領域合作]]，提供[[地方永續發展]]具體解方，並深化學生[[社會責任]]意識。

## 主要活動與成果

-   與[[荒野保護協會]]籌組「河川巡守隊」，積極參與[[頭前溪]]環境保護，深化學生[[永續意識]]與行動力。
-   與[[竹北市公所]]簽署合作意向書，取得[[地方永續發展]]、產業升級及[[青年培力]]等面向的政策性支持。
-   設立「AI人工智慧人才培力中心」，將[[AI]]課程列為大一必修，為計畫提供技術支援與設備資源。
-   與[[竹北水資源中心]]、[[麻園里里長辦公室]]及地方政府合作，完成[[鳳山溪]]河川[[生態田野調查]]。
-   開發[[污泥循環再利用]]之[[綠色材料]]草案，結合[[AI人工智慧]]技術，提出具創新性與實用性的[[循環經濟]]模式。
-   舉辦兩場[[社區共識會議]]及兩場[[環境教育工作坊]]，成功促進居民參與[[地方議題]]討論，建立[[社區對生態永續的共識]]。
-   跨院系規劃多門[[循環經濟]]、[[綠色材料]]及[[環境教育]]相關USR課程，180名學生實地參與[[社區場域服務與學習]]。
-   首次以[[社區參與]]方式繪製[[竹北市]][[鳳山溪]]流域地圖，結合[[在地知識]]、[[生態環境]]、[[歷史文化]]資訊與[[社區居民經驗]]。
-   透過[[線上國際論壇]]，讓師生接軌最新[[水資源]]相關資訊。
-   成功協調解決[[水質監測]]選點問題，透過[[社區共識會議]]與居民溝通，確保後續監測工作順利推動。

## 核心概念與連結

[[AI人工智慧]] — 應用於綠色材料開發，提升循環經濟模式的創新性與實用性。
[[AI賦能]] — 透過AI技術賦能綠色材料發展與地方永續實踐。
[[SDG6]] — 確保所有人都能享有水及衛生及其永續管理，本計畫關注鳳山溪水環境保護。
[[SDG11]] — 建立具包容、安全、韌性及永續的城市與人類住居，透過社區營造與地方永續發展實現。
[[SDG12]] — 確保永續消費及生產模式，本計畫透過污泥循環再利用綠色材料開發實踐。
[[在地知識]] — 透過社區參與繪製流域地圖，結合地方生態、歷史文化與居民經驗。
[[永續發展]] — 計畫的總體願景，旨在推動地方環境、社會與經濟的長期發展。
[[污泥循環再利用]] — 具體實踐循環經濟的創新模式，將廢棄物轉化為綠色材料。
[[生態田野調查]] — 鳳山溪流域生態資訊收集的主要方法，為環境保護提供基礎數據。
[[生態環境]] — 計畫關注的核心面向，透過河川巡守、生態調查及環境教育進行保護。
[[社區共識會議]] — 重要的社區參與機制，促進地方議題討論與共識建立。
[[社區場域服務與學習]] — 學生參與USR課程的重要實踐方式，強化跨領域能力與社會責任意識。
[[社區營造]] — 透過社區共識會議、環境教育工作坊及流域地圖建立，促進地方凝聚力。
[[循環經濟]] — 計畫核心議題，開發污泥循環再利用綠色材料，推動區域綠色經濟。
[[竹北市]] — 計畫實踐的市級場域，鳳山溪流域所在地。
[[竹北市公所]] — 重要的政策性合作夥伴，支持地方永續發展。
[[竹北水資源中心]] — 合作夥伴之一，協助污泥循環再利用等議題。
[[地方創生]] — 透過產業升級、青年培力及社區營造，活化地方發展。
[[地方永續發展]] — 計畫的總體目標，透過環境保護、產業升級及青年培力實現。
[[麻園里]] — 計畫在竹北市的固定實踐場域。
[[新竹縣]] — 計畫實踐的縣級場域。
[[新竹縣政府環保局]] — 外部合作夥伴，協助環境保護相關事務。
[[水資源]] — 計畫關注的SDG議題之一，涉及乾淨用水及水質監測。
[[環境教育]] — 計畫重要推廣活動，透過工作坊、課程及流域地圖建立社區共識。
[[綠色材料]] — 透過污泥循環再利用開發的環保材料。
[[綠色材料開發]] — 計畫核心活動，開發污泥循環再利用材料。
[[荒野保護協會]] — 早期合作夥伴，共同籌組河川巡守隊。
[[鳳山溪]] — 本計畫第一年度主要聚焦的流域，進行生態調查與環境教育。
[[歷史文化]] — 透過社區參與繪製流域地圖，結合地方歷史文化資訊。
[[青年培力]] — 與竹北市公所合作面向之一，強化學生跨領域能力與社會責任意識。
[[頭前溪]] — 學生河川巡守隊早期參與環境保護的河川。
[[跨領域合作]] — 團隊組成與課程設計的特色，整合不同專業師生。
[[社會責任]] — 大學社會責任（USR）計畫的本質，彰顯學校對地方的貢獻。
[[社區居民經驗]] — 繪製流域地圖時結合的重要在地資訊來源。
[[社區對生態永續的共識]] — 環境教育工作坊與共識會議旨在達成的目標。
[[地方議題]] — 社區共識會議與環境教育工作坊討論的核心內容。
[[永續意識]] — 學生參與河川巡守隊及USR課程後深化提升的意識。
