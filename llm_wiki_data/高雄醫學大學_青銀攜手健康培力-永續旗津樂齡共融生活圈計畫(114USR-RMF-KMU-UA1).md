# 青銀攜手健康培力-永續旗津樂齡共融生活圈計畫

| 欄位 | 內容 |
|------|------|
| 執行學校 | 高雄醫學大學 |
| 計畫類型 | 萌芽型 |
| SDG 關聯 | [[SDG3]]、[[SDG4]]、[[SDG11]] |
| 計畫議題 | [[高齡照護]]、[[健康促進]]、[[地方創生]]、[[失智友善]] |
| 實踐場域 | [[高雄市]]、[[旗津區]] |

## 執行目標

本計畫旨在延續前期成果，持續關注[[高齡照護]]及[[青銀共創]]議題，深化聚焦[[旗津區]]長者之生理健康、心理認知與地方產業優化三大面向。最終目標是建構一個青銀健康共融、樂齡護智培力、創生自立永續的[[旗津區]]健康[[永續發展]]生活圈。

## 主要活動與成果

-   **青銀攜手健康共融：**
    -   盤點[[旗津區]]長者及國中小需求，整合跨專業師資推動6件高齡特色[[社會處方]]箋及3件青銀用藥安全處方箋。
    -   編篡《旗津健康活動手冊》，提供據點人員運用，建構完善的社區健康照護網絡。
    -   [[青銀共創]]全島銀髮競賽，促進長者參與及活力。
-   **樂齡美學護智培力：**
    -   以高齡[[音樂照顧]]方案結合懷舊旋律互動，喚起長者記憶與情感連結。
    -   辦理長照人員專業加值課程2場，共53人次參與，強化在地照護人才專業。
    -   舉辦3個單位[[失智友善]]天使認證，培育53位在地志工，落實社區[[失智友善]]與健康識能提升。
-   **在地創生自立永續：**
    -   護理系學生訪談[[旗津區]]長輩錄製三部[[在地知識]]生命故事影片，並[[青銀共創]]旗津導覽行程，促進台日[[旗津區]][[文化傳承]]交流。
    -   製作旗津繪本手扇，優化銀髮科普平台與據點故事館。
    -   香粧系學生進行[[旗津區]]產業文化盤點，萃取在地品牌故事，培養地方文化與香粧領域行銷之綜整能力。
    -   舉辦「旗津未來願景工作坊」，邀集利害關係人共繪[[旗津區]]藍圖，展現[[地方創生]]願景。
-   **評估回饋永續深化：**
    -   結合校方SROI工作坊，發展學校及場域端多面向評估工具，逐步建構與優化[[社會影響力]]評估機制。
    -   辦理2個教師成長社群共6場活動，強化場域經營與計畫[[永續發展]]成效。

## 核心概念與連結

[[高雄市]] — 計畫實踐場域，位於台灣南部。
[[旗津區]] — 計畫核心實踐場域，為[[高雄市]]的離島區域，聚焦於此區的[[高齡照護]]與[[地方創生]]。
[[旗津醫院]] — 計畫重要合作夥伴與資源，提供醫療與照護支持。
[[高齡照護]] — 本計畫的核心議題，旨在提升[[旗津區]]長者的生理與心理健康。
[[健康促進]] — 透過多元[[社會處方]]箋與活動，全面提升長者及社區居民的健康福祉。
[[地方創生]] — 透過產業文化盤點、故事傳承與願景工作坊，活化[[旗津區]]的在地發展與經濟。
[[失智友善]] — 透過培訓在地志工與課程，提升社區對失智症的友善度與識能，實踐樂齡護智培力。
[[SDG3]] — 良好健康與福祉，與計畫的[[健康促進]]、[[高齡照護]]目標直接相關。
[[SDG4]] — 優質教育，透過[[青銀共創]]、人才培育、[[代間學習]]等活動實踐。
[[SDG11]] — 永續城市及社區，旨在建構健康、共融、自立的[[旗津區]][[永續發展]]生活圈。
[[青銀共創]] — 連結青年與長者共同參與活動、學習與創作，促進世代交流與合作。
[[社區陪伴]] — 建立完善的社區健康照護網絡，培育在地志工，提供長者支持與關懷。
[[代間學習]] — 透過[[青銀共創]]、生命故事錄製等方式，促進世代交流與知識傳承。
[[在地知識]] — 訪談長輩生命故事、盤點產業文化，保存與推廣[[旗津區]]的在地智慧與特色。
[[永續發展]] — 計畫的最終目標，旨在建構健康、共融、自立的[[旗津區]]生活圈。
[[音樂照顧]] — 運用音樂作為高齡服務與護智培力的創新方法，促進長者認知與情感連結。
[[社會處方]] — 將健康促進活動、用藥安全、[[音樂照顧]]等融入社區服務，作為多元的健康介入策略。
[[文化傳承]] — 透過繪本、故事影片、產業盤點等方式，保存與推廣[[旗津區]]的在地文化。
[[社會影響力]] — 透過SROI等評估機制，量化與質化計畫對社區及利害關係人產生的效益。
