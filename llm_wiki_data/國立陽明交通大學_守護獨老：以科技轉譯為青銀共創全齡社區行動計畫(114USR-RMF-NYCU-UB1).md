# 守護獨老：以科技轉譯為青銀共創全齡社區行動計畫

| 欄位 | 內容 |
|------|------|
| 執行學校 | 國立陽明交通大學 |
| 計畫類型 | 深耕型 |
| SDG 關聯 | [[SDG3]]、[[SDG4]]、[[SDG11]] |
| 計畫議題 | [[高齡照護]]、[[健康促進]]、[[數位落差]]、[[青銀共創]]、[[全齡社區]] |
| 實踐場域 | [[臺北市]] [[北投區]]、[[新北市]] [[三芝區]]、[[新竹市]] [[東區]] |

## 執行目標

本計畫旨在回應政府「降低[[長者數位落差]]」政策，並推動「[[社區即第二個家]]」概念，透過[[科技轉譯]]與[[青銀共創]]模式，建構一個能全面守護獨居長者、促進[[在地安老]]的[[全齡社區]]。

## 主要活動與成果

-   **提升社區長者健康飲食與安全用藥知能**：
    -   於[[新北市]] [[三芝區]] [[後厝里]]培訓15位營養志工。
    -   [[國立陽明交通大學]] [[藥學系]]學生至[[臺北市]] [[北投區]] [[吉慶里]]、[[榮光里]]、[[尊賢里]]為15位長者進行藥物盤點與衛教宣導。
    -   與[[臺北榮民總醫院營養部]]合作，推動共餐健康化與[[在地健康飲食文化]]轉型。
-   **培育種子師資延緩社區長者失能失智**：
    -   邀請業師與校友擔任社區講師，開發多元預防失能失智帶狀活動，並提供前後測數據。
    -   實現從在校學生、社區志工到具教育認證講師的[[全方位人才培育]]鏈結。
    -   推動[[跨世代運動課程]]，建立長者「我做得到」的信心，形成[[健康社交網絡]]。
-   **發展智慧科技促進長者身心功能**：
    -   培訓在校[[醫事學生]]開發[[智慧型穿戴感測器]]與[[體感遊戲平台]]，應用於長者行動力檢測與運動復健。
    -   與政府機關、校友企業合作，將ICOPE篩檢工具[[數位遊戲化]]，提升[[高齡健康檢測]]的參與意願與效度。
    -   將傳統復健與體適能運動結合Rabboni轉化為[[智慧手機應用程式]]，實現[[智慧化復健]]。
-   **提高獨居長者經濟安全意識**：
    -   [[國立陽明交通大學]] [[資財系]]41名學生於[[新竹市]]實踐場域進行防詐與財務問卷分析。
    -   前往[[北投稻香日照中心]]關懷[[失智症]]長者，進行防詐宣導。
    -   透過課程與[[防詐桌遊]]，提升長者[[高齡者金融防詐]]認知與[[自我理財能力]]。
-   **維護獨居長者居家環境安全**：
    -   評估[[北投區健康服務中心]]、[[臺北市]] [[北投區]] [[榮光里]]公共空間，提供改善建議。
    -   於[[臺北市]] [[北投區]] [[榮光里]]開設環境安全志工培訓，提升[[居家環境安全]]。
    -   與[[臺中科技大學]]合作進行居家環境安全共榮設計。
-   **社區活動永續經營**：逐步推動實踐場域「使用者付費」概念，為社區自主營運奠定基礎。

## 核心概念與連結

[[SDG3]] — 良好健康與福祉：本計畫透過健康飲食、安全用藥、預防失能失智及智慧復健等活動，直接提升長者身心健康。
[[SDG4]] — 優質教育：本計畫透過學生參與、志工培訓及長者學習課程，促進跨世代的知識傳遞與技能提升。
[[SDG11]] — 永續城市及社區：本計畫旨在透過[[青銀共創]]、[[社區陪伴]]及[[居家環境安全]]改善，建構[[全齡社區]]，實現[[在地安老]]與[[永續發展]]。
[[高齡照護]] — 本計畫核心議題，透過多面向策略（健康、安全、經濟、科技）全面提升獨居長者生活品質。
[[健康促進]] — 計畫透過營養志工培訓、安全用藥衛教、運動課程及智慧復健，積極促進長者身心健康。
[[數位落差]] — 本計畫回應政府政策，運用[[科技轉譯]]將篩檢工具[[數位遊戲化]]，並培訓長者使用智慧科技，以縮小長者在數位應用上的差距。
[[青銀共創]] — 計畫名稱核心，強調學生與長者共同參與活動設計、執行與學習，促進世代交流與互助。
[[全齡社區]] — 計畫願景，旨在透過跨世代參與及環境改善，打造適合各年齡層居住與生活的社區。
[[在地安老]] — 本計畫透過強化社區關懷網絡、提升居住環境安全及提供在地服務，支持長者在熟悉環境中安享晚年。
[[社區陪伴]] — 計畫透過志工探訪、共餐活動及社交網絡建立，提供獨居長者情感支持與社會連結。
[[科技轉譯]] — 本計畫將複雜的智慧科技應用轉化為長者易於理解與操作的工具（如[[智慧型穿戴感測器]]、[[體感遊戲平台]]、ICOPE[[數位遊戲化]]）。
[[永續發展]] — 本計畫透過[[社區活動永續經營]]模式（使用者付費）、[[人才培育]]及[[在地知識]]累積，確保計畫成果能長期延續並對社區產生正面影響。
[[智慧型穿戴感測器]] — 本計畫應用於長者行動力檢測與運動復健的科技工具。
[[體感遊戲平台]] — 本計畫開發用於長者運動復健的互動式科技。
[[數位遊戲化]] — 將傳統篩檢工具（如ICOPE）轉化為趣味互動遊戲，提升長者參與意願。
[[全方位人才培育]] — 計畫從在校學生、社區志工到具教育認證講師的完整人才發展鏈結。
[[社區活動永續經營]] — 透過推動「使用者付費」概念，為社區自主營運奠定基礎，確保活動能長期持續。
[[在地健康飲食文化]] — 透過共餐團隊主動設計健康菜單，推動符合在地特色且有益健康的飲食習慣。
[[跨世代運動課程]] — 結合不同年齡層參與的運動活動，促進世代交流與共同健康。
[[健康社交網絡]] — 透過運動課程及共餐活動，鼓勵長者主動參與，擴大社交圈，提升心理健康。
[[智慧化復健]] — 結合科技（如Rabboni應用程式）進行復健，提升效率與趣味性。
[[高齡健康檢測]] — 運用科技將ICOPE等篩檢工具數位化、遊戲化，提高檢測的參與度與效度。
[[高齡居家安全評估]] — 透過志工培訓與專業評估，找出並改善獨居長者居家環境中的潛在危險。
[[高齡者金融防詐]] — 透過課程與[[防詐桌遊]]，提升長者對金融詐騙的警覺性與辨識能力。
[[自我理財教育]] — 協助長者判讀財務問卷，增強其自主管理財產的能力。
[[防詐桌遊]] — 本計畫開發的互動式工具，用於提升長者防詐認知。
[[居家環境安全]] — 本計畫與[[臺中科技大學]]合作，旨在改善長者居住環境，降低意外風險。
[[長者數位落差]] — 本計畫致力於透過科技應用與教育，縮小長者在數位能力上的差距。
[[社區即第二個家]] — 本計畫推動的理念，強調社區應提供如同家庭般的溫暖與支持。
