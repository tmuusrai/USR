計畫摘要

一、計畫之重要發展歷程（500 字以內）
（一）各期核定預算
教育部推動第三期（112–113 年）大學社會責任實踐計畫獲得核定金額2,500,000 元。
教育部推動第四期（114–116 年）大學社會責任實踐計畫獲得核定金額2,750,000 元。
（二）發展歷程與成果
第三期計畫「輔仁好學、好學新莊」，以「公民好學、環境好學、藝文好學」三主軸來設計行動方案，規劃新莊好學課程地圖及修課路徑，透過課程逐步深化本計畫運作及成果產出，結合本校跨領域學院開設「新莊好學跨領域學程」，發展創新教學方式，增進師生從事參與式社會實踐課程。第三期計畫以建置課程地圖，串聯教師社群、推動教學創新與實踐為主要成果。
第四期計畫「水圳文化的傳承與創新：建構新莊生活環境博物園區」，為實踐生活博物園區之概念，調整教師社群及計畫團隊組成。由景觀設計系（生態與空間設計）、歷史系（文史爬梳與導覽）、博物館研究所（活動策畫與教材設計）、英文系（文化轉譯與國際對接），擇定新莊廟街、樂生院、塭仔圳三大場域，逐年深化實踐與經營，並推動建立青年基地作為培力工作站。成果聚焦於多元培力、地方共學，從教學創新串聯場域實踐、經營與擴散，逐步建構新莊生活環境博物園區，實踐文化傳承與創新。

二、執行內容、進度與成果（500 字以內）
（一）教務與課程執行
113-2 學期至114-1 學期，推動27 門（原定18 門）計畫相關課程，修課學生人數，共計1072 人。
114-1 學期，新莊好學跨領域學分學程、微學分學程及課程地圖，皆依計畫滾動調整並完成送審。
（二）活動執行成果
已執行73 場活動，共2307 人次參與，包含22 場演講、30 場場域活動、3 場共同培力系列活動、3 場工作坊、9 場外部會議、5 場聯合成果展、1 場助理群培力活動。
（三）具體成果產出
10 支地方活動影視紀錄、30 幀地方活動影像紀錄、3 套桌遊（另有2 套開發中）、59 份樂生院景觀設計提案、9 支中英語翻譯影片、1 個Podcast 頻道（8 集內容）、30 份簡報、67 則回饋意見、2 份校外專家學者回饋、1 場雙語營隊、82 份問卷回饋、8 場雙語教學活動、3 件雙語文化作品、30 份植栽設計提案、5 份塭仔圳重劃區公十一規畫提案、5 份塭仔圳重劃區公十一規畫圖。
（四）團隊整合與拓展
本計畫為四個學院之跨領域專業合作，為強化跨院系之合作及執行，共進行15 場內部協調會議（包含11 場教師社群會議、3 場技術工作會議、1 場助理群培力暨工作會議）。114-1 學期，將邀請日文系教師加入，增添團隊執行量能，嘗試對接日本學校。

三、執行成效與亮點（500 字以內）

（一）教學創新實踐
從教務改革到教學創新，本計畫以經費支持教師實踐大學社會責任之精神，連結課程進行社會實踐，形式包含地方走讀、外語導覽、活動策展、雙語教育營隊、桌遊開發、文化產品設計、影音創作與記錄、Podcast 頻道經營、空間規劃、碳匯測量等。
（二）多元培力、地方共學
本計畫持續邀請跨領域專業者、地方場域夥伴、地方局處代表進行多元培力，為地方對接多元的人才、技術與資源，深化地方培力之效果。例如：5 月與新莊保元宮推動月老雙語文化，翻譯看板及御守等皆可由保元宮延續使用，七夕時仍被活用，展現地方培力之成果。
（三）國教端串聯與合作
本計畫串聯丹鳳高中、新莊高中、新莊國小和國泰國小等國教端學校，並結合地方文化與歷史、環境生態與空間設計及永續發展相關課程與活動，提升學生對在地文化的興趣和社會責任感。
（四）公私協力
本計畫以輔大做為平台，持續串聯地方政府、民間社區與團體、產業進行合作，攜手各界共同促進地方發展，擴大執行量能。例如：5 月接獲新北市政府經濟發展局以及城鄉發展局通知，碧江街人行道已變更規劃，並邀請本USR 計畫後續共同參與｢新莊百年風貌整合計畫｣、合作後續復甦新莊街與碧江街之發展規劃。

四、成效評估機制（500 字以內）
本團隊將採用 OKR(Objective Key Result)作為主要的成效評估機制，並於第二年起嘗試使用SROI（Social Return on Investment）輔助進行成效評估。
OKR 是一項「由下而上」的機制，由計畫主持人訂下目標，計畫團隊成員一起思考，確保所有人清楚目標方向。OKR 強調溝通的重要性，達成團隊成員互相溝通。本校已設置管考平台且本計畫主持人與教師社群進行面談，檢討與審視計畫推動執行情況及向校級報告進度。
SROI（Social Return on Investment）是一種衡量計畫社會影響力的評估方法，用以量化非金錢效益的價值。透過分析投入與成果之間的關聯，將教育、環境、文化或社會改變等效益轉換為金額。此方法將有助本計畫展現公共效益、提升資源運用效率，並作為後續決策與永續推動的重要依據。本期計畫第一年將進行利害關係人盤點，並持續提升計畫相關數據之蒐集，以利後續推動SROI 之執行。
成效評估部分，所有參與大學社會責任實踐計畫之課程都已讓學生主動填寫成效評估問卷。問卷架構包含三個概念，分別為「學習動機」、「公民素養」、「內在價值養成」與「課程滿意度」。

五、執行差異分析及因應措施（200 字以內）
（一）跨院系合作橫向溝通與執行協調問題：現已透過定期教師社群會議、助理培力與線上工具強化控管。
（二）原定逐年擴大場域，但因樂生院、塭仔圳陸續推進，造成預算與執行量能趨緊，將尋求外部資源挹注，並與合作單位分擔費用。
（三）培力工作站空間媒合不易，已多方洽詢並找到合適之進駐空間。
（四）臨時人員聘任稍多且流動頻繁，因執行需求後續將調整聘任四位兼任助理，並以專兼任助理為長期培力對象，降低異動並穩定執行人事。

壹、執行內容進度與成果

一、團隊形成與推動機制

（一）計畫實際執行內容與原計畫目標、執行架構及重點工作事項的契合度：
本計畫以水圳文化為核心概念，係因新莊的地方發展與水圳緊密相連，新莊曾因水圳的發展繁榮興盛於清領時期，故曾有「一府、二鹿、三新莊」之盛名。如今的新莊雖有眾多百年廟宇、古宅等豐富歷史遺產，但在地的年輕世代卻普遍並不熟悉地方的文史與內涵，因此本計畫逐年連結場域進行合作與培力，透過地方文史爬梳、空間與生態環境設計、走讀與展覽並結合外語專業進行文化轉譯，實踐生活環境博物館園區（Eco Museum）之概念。本計畫將歷史與生活連結，結合空間規劃與文化轉譯，將新莊古城的文化進行傳承與創新與計畫目標契合度極高。（請參閱附錄）
近年，隨著都市開發新莊的文化地景持續受到衝擊，例如日治時期興建的新莊郡役所已於2021年遭拆除改建為住宅大樓；因此，本計畫團隊於新莊廟街場域，持續與文史工作團體、地方宮廟深化合作，進行文化創新、文史記憶保存與教育。而同樣受都市發展影響的樂生院，在如今重建修繕舊院區後，依舊面對種種挑戰，本計畫今年與樂生院加速合作，透過四個院系的協力投入，陪伴樂生院進行文史爬梳與彙整、周邊環境規劃、活動策展與雙語翻譯等，持續深化合作，建立長期發展夥伴關係。另外，輔大團隊亦積極促成與新北市政府共同修復輔大段之張、劉家古圳路，透過新莊古圳修復深化合作，持續與地方政府倡議地方文化地景的保存。今年協助新北市政府進行塭ㄟ圳故事館布展，並延續塭仔圳重劃區之公園綠地與溪流藍帶，以綠色基礎設施概念帶入碳匯、生態永續等觀念，更推動碳匯教育與實驗，獲得中央及地方政府之肯定。在如此快速變遷的都市發展中，進行文化傳承與創新，並將永續發展精神融入都市發展的歷程，不僅深富教育意義，更是輔大實踐大學社會責任的體現，與計畫目標緊密契合。

（三）整體推動組織架構及協同運作機制，並說明團隊成員之任務分工
輔仁大學校方由學術副校長王英洲教授（計畫主持人）以及教務長蔡宗佑教授（共同主持人）組成行政與資源整合及計畫協調的工作小組，並以大學社會責任計畫總辦公室（USR Hub）的組織架構設立於輔大校園中。總辦公室另外還有一名專案教師以及二位專任助理負責協助校內計畫執行與協調。
在計畫執行層面，則是由顏亮一教授（共同主持人）負責統籌生活環境博物園區的執行，以及四位協同主持人分別負責四個對應策略的課群。本計畫在生活環境博物園區之推動執行由一位專案經理負責，並負責計畫進度管理、帳務管控與助理群統籌及培力。四個課群分別是「全球與在地對話」、「文化轉化與展示」、「生活與歷史環境」、「環境與生態基盤」課群，各由一位兼任助理協助協同主持人，視需求聘任臨時助理進行課程活動支援。

（四）計畫執行團隊與校內行政系統（含校級USR 專責單位）共同推動大學社會責任實踐永續發展之情形
本計畫之執行回應聯合國永續發展指標SDG 4優質教育、SDG 11的永續城市與社區、SDG 13氣候行動。

1.SDG 4優質教育：本計畫透過校內USR 辦公室，持續與各大專院校進行跨校共學，如與文藻、靜宜進行三校跨校共學，至暨南大學進行標竿學校交流、至海洋大學參與共培暨SIG 交流論壇活動、參與淡江大學舉辦之北區地方學工作坊等，藉由與各校請益之經驗，進行教學創新及調整。本計畫推動之「新莊好學跨領域學分學程」，循序滾動調整以做中學為亮點，鼓勵教師進行社會實踐導向之課程。本計畫不僅以經費支持本校教師開展與計畫相關之課程與教學創新，更透過與國教端合作，將永續發展概念向下扎根，實踐SDG 4優質教育內涵。

2.SDG 11永續城市與社區：本計畫不僅以實作課程為社區雙語能力進行提升，更與新莊保元宮合作推動月老文化之轉譯，且透過雙語導覽為地方文化對接國際作鋪陳；另外，亦將永續概念以雙語教育營進行推廣，打造新莊永續雙語及國際化共學機制，對應SDG 11的永續城市與社區項目。

3.SDG 13氣候行動：配合政府2050淨零政策以及輔大永續發展目標，本計畫結合輔大USR 與教育部計畫，推廣碳匯教育，導入生態設計課程，帶領學生於塭仔圳重劃區中心區位的輔仁大學建置校園喬木及土壤碳匯基線值工作以及提出塭仔圳地區之土壤改良計畫，以利後續計算碳吸存量，協助場域計算是否達成碳中和，建置完成後之成果與經驗提供新北市政府低碳中心推動低碳城市之目標。本計畫教學過程中與新北市光仁中學合作碳匯教育，參加新北市公私立高中職全球公民培力暨學生倡議行動決賽，獲得教育部特優第一名獎之支持與鼓勵，持續滾動使各界透過USR 計畫之執行，實踐SDG 13氣候行動。

（五）計畫協調機制與落實情形
首先，本計畫主持人王英洲學術副校長持續透過參與教師社群會議引導計畫開展，並由本校USR 專責辦公室協助，已召開4次跨計畫之分享會，協調各計畫之執行、增進各計畫之橫向串聯，並分享成果號召更多教師參與USR 計畫。其次，由共同主持人蔡宗佑教務長協助計畫團隊與教務處協調，推動計畫課務調整及加速教務行政之執行；最後，由共同主持人顏亮一副總務長負責推動教師社群，進行跨院系計畫之討論與協調執行。本計畫之執行整合四個院系專業，整合難度較高，但目前透過每月教師社群會議，並新增助理群培力及工作會議，已有效進行協調並掌握執行進度。

參、成效評估機制

一、評估計畫成果與成效之機制與資料蒐集方法

（一）個案計畫成果資料蒐集的系統化流程和執行情形
本團隊將採用 OKR(Objective Key Result)作為主要的成效評估機制，並於第二年起嘗試使用SROI（Social Return on Investment）輔助進行成效評估。
OKR 是一項「由下而上」的機制，由計畫主持人訂下目標，計畫團隊成員一起思考，確保所有人清楚目標方向。OKR 強調溝通的重要性，達成團隊成員互相溝通。本校已設置管考平台且本計畫主持人與教師社群進行面談，檢討與審視計畫推動執行情況及向校級報告進度。
SROI（Social Return on Investment）是一種衡量計畫社會影響力的評估方法，用以量化非金錢效益的價值。透過分析投入與成果之間的關聯，將教育、環境、文化或社會改變等效益轉換為金額。此方法將有助本計畫展現公共效益、提升資源運用效率，並作為後續決策與永續推動的重要依據。本期計畫第一年將進行利害關係人盤點，並持續提升計畫相關數據之蒐集，以利後續推動SROI 之執行。

（二）個案計畫成效資料的評估面向和方法的適切性與可行性
在成效評估的部分，所有參與大學社會責任實踐計畫之課程都已讓學生主動填寫成效評估問卷。問卷架構包含三個概念，分別為「學習動機」、「公民素養」、「內在價值養成」與「課程滿意度」。問項皆為李克特尺度，一分代表非常不同意，五分代表非常同意。在階段性課程結束後，在學生願意的前提下，學生會在線上進行問卷的填寫。

二、各類型利害關係人意見蒐集之辦理方式與回饋機制
本計畫針對課程評估的調查為階段性作業的問卷與開放式意見回饋，大部分課程都有期中報告，因此會有較為具體的成效評估。

（一）各類型利害關係人調查的分析結果回饋機制
在分析結果中，三個面向（文化永續議題與跨文化素養核心理念、永續議題融入雙語教學知能與態度、以及永續議題結合跨文化素養於雙語教學之社會實踐）的平均數皆介於3.78至4.23之間（五分量表中，一分為非常不同意，五分為非常同意），整體分數顯示參與者對於課程內容與教學整合的認知與態度呈現正向傾向。標準差約介於0.8至1.1之間，顯示多數參與者的回覆具一致性。
在三個面向中，文化永續議題與跨文化素養核心理念的平均數最高（前測M=3.97，後測M=4.23），顯示學生對文化永續與跨文化素養核心概念的理解最為成熟；永續議題融入雙語教學知能與態度部分（前測M=3.91，後測M=4.07）則反映出學生對永續議題與教學設計之間的關聯性有明顯提升；而永續議題結合跨文化素養於雙語教學之社會實踐雖為三者中平均數最低（前測M=3.78，後測M=4.06），但成長幅度最大，代表學生在實際應用與社會行動層面上逐漸建立信心與策略。

（二）制訂利害關係人意見反映機制的辦理情形
本計畫積極建立成效評估機制，透過社區居民與學生的回饋，持續檢視與調整活動內容，以監測參與度並吸引更多民眾投入，進而擴大社會責任的實踐範圍。社區意見回饋可確保活動具實質助益，評估結果亦作為改進依據，用以優化課程設計、提升工作坊互動性及調整講座主題，使活動更貼近地方需求並實現大學社會責任核心目標，促進社會參與與社區發展，同時培養學生對地方文化之興趣與社會責任感。（請參閱附錄）
