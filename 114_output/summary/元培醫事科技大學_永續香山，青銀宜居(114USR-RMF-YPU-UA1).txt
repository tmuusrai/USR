# 元培醫事科技大學 114 年度 USR 計畫執行成果報告
**計畫名稱：永續香山，青銀宜居**

## 一、計畫基本架構與目標

本計畫為元培醫事科技大學推動之大學特色類萌芽型計畫，以「永續香山，青銀宜居」為核心目標，結合醫護、健康及福祉學院等跨學科專業，建構包含「人才培育」、「環境永續」、「走讀香山」與「高齡友善」四大互補支援的主軸策略。計畫期許透過師生深耕社區、跨世代交流與科學技術導入，解決新竹市香山區在地高齡健康照護、環境衛生與生態文化傳承等議題，打造青銀共榮之宜居社區。

- **計畫名稱**：永續香山，青銀宜居
- **計畫類型**：大學特色類萌芽型計畫（新興計畫）
- **計畫期程**：114年1月1日至114年9月30日（報告統計期程）
- **核心議題**：在地關懷
- **關聯 SDGs**：
  - SDG 3 良好健康與福祉
  - SDG 4 優質教育
  - SDG 12 負責任的消費及生產
- **實踐場域**：
  - **固定實踐場域**：新竹市香山區東香社區發展協會、香山區香村社區發展協會、香山區大庄國小、香山區南隘國小。
  - **擴展與應用場域**：新竹市香山區香山社區發展協會、香山內湖日照中心、青青草原（生態環境應用場域）。

---

## 二、核心執行內容與數據成效

### 1. **人才培育與永續微學程建置**
整合跨院系教學資源，成立微學程並推動永續相關課程，培養學生解決在地實務問題之能力，同時將永續發展理念向下札根至國小學童。

| 指標項目 | 具體執行數據與成果 |
| :--- | :--- |
| **學程成立** | 成立「綠色健康永續人才微學程」與「ESG淨零永續微學程」共2個微學程。 |
| **課程開設** | 開設「ESG永續管理」（24人修課）、「銀髮健康促進」、「環境生態學」、「水質分析實驗」等共13門相關課程，總計修課人次達300人次以上。 |
| **國小教案開發** | 研發「SDGs對對碰」與「永續大富翁」2套永續桌遊教案，於合作國小試行。 |
| **師生研習與活動** | 辦理國小師生永續教育活動6場次，共計 374 人次參與。 |

---

### 2. **環境永續與公共衛生改善**
將校內環境衛能與生技專業技術導入實踐場域，針對合作國小進行環境品質優化，並對區域指標景點進行生態水質監測。

| 指標項目 | 具體執行數據與成果 |
| :--- | :--- |
| **場域設備建置** | 於大庄國小及南隘國小裝設「高氧化力分子生成裝置」，改善場域空氣品質與環境菌數。 |
| **衛生改善檢測** | 執行校園異味調查與除臭改善場域活動3場次，服務 21 人次，顯著降低環境中細菌與黴菌量。 |
| **生態水質監測** | 針對青青草原生態池進行水質採樣與優氧化檢測，檢測發現池水總磷已達富營養化標準，並提出進排水管控建議。 |

---

### 3. **走讀香山與生態文化調查**
結合通識文史與環工系所團隊，開展青青草原生態多樣性調查，並深入社區進行耆老口述歷史紀錄，累積在地文史與生態資產。

| 指標項目 | 具體執行數據與成果 |
| :--- | :--- |
| **生態調查行動** | 於青青草原執行約32次動植物生態調查（累積場域生態活動35場次，共 176 人次參與），完成步道兩側1公尺內生態分布初步報告。 |
| **文史調查與培訓** | 開設「我手寫我口」通識課程培訓口述歷史訪員（50人修課），完成 5 份香山社區耆老口述歷史初稿。 |

---

### 4. **高齡友善與健康促進推動**
由高齡健康照護與醫管等系所師生進駐社區關懷據點與日照中心，導入肌力訓練、心理健康與節慶融入式健康促進課程。

| 指標項目 | 具體執行數據與成果 |
| :--- | :--- |
| **社區據點服務** | 於東香、香村據點及內湖日照中心執行高齡健康促進與永續教育共 27 場次，累計服務長者達 849 人次。 |
| **跨世代共融** | 於4月2日配合南隘國小辦理 1 場老幼共融活動，促進跨世代交流與社區凝聚力。 |

## 三、技術創新或特色亮點

1. **分齡互動式永續教育遊戲教案**
   - **執行方式與技術**：開發「SDGs對對碰」與「永續大富翁」兩套原創桌遊，將複雜的國際永續指標（SDGs）轉化為分齡互動遊戲，引導國小低、高年級學童於遊戲中學習環境保護與永續概念。
   - **社會價值**：降低永續教育門檻，建立可複製、可推廣至各小學的模組化永續教案。

2. **高氧化力分子生成技術導入場域除臭與抑菌**
   - **執行方式與技術**：將生技與環工團隊之技術研發成果（高氧化力分子生成裝置）實際應用於大庄與南隘國小場域，透過定期菌數落塵檢測與異味指標監控進行科學驗證。
   - **社會價值**：有效降低校園環境細菌與黴菌密度、消除異味，實質提升學童與教職員之公共衛生環境品質。

3. **「高齡上下肢循環運動」與節慶融入式健照模組**
   - **執行方式與技術**：因應高齡者肌少症風險，由學生團隊自主規劃一套「高齡上下肢循環運動」，自編動作流程與輔具；並結合端午節（包粽與營養教育）及中秋節（柚子皮再利用環保教學）開辦活動。
   - **社會價值**：具高度複製與推廣彈性，促進高齡者延緩失能，同時達到環保、健康與文化傳承三重效益。

## 四、資源鏈結與經費執行

- **外部資源鏈結**：與新竹市香山區東香社區發展協會、香村社區發展協會、香山社區發展協會、大庄國小、南隘國小等5個單位簽署合作意向書/議定合作，並與中華大學、清華大學、輔英科技大學等校進行跨校 USR 交流。
- **計畫總經費（教育部補助款 + 學校配合款）**：核定總額 NT$ 2,750,000 元。
- **實際執行金額**：NT$ 774,908 元。
- **整體執行率**：**28.18%**（其中教育部補助款核定 250 萬元，執行 774,908 元，執行率 31%；學校配合款 25 萬元，執行 0 元）。
- **剩餘經費主要用途說明**：因報告期程僅統計至114年9月30日，剩餘經費將於第四季（10–12月）用於支應各分項課程結案、期末利害關係人質性訪談與滿意度調查分析報告編撰、場域持續性活動採購及年底計畫成果展辦理等支出。

## 五、成效評估機制

計畫建立多元質定量管考機制，並由隸屬校務暨永續發展中心之「永續暨社會責任辦公室」進行每月追蹤與管考：
1. **量化指標追蹤**：定期統計活動場次、參與人次、修課人數及滿意度問卷。
2. **健康與生理數據評估**：於期初針對社區據點長者進行身體組成檢測、肌力測試與心理狀態問卷，作為活動前後效益差異分析之基線。
3. **科學量測數據**：定期追蹤國小高氧化力裝置裝設前後之環境菌落數變化，以及青青草原生態池之水質檢測數據（如總磷濃度）。
4. **質性評估**：針對教師、學生、社區據點負責人及長者等利害關係人進行深度訪談，了解計畫對在地社區帶來的實質改變，作為後續計畫策略調整之依據。
