# 國立臺灣大學「尋找雲林農村生命力 – 永續農村營造計畫」
## 114年度執行成果分析報告

### 一、計畫基本架構與目標

本計畫由國立臺灣大學整合校內跨領域專業能量，深耕雲林在地農牧產業。計畫以「植物醫學」與「動物醫學」雙核心團隊為主軸，鏈結園藝、食科、生傳與農碳等子團隊，建構「產地到餐桌」的完整輔導體系，致力於解決在地病蟲害、畜禽疫病、採後保鮮及淨零減碳等產業痛點，促進雲林農村之永續發展與產業升級。

- **計畫名稱**：尋找雲林農村生命力 – 永續農村營造計畫
- **計畫類型**：永續發展類特色永續型計畫（深耕型/特色永續型）
- **計畫期程**：114年1月1日至114年9月30日（本期報告期程）
- **核心議題**：產業鏈結與經濟永續
- **關聯 SDGs**：
  - SDG 2 零飢餓
  - SDG 4 優質教育
  - SDG 12 負責任的消費及生產
- **實踐場域**：
  - **固定實踐場域**：雲林縣莿桐鄉（莿桐鄉農會）、雲林縣元長鄉（元長崙仔社區、元長產銷班）、雲林縣斗南鎮（斗南農會）。
  - **合作擴展與其他場域**：雲林縣褒忠鄉（新湖合作農場）、慈心大自然莊園、山哥農場、宏昇芽菜、子茂合作社等。

---

### 二、核心執行內容與數據成效

本計畫將技術實作直導場域，具體執行成果劃分為四大核心領域：

#### 1. **植物健康管理與田間診療服務**
由植醫團隊深入雲林第一線農地，針對蒜頭、竹筍、花生等重點作物推動脫毒與病害防治計畫，辦理安全用藥講習與農藥快檢服務，降低資材成本並提升作物食安價值。

| 指標項目 | 執行成效與數據 |
| :--- | :--- |
| **田間診斷服務件數** | 累計執行 **271 件** |
| **技術輔導覆蓋面積** | 約 **134.7 公頃** |
| **主要合作對象** | 莿桐鄉農會、元長產銷班、山哥農場等 |

#### 2. **經濟動物疾病防控與生物安全防線**
動醫團隊建置動物疾病診斷中心，提供精準血清學與分子檢測，實施雲林在地送檢半價優惠與免費防疫輔導；推動牧場生物安全與在地屠宰鏈結，降低運輸碳排放。

| 指標項目 | 執行成效與數據 |
| :--- | :--- |
| **禽畜精準診斷件數** | 累計達 **5,981 件**（含血清、分生及病理診斷） |
| **在地人才培育** | 辦理「雲林縣動物醫事助理培訓班」（**216小時**認證班） |
| **產官學研合作會議** | 與雲林縣防疫所召開 **2 場次**，產官學參人次達 **30 人次** |

#### 3. **農業低碳轉型與碳足跡盤查**
農碳團隊（生工系）於慈心大自然莊園設置低碳示範區，導入間歇灌溉（AWD）、稻稈移除及紙質抑草蓆等減碳工法，並建置碳監測系統，協助在地農企業建立產品碳足跡基線。

| 指標項目 | 執行成效與數據 |
| :--- | :--- |
| **低碳示範基地** | 慈心大自然莊園（建置減碳技術與監測系統） |
| **輔導碳盤查企業** | 新湖合作農場（美生菜、水耕草莓）、宏昇芽菜 |

#### 4. **農產加值、品牌行銷與食農教育**
園藝與食科團隊協助改善採後冷鏈與保鮮技術（如解決芽菜病原菌與儲藏期問題），並與莿桐鄉農會合作開發黑蒜精等保健機能食品；生傳團隊則培訓食農教育種子教師，拍攝 USR 紀錄片擴大社會影響力。

| 指標項目 | 執行成效與數據 |
| :--- | :--- |
| **團隊工作與對外會議** | 辦理內部工作會議、產學合作會議及市集討論會等共 **13 場次**，累計 **194 人次** 參與 |
| **外部資源交流活動** | 辦理「多元健康 ESG 創新實踐論壇」（雲林縣長張麗善及多位專家出席） |

### 三、技術創新或特色亮點

1. **植動醫雙核心「現場即診與精準防疫」機制**
   結合跨領域專業，提供田間現場巡診、病蟲害診斷與動物血清/分子檢測。搭配半價補貼與質譜快檢車鏈結，讓農牧戶能以低成本獲得高階醫療級診斷，有效降低用藥量並防範大規模疫病。

2. **農業低碳與循環經濟示範模組**
   整合間歇灌溉、紙質抑草蓆等低碳農法，並將畜牧廢棄物（糞尿）資源化、沼氣利用與有機副產物飼料化導入 ESG 輔導實務，為在地合作農場提供自願性碳盤查與產品碳足跡計算基線。

3. **全齡階梯式「產藥醫育一體」培力系統**
   開創從國小食農教育、大學生田間診斷實習、到產業端「216小時動物醫事助理認證班」的完整人才鏈，實質補足在地獸醫與農業技術人力的缺口。

### 四、資源鏈結與經費執行

本計畫積極鏈結地方政府、民間基金會與農企業，經費執行狀況如下（期程截至114年9月30日）：

#### 經費執行明細表
- **教育部補助款（經常門）**：核定 9,500,000 元，實際執行 4,908,142 元（執行率 **51.66%**）
- **學校配合款（自籌款）**：核定 950,000 元，實際執行 339,389 元（執行率 **35.73%**）
- **計畫總經費**：核定 **10,450,000 元**，實際執行 **5,247,531 元**（整體執行率 **50.22%**）

#### 外部資源引入與募款
- **對外募款目標**：500,000 元（占補助款 5%）
- **實際募款金額**：130,000 元（目前運用金額 0 元）
- **合作與資源挹注單位**：財團法人豐泰基金會（自籌款合作討論）、雲林縣政府農業處、雲林縣動植物防疫所。

#### 剩餘經費用途說明
由於本報告截至9月30日，剩餘約 **49.78%**（約520萬元）經費將用於第4季辦理之 USR EXPO 北區成果展、黑蒜精動物實驗與檢驗費、田間巡診車輛維護與耗材、後續多場農業講習會及專任助理與學生兼任助理薪資結算。

### 五、成效評估機制

計畫建立多重檢驗機制，確保成果具備可追溯性與社會效益：

1. **量化 KPI 追蹤**：每月追蹤診斷件數（植醫271件/動醫5,981件）、輔導面積（134.7公頃）及會議場次等硬指標。
2. **質性回饋與問卷**：透過農民滿意度問卷與 USR 微電影紀錄，評估農企與青農對技術落地之實際感受。
3. **SROI 社會投資報酬率**：導入 SROI 工具對核心輔導案例進行經濟與社會效益量化評估。
4. **AA1000 利害關係人議合**：採用 AA1000 標準（包容性、重要性、回應性），並以李克特五點量表（平均 **3.5 分**為決策採納門檻）評估間接受益者意見，定期將結果回饋校內永續辦公室與地方政府。
