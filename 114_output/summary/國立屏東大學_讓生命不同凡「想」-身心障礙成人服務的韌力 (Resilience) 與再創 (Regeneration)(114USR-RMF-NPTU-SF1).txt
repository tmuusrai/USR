# 教育部推動第四期（114–116年）大學社會責任實踐計畫
## 114年度執行成果重點報告

### 一、計畫基本架構與目標
本計畫立基於《身心障礙者權利公約》（CRPD）精神與生態系統理論，以「身心障礙成人」為核心，深耕屏東並擴散至澎湖、臺東與海外。計畫整合跨領域師生資源與社福機構，建構包含「i自立、i健康、i心靈、i家庭、i永續、i夥伴」之六大支持體系，致力提升身障者自立韌力、家庭支持與場域永續再創。

- **計畫名稱**：讓生命不同凡「想」-身心障礙成人服務的韌力 (Resilience) 與再創 (Regeneration)
- **計畫類型**：永續發展類特色永續型計畫（深耕/特色永續型）
- **計畫期程**：114年1月1日至114年9月30日（本階段報告期程）
- **核心議題**：在地關懷
- **關聯 SDGs**：
  - SDG 4 優質教育
  - SDG 8 合宜工作與經濟成長
  - SDG 10 減少不平等
  - SDG 17 促進目標的夥伴關係
- **實踐場域**：
  - **國內固定場域**：
    1. 屏東縣屏東市：社團法人屏東縣啟智協進會
    2. 屏東縣屏東市：財團法人屏東基督教勝利之家
    3. 臺東縣臺東市：社團法人台東縣智障者家長協會
    4. 澎湖縣馬公市：澎湖縣私立財團法人天主教澎湖教區附設惠民啟智中心
  - **國外固定場域**：馬來西亞吉隆坡：雙福升維發展協會
  - **合作擴展場域**：國內2所高中（USR協作平台與共融社團）、馬來西亞拉曼大學（UTAR）、日本信州大學（線上交流）、民眾醫院。
### 二、核心執行內容與數據成效

本計畫共集結來自 8 校 26 位跨領域教師、1 位專案經理及 3 位專任助理共同運作，推動四大核心執行面向：

#### 1. **跨域人才培育與雙證照創新教學（學分學程）**
結合特教、心理、體育、電通、行銷等學系，開設「身心障礙者服務創新學分學程」，實施「三級三審」課程品保機制，並與屏東縣政府社會處及職能治療所合作，培育具備身心障礙教保人員及延緩失能指導員資格之跨域人才。

| 指標項目 | 具體數據成效 |
| :--- | :--- |
| **開設課程數量** | 114年度共開設 **17 門** 實務融入課程 |
| **課程變更調修** | 新增 **5 門** 課程（跨領域中心、電通系、教育系各1門，文創系2門），刪減2門 |
| **學生修課人次** | 累計 **605 人次** 參與課程 |
| **證照與學程取得** | **9 人** 取得雙證照、**6 人** 順利修畢學分學程 |

#### 2. **智青自立倡議與家庭/心靈支持網絡（i自立、i家庭、i心靈）**
以智青（心智障礙青年）為主體辦理自立生活營隊與自我倡議培力，同時針對照顧者與機構服務人員提供創傷知情培訓、個別心理會談與支持團體。

- **共融與營隊活動**：與場域及合作高中辦理 **36 場** 活動，累計 **1,230 人次** 參與。
- **家庭與心理支持**：完成 **3 場** 家庭論壇、**3 場** 照顧者支持團體、**3 場** 社區共融活動，並持續辦理個別心理會談。
- **管考與共務會議**：辦理 **5 場** [i家庭][i心靈]工作會議（58人次）、**1 場** [i自立]工作會議（27人次）。

#### 3. **科技健康促進與永續在地產品開發（i健康、i永續）**
研發適應性體能與體感互動科技，並導入農業副產物循環利用概念，輔導場域開發高附加價值商品與行銷通路建立。

- **科技輔助健康**：於場域及民眾醫院設置 **AR牆面投影互動系統**，設計健康訓練分級課程。
- **永續產品開發**：研發「花生藤保濕噴霧」、「檸檬手抄紙擴香片」、「擦澡巾」等特色產品。
- **子計畫會議與培力**：辦理 **5 場** [i永續]工作會議（41人次），完成課程與場域產品宣導影片拍攝。

#### 4. **文化平權易讀服務與國際/跨校合作（i夥伴）**
推動資訊無障礙，發行易讀教材並推動影音化；強化跨校 SIG 社群及跨國 USR 模式移轉。

- **易讀教材研發**：累計開發與更新 **6 本** 易讀教材（含《一起出遊》1~4冊、《居家安全:求助技能》、《健康體適能》），並由師生與智青共創完成「屏東縣立圖書館導覽易讀手冊」。
- **國際交流移轉**：114年6月16–23日師生赴馬來西亞與拉曼大學及雙福升維發展協會合作（分為健康促進組與社區共融組）；10月辦理跨國 USR 成果分享（含日本信州大學）。
- **跨校與夥伴會議**：辦理 **2 場** SIG共培活動、**5 場** 跨校教師專業學習社群、**2 場** 國內夥伴大學會議（49人次）、**3 場** 跨國夥伴大學會議（70人次）。
### 三、技術創新或特色亮點

1. **跨域雙證照人才培育機制**
   - **創新內容**：打破單一學門藩籬，結合特教與體育專業，學生修畢指定學程即可同時考取「身心障礙教保人員」與「延緩失能指導員」雙證照。
   - **社會價值**：精準對接超高齡社會與身障老化之雙重照顧需求，縮短學用落差。

2. **AR體感互動與智能科技融入場域復健健康促進**
   - **創新內容**：由電通系與特教系團隊共同研發AR牆面投影互動系統，將功能性體能訓練遊戲化、數位化。
   - **社會價值**：降低身障成人運動阻力，提升持續復健意願，並建立體能動作評估之數據資料。

3. **農業廢棄物再創（Regeneration）與永續經濟自立**
   - **創新內容**：結合行銷專業與在地農特產，利用廢棄花生藤萃取研發「花生藤保濕噴霧」及「檸檬手抄紙擴香片」。
   - **經濟價值**：協助機構建立自有產品品牌與電商通路，實現身障者參與生產過程之職能賦能與經濟自立。

4. **智青共創之文化平權「影音化易讀服務」**
   - **創新內容**：首創由大學師生與智青共同擔任「易讀審辦員」，將複雜的圖書導覽與生活資訊轉換為易讀圖文與影音教材。
   - **社會價值**：實踐 CRPD 資訊平權，促進心智障礙者自主參與社會文化活動。

### 五、成效評估機制

計畫建立量化與質化並行之評估機制，並與校級「大武山社會實踐暨永續發展中心」深度連結，導入 **SROI（社會投資報酬率）** 架構，分為三年期推進：
- **114年（架構建置期）**：盤點利害關係人、建立投入與產出（OUTPUT）及成果（OUTCOMES）事件鏈，評估項目包含學生「學分學程核心能力指標」、「CRPD知能檢核表」、教師「教學效能評估表」、場域機構焦點訪談及團體諮商滿意度調查。
- **115年（模型深化期）**：優化數據整合與回饋修正機制。
- **116年（成效整合期）**：產出校級社會影響力報告，並匯入校務研究（IR）資料庫。
