# 東南科技大學「樂齡樂活：跨世代交流服務培力計畫」114年度執行成果報告

## 一、計畫基本架構與目標

本計畫為教育部第四期（114–116年）大學社會責任（USR）萌芽型計畫，旨在承接東南科技大學自101年起之樂齡大學經驗，盤點高齡者於「健康管理、飲食、運動、人際、靈性」五大核心需求。計畫透過大學跨專業領域之整合，以「青銀共學」與「跨世代交流」為核心，致力於提升在地銀髮族之健康識能與生活品質，減少慢性病風險並培育具社會關懷與實務能力之跨域人才。

- **計畫名稱**：樂齡樂活：跨世代交流服務培力計畫
- **計畫類型**：大學特色類萌芽型計畫
- **計畫期程**：114年1月1日至114年9月30日（本報告期程；整體計畫為114–116年，採「2025啟動、2026深化、2027整合」三階段推動）
- **核心議題**：在地關懷、高齡化社會福祉、跨世代共學、健康促進與在地產業加值
- **關聯 SDGs**：
  - SDG 2：消除飢餓（推廣營養與在地友善食材）
  - SDG 3：良好健康與福祉（健康促進與高齡身心療癒）
  - SDG 4：優質教育（終身學習與青銀共學）
  - SDG 11：永續城市及社區（高齡友善社區建構）
  - SDG 12：責任消費與生產（在地食材加值與永續飲食）
  - SDG 17：多元夥伴關係（跨界醫療、社區與衛政合作）
- **實踐場域**：
  - **固定實踐場域**：新北市深坑區東南科技大學校園（體適能中心、專業教室）
  - **合作擴展場域**：新北市深坑區、石碇區、平溪區、淡水區、汐止區（汐止老人會）；臺北市文山區（萬芳醫院長照病房、文山區健康服務中心）
## 二、核心執行內容與數據成效

本計畫整合四大子計畫，採取「課程+活動」雙軌推動，執行內容與量化成效如下：

### 1. **智慧探索子計畫（應用英語系主導）**
- **執行內容說明**：以「青銀共學」為核心，結合「旅遊導覽英文」等專業課程，帶領長者進行深坑、石碇、淡水古蹟及平溪之文化走讀。透過英文老歌教唱、在地文史解說與行動 App 數位導覽工具，促進長者終身學習與數位融入，同時提升學生英文導覽與溝通實務能力。
- **量化成效與數據**：

| 項目 | 執行說明與數據成效 |
| :--- | :--- |
| **活動場次與人次** | 辦理 4 場「青銀共學智慧探索」研習參訪，總參與人次達 **155 人次**（各場為 43、42、35、35 人）。 |
| **青銀配對比例** | 採小組陪伴模式（約 1:2～1:3 配對），如 7/23 場次包含長者 **25 人**、學生 **8 人**、教師 **2 人**。 |
| **合作單位** | 汐止老人會、在地社區據點。 |
### 2. **活力銀髮子計畫（表演藝術系主導）**
- **執行內容說明**：導入「醫養藝結合」模式，學生小隊深入萬芳醫院長照病房進行移動式互動演出（如「釣粽FUN端午」、母親節懷舊金曲、小丑默劇）；並與文山區健康服務中心合作推動「樂齡故事劇場」，經由 10 週戲劇課程引導長者書寫生命故事並登台展演，建立自信。
- **量化成效與數據**：

| 項目 | 執行說明與數據成效 |
| :--- | :--- |
| **醫院關懷演出** | 端午場動員 **7 名**師生；母親節場由 **5 名**師生與外聘歌手演出，服務約 **20 名**住院長者與醫護人員。 |
| **樂齡故事劇場** | 進行 10 週課程，直接培育 **24 名**長者學員、投入 **6 名**工作人員，於 114 年 9 月校內成果展吸引超過 **100 名**社區民眾與師生觀賞。 |
| **合作單位** | 萬芳醫院、臺北市文山區健康服務中心。 |
### 3. **健康共築子計畫（休閒事業管理系主導）**
- **執行內容說明**：結合「健身教練理論與實務」課程，於校內體適能中心辦理「樂齡體適能體驗營」。採分站一對一或一對二指導模式，提供個別化肌力與平衡訓練，並深入社區示範居家運動，同時輔導學生考取專業證照。
- **量化成效與數據**：

| 項目 | 執行說明與數據成效 |
| :--- | :--- |
| **服務人次與對象** | 累計服務 **300 人次**，涵蓋 **60 位**不重複社區長者（年齡 60–75 歲，平均參與 5 次）。 |
| **學生參與與考照** | 每場投入約 **20 名**大三與大四學生；成功輔導 **21 名**學生考取「運動科技樂齡指導員」等專業證照。 |
| **場域運用** | 本校中正大樓 B1 體適能中心。 |
### 4. **樂齡樂享子計畫（餐旅管理系主導）**
- **執行內容說明**：融合「產品創新研發」課程，運用深坑在地豆腐與茶葉（鐵觀音）等食材，研發高齡友善餐點與伴手禮（如鐵觀音巧克力塔）。開設果凍花藝跨代共學課程，並組隊參加餐飲競賽，傳承在地飲食文化。
- **量化成效與數據**：

| 項目 | 執行說明與數據成效 |
| :--- | :--- |
| **師生與長者參與** | 由 **12 位**系上教師主導，果凍花工作坊每梯次 **17–30 人**（長者 7–10 人、學生及人員 10–20 人）；茶文化封茶體驗動員 **22 名**學生。 |
| **競賽展演** | 跨代組隊參加「臺南美食之都」、「國際菁英盃」等餐飲藝術競賽。 |
| **合作單位** | 深坑在地茶園、社區發展協會。 |
## 三、技術創新或特色亮點

1. **「醫養藝」三位一体之療癒介入模式**：
   - *執行方式*：打破傳統表演形式，由表演藝術系師生深入萬芳醫院病房進行「多點移動式」微型演出與床邊互動；同時導入樂齡故事劇場，將長者生命經驗轉化為舞台劇本。
   - *社會/經濟價值*：舒緩住院長者焦慮、優化醫事照護環境，並提供長者自我價值重塑的舞台，創立「衛政—社區—大學—醫院」四方共好之可複製模式。

2. **學用合一之「運動科技與檢測考證一體化」**：
   - *執行方式*：將校內專業體適能中心開放為社區共享基地，結合專業課程，由學生提供長者一對一客製化肌力訓練，並直接對接「運動科技樂齡指導員」證照考照機制。
   - *社會/經濟價值*：有效減緩長者肌少症與跌倒風險，同時促進學生高薪就業專業技能，達到「長者獲健康、學生得證照」雙贏。

3. **「產地到餐桌」高齡友善飲食與在地農產加值**：
   - *執行方式*：結合深坑在地茶產業與豆腐產業，由餐旅系師生研發低油、低鹽、高纖且易咀嚼的樂齡飲食與鐵觀音伴手禮，並引入果凍花藝術進行跨世代藝術共學與國際競賽。
   - *社會/經濟價值*：帶動在地茶農與特色產業加值，創造樂齡養生飲食新商機，促進跨世代文化交流。

## 五、成效評估機制

計畫建立「先表單、後平台」的雙層數據蒐證模式，將各場次單場報告書資料匯入 CIP 資訊平台與儀表板，進行數據驅動與定期內部稽核。

**評估發現之重要結論**：
1. **量化指標大幅超標**：114年度核心 KPI 多已達標或超標，如整體服務人次達 **415 人次**（預標 450 人次，後續月分即能超越）、學生志工參與 **57 人**（目標 50 人）、學生考照 **21 人**。
2. **質性轉變顯著**：「青銀共學」顯著消融跨世代刻板印象。長者在年輕學生陪伴下降低了對數位工具與英語學習的恐懼；學生則培養出深刻的同理心與社會責任感。
3. **敏捷滾動調整**：依據參與率檢討，及時修正「智慧探索」之活動節奏與App教學方式，使社區長者參與意願顯著提升。
