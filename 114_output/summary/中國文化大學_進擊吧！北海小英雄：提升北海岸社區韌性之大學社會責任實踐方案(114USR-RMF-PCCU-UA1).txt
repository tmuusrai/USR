這是一份根據中國文化大學「進擊吧！北海小英雄：提升北海岸社區韌性之大學社會責任實踐方案」114年度執行成果報告書所整理的詳細執行成果報告：
# 中國文化大學 USR 計畫執行成果報告

## 一、計畫基本架構與目標

本計畫以「為北海岸教育而教」（Teaching for North Coast, TFNC）為核心哲學，聚焦於北海岸（三芝、金山、萬里）少子化、長者高齡化及產業轉型等議題。透過大學學術資源整合，建構優質教育行動區，推動在地知識永續、經濟創生韌性與在地陪伴，實踐大學與地方共學共好之永續願景。

*   **計畫名稱**：進擊吧！北海小英雄：提升北海岸社區韌性之大學社會責任實踐方案
*   **計畫類型**：大學特色類萌芽型計畫
*   **計畫期程**：114年1月1日至114年9月30日（第四期 114–116年）
*   **核心議題**：在地關懷
*   **關聯 SDGs**：
    *   SDG 4：優質教育
    *   SDG 10：減少不平等
    *   SDG 11：永續城市及社區
*   **實踐場域**：
    *   **固定場域**：
        1. 新北市三芝區：三芝故事館
        2. 新北市金山區：新北市立金山高級中學
        3. 新北市金山區：金包里慈護宮
        4. 新北市金山區：浪金山
        5. 新北市萬里區：新北市立萬里國民中學
        6. 新北市萬里區：萬里區公所
    *   **合作擴展場域**：新北市石門區公所、新北市立瑞芳高級工業職業學校、臺北市大龍國民小學。
## 二、核心執行內容與數據成效

本計畫聚焦三大行動主軸與跨校鏈結，執行成效與數據彙整如下：

### **1. 深化在地知識永續與永續教材研發**
結合全校必修跨域模組與微學分課程，將地方知識轉化為創新教具與教材。本年度開辦「三芝學」課程，研發北海岸特色桌遊與繪本，並推廣至都市與偏鄉國中小學。

| 指標項目 | 具體數據成效 |
| :--- | :--- |
| **開設課程與修課** | 開設跨域模組「三芝學」課程 3 門，修課學生數 38 人 |
| **永續教材研發成果** | 完成《北海岸軟絲復育桌遊》1 套、《北海岸大氣知識繪本》1 套 |
| **校園推廣效益** | 深入臺北市大龍國小進行永續桌遊推廣，服務學生 46 人 |

### **2. 強化經濟創生與法扶行動隊**
由法律系師生組成「法扶行動隊」，深入北海岸三芝、金山、萬里及石門等區域，提供免費法律諮詢服務與偏鄉防詐宣導，解決在地長者與青年創生過程中面臨的法律問題。

| 諮詢服務項目 | 具體數據成效 |
| :--- | :--- |
| **服務次數與場次** | 公益法律諮詢 27 次、法治教育講座 1 場（金包里慈護宮/石門區公所） |
| **案件處理與涵蓋範疇**| 實質處理 14 件案件（涵蓋家事、財產、詐欺、遺產等領域） |
| **服務受惠人數** | 累計服務逾 60 人次，並於三芝區形成穩定回訪社群 |

### **3. 實踐在地永續陪伴與基地建置**
結合產業資源與技職學校，以循環建材改造在地空間，建立區域教育中心；同時舉辦多元營隊活動與國際交流，深化在地陪伴。

*   **萬里國中校史室暨永續教育基地**：攜手環球購物中心、SkillsforU、瑞芳高工，打造北海岸首座循環建材教學基地，設置「人物誌採訪區」，並有萬里國中 7 位學生全程深度參與設計。
*   **永續教育夏令營**：於萬里國中辦理為期 3 天之營隊，融合無人機、數位桌遊、編織與彩繪等課程。
*   **台日國際共學交流**：接待日本天理大學、中部大學及東京國際大學師生走訪三芝故事館與萬里國中，進行草仔粿手作與「永生樹」永續互動。

### **4. 跨校網絡連結與整體成果**

| 統計項目 | 具體數據 |
| :--- | :--- |
| **校內外活動總場次** | 累計辦理 48 場 |
| **總參與人次** | 累計超過 1,200 人次 |
| **跨校聯盟合作規模** | 成立「北海岸 USR 跨校聯盟」（共 7 所大學），教師共學達 85 人次 |
## 三、技術創新或特色亮點

1.  **循環建材產官學共創「永續教育基地」**
    *   **執行方式**：串聯企業（環球購物中心）、NGO（SkillsforU、懷世代公益平台）、技職端（瑞芳高工室內空間設計科）及媒體（聯合報倡議家），運用環保循環建材改造萬里國中校史室與閱讀教室。
    *   **社會與經濟價值**：創造北海岸首座「循環建材實體示範教室」，展現跨域資源整合與廢棄物循環再利用的教育示範效益，該模式於113年獲得「永續教科書2025」企業組優秀案例。
2.  **偏鄉法扶行動隊與社區安全防護網**
    *   **執行方式**：由法律系專業師生駐點三芝故事館、金包里慈護宮及萬里區公所，提供常態化法律諮詢服務，並針對偏鄉長者開設防詐騙與婦女權益講座。
    *   **社會與經濟價值**：將大學法律專業落地，補足偏鄉法扶資源缺口，降低社區長者遭詐騙風險，強化在地創生團體之法制健全性。
3.  **「北海岸 USR 跨校聯盟」制度化協作平台**
    *   **執行方式**：串聯中國文化大學、致理科大、馬偕醫學院、臺北科技大學、臺灣海洋大學、明志科大及淡江大學等 7 所大專院校，透過 LINE 社群與定期實體共識會議推進資源共享。
    *   **社會與經濟價值**：打破單一學校資源限制，實現課程共構、聯合展覽與教師增能，建立可持續發展的大學社會責任區域網絡。
## 四、資源鏈結與經費執行

*   **外部資源引入**：
    *   **政府單位**：教育部（補助款）、新北市萬里區公所、石門區公所。
    *   **企業與NPO合作**：環球購物中心（Global Mall）、SkillsforU、懷世代公益平台、聯合報倡議家。
    *   **教育與民間機構**：瑞芳高工、金包里慈護宮、浪金山、三芝故事館。
*   **計畫經費執行狀況**：

| 款項名稱 | 核定金額 (NTD) | 實際執行金額 (NTD) | 執行率 |
| :--- | :--- | :--- | :--- |
| **教育部補助款** (經常門) | $2,750,000 | $1,952,395 | 71.00% |
| **學校配合款** (自籌款) | $350,000 | $224,356 | 64.10% |
| **計畫總經費** | **$3,100,000** | **$2,176,751** | **70.22%** |

*   **剩餘經費主要用途說明**：因114年度專任助理人員異動（原執行秘書張芳瑜、經理楊睦庭於6月離職，7月由朱紫榕、邱郁書接任）及萬里國中校史室場域工程施工期程順延，致部分經費進度延後。剩餘經費規劃於第4季持續投入場域維運、跨校共學活動及教材產出推廣。
## 五、成效評估機制

計畫建立質量並重的系統化評估體系：

1.  **量化指標與數據追蹤**：
    *   建置「場次與人次統計表」專案資料庫。
    *   **永續素養量表前後測**：學生永續素養平均分數由 **72.4 分顯著提升至 81.6 分**。
    *   **滿意度調查**：整體課程與活動滿意度問卷達 **85% 至 87%**。
2.  **質性成效評估與 SROI 機制**：
    *   採集學生課後心得與焦點座談，學生反映能「於真實場域解決問題」。
    *   針對「金山高中文史教育基地專案」導入 **SROI（社會投資報酬率）** 計算，量化教育場域改造的社會影響力。
3.  **校務系統整合**：
    *   評估數據回饋至校內永續發展暨校務研究中心，納入平衡計分卡（BSC）四大構面（校務治理、人才培育、在地需求、陽明山學）追蹤考核。
