# 「”原“創教育–原民技藝文化推廣」114年度執行成果報告

## 一、計畫基本架構與目標

本計畫以「教育平權」與「文化永續」為核心使命，致力於將泰雅族傳統技藝轉化為現代教育場域可實踐的教具與課程，達到傳統文化保存與活化的目的。計畫團隊結合跨領域師資與部落耆老智慧，從小學至樂齡大學建立全齡共學機制，並進一步培育原民文化創意人才，朝向文化創業與部落永續發展邁進。

- **計畫名稱**：”原“創教育–原民技藝文化推廣
- **計畫類型**：大學特色類萌芽型計畫
- **計畫期程**：114年1月1日至114年9月30日（本期報告採計區間）
- **核心議題**：文化永續
- **關聯 SDGs**：
  - SDG 4 優質教育（Quality Education）
  - SDG 11 永續城市及社區（Sustainable Cities and Communities）
- **實踐場域**：
  - **固定實踐場域**：
    1. 宜蘭縣大同鄉 寒溪部落
    2. 桃園市復興區 羅浮國小
    3. 桃園市復興區 光華國小
    4. 桃園市復興區 長興國小
    5. 宜蘭縣南澳鄉 金岳社區發展協會
  - **合作擴展場域**：宜蘭縣四季部落、新北市烏來部落/烏來泰雅民族博物館、新竹縣尖石鄉、臺北市萬華社區大學、基隆市暖暖高中、新竹市光武國中、德明財經科技大學、國立羅東高級商業職業學校、蘭陽原創館。

## 二、核心執行內容與數據成效

計畫於114年1月至9月期間，積極於校內外及部落場域開展推廣活動，重點執行內容與量化數據如下：

### 1. **原民技藝體驗營與推廣活動**
計畫團隊邀請原住民專家學者、部落耆老及學校教師，前往各級學校與社區辦理編織、薏苡串珠及山林獵人文化體驗等活動，達到全齡推廣目標。
- **數據成效**：共辦理 **11場次**，累計 **311人次** 參與。

| 合作場域/單位 | 活動內容摘要 | 參與人數（校內/校外） |
| :--- | :--- | :--- |
| **光武國中** | 原住民織布技藝體驗營（2場） | 校內10人次 / 校外20人次 |
| **長興國小** | 織布體驗營（1場）、薏苡串珠體驗營（1場） | 校內3人次 / 校外30人次 |
| **萬華社區大學** | 樂齡原住民技藝體驗營（1場） | 校外15人次 |
| **德明財經科技大學** | 原住民織布機成果推廣體驗營（1場） | 校內10人次 / 校外15人次 |
| **烏來/暖暖高中** | 參觀烏來泰雅民族博物館、泰雅族一日生活體驗營 | 校內1人次 / 校外12人次 |
| **中華科大樂齡大學**| 樂齡織布體驗、菱形紋編織課程（產出悠遊卡布條及鑰匙圈） | 40人次 |

### 2. **原民文化跨領域課程與校內實踐**
於中華科技大學開設通識課程「大學生社會實踐」，結合原民文化資料蒐集、田野調查與成果發表，深化學生對多元文化的尊重與公民素養。
- **數據成效**：
  - 辦理「通識期末學生原民文化學習成果發表會」**1場次**，共 **53人次** 參與。
  - 校內學生參與山林體驗、原民文化採集與拜訪累計達 **140人次**。

### 3. **部落共識溝通與產官學合作會議**
計畫主持人與團隊定期深入宜蘭寒溪部落、金岳部落及合作學校召開共識會議，深化部落與學校之對話機制。
- **數據成效**：辦理工作協調與合作會議 **3場次**（1月、2月、3月、7月、8月、9月滾動進行），累計 **34人次** 專業人員與耆老參與。

## 三、技術創新或特色亮點

### 1. **桌上型「小型織布機」教具開發與模組化**
- **執行方式與技術**：團隊將傳統龐大複雜的泰雅族地機（織布機）進行結構簡化與微型化設計，研製成便攜且易操作的「小型織布機」教具。
- **社會與經濟價值**：降低了傳統編織技藝的學習門檻，使原本僅能「觀賞」的文化資產轉化為「可手作體驗」的教材；教具具備量產與模組化教學潛力，為文化文創化奠定基礎。

### 2. **部落耆老與專業專家深度協同教學**
- **執行方式與技術**：引進包含寒溪部落黃志堅牧師（獵人學校創辦人）、四季教會江明清牧師（泰雅語教材主編）、陳初保泰雅耆老（族語聖經審譯）、金岳社區陳芃伶總幹事（台大城鄉所碩士/編織專家）等核心力量共同投入。
- **社會與經濟價值**：將部落傳統山林智慧、古調、族語及織布技術系統化導入高等教育與K-12體系，賦予部落耆老專業教師地位，提升族群文化自信與認同感。

### 3. **跨世代與跨層級「全齡共學」推廣模式**
- **執行方式與技術**：打破傳統單一對象的推廣模式，涵蓋國小、國中、高中、科技大學、社區大學至樂齡大學。
- **社會與經濟價值**：實現「全民原教」理念，讓長者活化腦力與手指肌力、青年獲得多元文化素養、幼童從小扎根文化包容性，建立世代共融的示範架構。

## 五、成效評估機制

計畫建立多重回饋機制與系統化資料蒐集流程：

1. **評估機制**：採用「教學意見調查問卷」與活動後學習成果展示評估。
2. **評估面向**：
   - **技能掌握度**：評估學員對織布、植物薯染、串珠及竹筒飯等技藝實作的熟練度。
   - **文化認知與態度**：量化學員在參與後對泰雅歷史、多元族群共融與文化保存意願的改變。
   - **滿意度與擴散力**：檢視課程設計、師資、場地滿意度，以及學員將經驗分享予親友之「文化擴散效益」。
3. **重要結論**：調查結果顯示，體驗式教學能顯著打破平地學生對原住民族的刻板印象，並大幅增進樂齡與幼童學員對傳統工藝價值的認同，證明「手作體驗」結合「故事講述」能帶來深遠的社會影響力。
