# 國立中山大學 USR 計畫 114 年度重點執行成果報告

## 一、計畫基本架構與目標

本計畫立足高雄港灣都市與屏東/高雄農漁城鄉，面對工業轉型、氣候變遷與人口老化等重度挑戰，整合「循環永續的環境」、「深耕地方的文化」與「公平包容的社會」三大主軸。計畫以「鏈結式」行動方法鏈結國內外場域，建立「大學－社區－職人」共構模式，旨在培育具全球視野與在地關懷的永續人才，並將臺灣地方轉型與循環維修經驗輸出至國際舞台。

*   **計畫名稱**：邁向永續轉型與創生：城市共事館的全球在地實踐
*   **計畫類型**：永續發展類國際合作型計畫
*   **計畫期程**：114年1月1日至114年9月30日（本報告期程；全期為114–116年）
*   **核心議題**：港灣工業城市淨零與公正轉型、農漁城鄉氣候調適、地方創生、循環維修經濟、文化轉譯與防災韌性。
*   **關聯 SDGs**：
    *   SDG 11 永續城市及社區
    *   SDG 12 負責任的消費及生產
    *   SDG 13 氣候行動
*   **實踐場域**：
    *   **國內固定實踐場域**：高雄市旗津區「技工舍 | 旗津社會開創基地」、高雄市前鎮區「前鎮第二公有市場」。
    *   **國內合作擴展場域**：高雄市旗山區「旗美社區大學」（鏈結美濃愛鄉協進會等在地組織）。
    *   **國外固定與合作場域**：英國倫敦（英國創意藝術大學/永續創新實驗室/Farnham維修咖啡館）、日本神奈川縣（神奈川大學）、越南胡志明市（越南胡志明市國家大學下屬社會科學暨人文大學）、日本京都市（京都大學地球環境學堂）、日本茨城縣（筑波大學）、日本富山縣（冰見市役所/國際交流中心）、日本川崎市役所、日本AIA區域創新聯盟（木下齊）、熊本縣津奈木町等。

## 二、核心執行內容與數據成效

### 1. **連結灣岸循環永續與環境公正轉型**
推動「南方修理聯盟」並結合城鄉民主審議與氣候防災，建立跨國/跨校永續教育示範點與維修據點，引導市民參與生活轉型與減碳行動。

| 績效項目 | 114年1-9月累積數據 |
| :--- | :--- |
| 開設相關課程 | 16 門 |
| 辦理工作坊 | 38 梯/場次 |
| 永續教育示範點 | 1 處（旗津技工舍） |
| 循環綠活節與跨國/跨校交流 | 14 場 |
| 投入全球實踐總人次 | 約 4,284 人次 |
| 南方修理聯盟累計成果 | 修復 >4,000 件物品（修復率約70%），減碳 73,898 公斤，培訓 >60 名志工 |

### 2. **發展灣岸創生創新與社會永續**
串連國際與在地農漁城鄉場域，推動「港區地域循環共生圈專案」，並進行跨國共課與文化交流，帶動農村與舊港區在地產業轉型。

| :--- | :--- |
| 開設課程 | 8 門 |
| 工作坊 | 6 場 |
| 國際交流活動 | 7 場（含愛媛大學旗美共課1次、冰見國際攝影展1次） |
| 成果發表 | 6 人/場次 |

### 3. **促進港灣轉型與地方智慧之文化永續**
以高雄港灣為核心，推動人文調查與勞工/人權歷史轉譯，辦理學程、展覽與國際論壇，奠定城市文化治理基礎。

與日本、英國及東南亞頂尖學府及公部門締結夥伴關係，透過雙向駐地行動與共培共課，建構具全球實踐力的跨域人才養成體系。

## 三、技術創新或特色亮點

1.  **「南方修理聯盟」草根循環經濟與國際維修網絡接軌**
    *   **執行方式**：整合高雄、台南、屏東多所社區大學，成立「高雄小家電診所」與6處維修據點。開發農機具與家電維修課程，並登上國際「Open Repair Alliance」平台。
    *   **效益**：修復率高達七成，減少近7.4萬公斤碳排放，114年更獲邀至英國創意藝術大學「第四屆英國維修咖啡館會議」進行臺灣經驗發表。
2.  **「調查—轉譯—展演」跨國文化與人權轉譯模組**
    *   **執行方式**：從「二十五淑女事件」50週年調查看起，跨國連結墨西哥AZUL ARENA畫廊與美國哥倫比亞大學，舉辦《捲入裝配》美墨邊境與臺灣勞工聯展；並串連全臺8所大專院校與高中，發表《2025 Action! 519 跨校人權轉譯聯展》。
    *   **效益**：將在地威權歷史、勞工與女性工傷議題進行當代藝術與人權轉譯，成功躍上國際展演舞台。
3.  **台日港灣與城鄉地域循環共生跨國平台**
    *   **執行方式**：成立「台日港灣研究/教學平台」，鏈結京都大學、筑波大學、東北大學及富山縣冰見市役所。推動「台日攝影嘉年華」及「氣候變遷與地方知識工作坊」。
    *   **效益**：促進高雄港與東京灣/冰見市在工業歷史、氣候調適與防災韌性上的深度跨國政策與學術對話。
4.  **「大學–社區–職人」共構之技工舍基地創新營運**
    *   **執行方式**：活化旗津「技工舍」，導入在地職人與「滔滔社」，培育學生駐地創業（如「線頭工作室」），並辦理「循環綠活節」永續市集。
    *   **效益**：獲日本 Good Design Award 肯定，建立可持續自運作的地方創生與永續教育基地。

## 五、成效評估機制

1.  **評估機制設計**：計畫導入社會投資報酬率（SROI）評估架構，由校級「校友服務暨社會責任中心」專責協助，針對學生、社區居民、合作館舍與國際夥伴等利害關係人，進行質量化指標追蹤與自評工作坊。
2.  **學生前後測問卷分析（113-2學期）**：
    *   **施測對象與回收**：修課學生總計613人次，前測回收441份。經配對並排除未填寫後測者，**有效成對問卷為313份**。
    *   **重要結論**：問卷結果顯示學生在「永續城市與社區理念認知」、「USR相關知識與實作能力」、「對USR計畫之認同感」及「學校永續目標對接度」等面向，後測分數均呈現顯著成長，顯示課程與場域實踐有效提升學生之永續素養與問題解決能力。
