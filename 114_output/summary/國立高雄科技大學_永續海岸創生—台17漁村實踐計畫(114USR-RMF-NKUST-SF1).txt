# 國立高雄科技大學「永續海岸創生—台17漁村實踐計畫」114年度執行成果報告
## 一、計畫基本架構與目標
本計畫由國立高雄科技大學（高科大）推動，歷經8年（自106年起至今第四期）的推動與深耕，已由初期的大學主導示範，轉型為地方陪伴與智庫角色。計畫核心使命在於回應全球ESG與永續發展趨勢，以「在地永續」、「人才培育」與「產業創新」為三大主軸，將高雄永安之成功經驗擴散至台17線沿海漁村（含彌陀、梓官），協助地方發展具韌性與循環價值的海岸產業，達到漁村永續共榮。
*   **計畫名稱**：永續海岸創生—台17漁村實踐計畫
*   **計畫類型**：永續發展類特色永續型計畫（教育部第四期114–116年）
*   **計畫期程**：114年1月1日至114年9月30日（本期執行區間）
*   **核心議題**：產業鏈結與經濟永續
*   **關聯 SDGs**：
    *   SDG 2 零飢餓
    *   SDG 12 負責任的消費及生產
    *   SDG 14 水下生物
*   **實踐場域**：
    *   *固定實踐場域*：
        *   **高雄市永安區**：百甲休閒漁場、于錦鳳養殖場、蘇家養殖場、烏林投社區活動中心、烏林投水域、蘇班長安心漁場、永華社區發展協會、高雄市永安區科技養殖協會、永新灣
        *   **高雄市梓官區**：高雄市梓官區漁會
        *   **高雄市彌陀區**：高雄市彌陀區海惠繁養殖場、鑾鑫水產、高雄市彌陀區南安國民小學
    *   *合作擴展場域*：高雄市永安區新港社區發展協會（青創聚落）
*   **計畫主持團隊**：計畫主持人丁國桓副教授（海管所）；共同主持人謝淑玲特聘教授兼副校長、詹昊棠助理教授；協同主持人包含侯智耀、葉恒志、龔蒂菀、歐招輝、陳彥銘、陳秀惠、丁后儀等多位跨領域專家。
## 二、核心執行內容與數據成效
本計畫對焦 ESG 三大面向，劃分四大執行子項目，具體成效如下：
### 1. **【環境保護】水下生態防護與養殖減碳技術**
*   **執行內容**：建置海洋環境數據平台，研發人工魚礁區鬼網清除模式；媒合地方組織進行水下調查；導入養殖業碳足跡管理，協助業者進行碳盤查試算與減碳輔導；結合課程引導學生針對魚塭高耗電問題開發動能回收之節能水車。
*   **數據成效**：
| 項目 | 執行成效與數據指標 |
| :--- | :--- |
| **碳足跡與減碳** | 完成在地養殖業者碳盤查試算與主要碳排放來源分析，提供具體減碳策略建議。 |
| **水下生態調查** | 媒合地方組織完成水下資源與生態現況盤點，建置鬼網清除數據平台（預計年底下水實測）。 |
| **綠能設備研發** | 結合工業設計與模具系課程，完成「養殖水車動能結合回收能源發電」雛型設計。 |
### 2. **【社會責任】食漁與水域安全教育深耕**
*   **執行內容**：串聯台17線在地國中小學，培養食漁教育種子師資，研發特色教案；辦理水域安全教育體驗、入校宣導與師資培育；受教育部及漁業署邀請，協助將食魚教育與水域安全教育結合並推廣至全國。
*   **數據成效**：
| 項目 | 執行成效與數據指標 |
| :--- | :--- |
| **在地扎根** | 輔導**高雄市彌陀區南安國民小學**成功申請通過「114年海洋保育在地守護計畫」。 |
| **青年創生** | 輔導在地漁青團隊獲**教育部「114年青年回鄉行動獎勵計畫」最高額度獎金**，用於場域改造與海洋教育基地建設。 |
| **推廣範圍** | 教育推廣由高雄在地永安、彌陀擴散至全國，達成跨縣市水安與食漁教育合作。 |
### 3. **【產業創新】水產副產物高值化與循環經濟**
*   **執行內容**：針對在地養殖產業（如石斑魚）之加工副產物，進行高值化生物萃取與產品開發，延伸水產品產業鏈，實現全魚利用與零廢棄目標。
*   **數據成效**：成功運用石斑魚加工副產物開發出「**黑蒜瑪卡文蛤精華**」等高價值保健/食品，建立水產循環經濟商業模式，並榮獲「**TSAA台灣永續行動獎**」肯定。
### 4. **【公司治理】人才培育與跨域網絡鏈結**
*   **執行內容**：開設「海岸地方創生學分學程」，導入SEL（社會情緒學習）理論建構學習量表；舉辦南部見學活動與SIG（特別興趣小組）交流，鏈結台17沿線團隊籌組「海岸創生聯盟」。
*   **數據成效**：完成SEL量表專家諮詢與預試；辦理多場跨校交流與南部見學，串連高科大（海管所、水食系、工設系、模具系、資管系、體育室）與大葉大學等跨校師生團隊。
## 三、技術創新或特色亮點
1.  **人工魚礁區鬼網清除數據平台**
    *   *執行方式*：結合資訊管理與海洋事務專業，建置水下廢棄漁網（鬼網）數據追蹤平台，結合地方組織調查與數據分析，建立系統化的清理與防護模式。
    *   *社會/經濟價值*：改善海洋棲地環境，減少漁業資源無謂消耗，提升水下生物多樣性（SDG 14）。
2.  **養殖水車能源回收與碳足跡管理技術**
    *   *執行方式*：針對魚塭高耗電特性，導入碳足跡盤查機制；同時由工設系與模具系跨域合作，將水車運轉動能結合回收發電系統。
    *   *社會/經濟價值*：降低養殖戶電費負擔與碳排放量，協助傳統養殖業應對未來碳關稅與ESG浪潮。
3.  **石斑魚副產物全魚利用技術（黑蒜瑪卡文蛤精華）**
    *   *執行方式*：由水產食品科學系團隊運用生物萃取與加工技術，將過去被視為廢棄物的加工副產物轉化為高附加價值保健產品。
    *   *社會/經濟價值*：促進產業循環經濟，減少廢棄物處理成本，提高水產品附加價值，並榮獲 TSAA 台灣永續行動獎。
4.  **基於 SEL（社會情緒學習）的 USR 學習成效評估工具**
    *   *執行方式*：導入SEL理論設計量化問卷，經專家諮詢與預試後，應用於海岸地方創生學程，評估學生在社會實踐中的情緒、共感與責任感養成。
    *   *社會/經濟價值*：精準優化USR教學實踐，確保大學人才培育與地方需求無縫接軌。

## 五、成效評估機制
本計畫建構多元且嚴謹的成效評估架構：
1.  **OKR與KPI目標管理**：採用目標與關鍵成果（OKR）及關鍵績效指標（KPI），由下而上確認實踐目標，定期追蹤量化進度，確保執行過程透明可追蹤。
2.  **社會影響力評估（SIA）與SROI**：引進社會投資報酬率（SROI）分析法，評估團隊開發之加工產品與創生方案，計算其直接經濟收益與廢棄物減量、產業循環等間接社會效益。
3.  **社會情緒學習（SEL）問卷**：針對修讀「海岸地方創生學分學程」之學生進行前後測，量化評估學生在社會責任、在地關懷與問題解決能力的養成，評估結果直接作為課程優化依據。
4.  **利害關係人回饋**：每月固定召開教師社群會議，並定期辦理地方座談會，蒐集在地養殖戶、漁會、社區協會與中小學教師之回饋意見，進行滾動式修正。
