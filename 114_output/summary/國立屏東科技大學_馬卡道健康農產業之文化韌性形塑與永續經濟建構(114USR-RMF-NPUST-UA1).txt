以下為根據國立屏東科技大學「馬卡道健康農產業之文化韌性形塑與永續經濟建構」計畫報告書所編製之詳細執行成果報告：
# 國立屏東科技大學 USR 計畫執行成果報告
**計畫名稱：馬卡道健康農產業之文化韌性形塑與永續經濟建構**

## 一、計畫基本架構與目標

國立屏東科技大學結合生技、農藝、畜產、文創與設計等多領域跨學門師生團隊，以「文化韌性」與「永續經濟」為雙核心主軸，透過學術能量深耕在地，將平埔族馬卡道文化復振、生態保育、循環農業與食農教育進行深度整合。計畫目標在於活化在地農產與歷史記憶，建構兼具文化深度與產業競爭力的永續地方生態圈。

*   **計畫名稱**：馬卡道健康農產業之文化韌性形塑與永續經濟建構
*   **計畫類型**：大學特色類萌芽型計畫（教育部第四期 114–116 年）
*   **計畫期程**：114年1月1日至114年9月30日（本階段報告期程）
*   **核心議題**：文化永續（兼及生態保育、循環農業與地方創生）
*   **關聯 SDGs**：
    *   SDG 3 良好健康與福祉
    *   SDG 4 優質教育
    *   SDG 11 永續城市及社區
*   **實踐場域**：
    *   **固定實踐場域**：
        1. 屏東縣內埔鄉：老埤社區發展協會、老埤馬卡道文化協會、泰安國小、榮華國小、隘寮國小、崇文國小
        2. 屏東縣萬巒鄉：赤山村（赤山社區發展協會）
    *   **擴展與合作場域**：屏科大附設非營利幼兒園、屏科大員生消費合作社、老埤牛角灣溪流域、馬卡道植物園、高雄師範大學（文化展演場域）
## 二、核心執行內容與數據成效

本計畫於執行期間，透過四大專業領域分工（由趙雲洋、古佳峻、侯博倫/陳秀足、洪孝宇等教授主責），達成多元面之實質進展：

### 1. **文化復振與數位教育扎根**
*   **執行內容**：蒐集整理德國柏林圖書館微縮史料、塔加里揚之戰（1635年）歷史文獻及法文論文（如李國銘老師論文翻譯）。開發馬卡道虛擬博物館、主題桌遊與走讀教材；將文史導入小學及幼兒園，辦理寒假營隊、米食教育與傳統工藝工作坊。
*   **數據成效**：

| 項目 | 執行成果與數據 |
| :--- | :--- |
| **校內開設課程** | 開設 **10 門** 跨領域 USR 學分學程課程 |
| **校內修課學生** | 累計超過 **600 人次** 選修 |
| **場域扎根學校** | 涵蓋 **4 所國小**（泰安、榮華、隘寮、崇文）及 **1 所非營利幼兒園** |
| **文史與體驗活動** | 辦理「搭加里揚之戰重演藝術展」（高師大場次，15人次）、內埔健走推廣（10人次）、文史採集與植物園勘查等多場次 |
| **國小營隊與工作坊** | 泰安國小寒假營隊：紅藜握壽司（23人次）、彩繪DNA/桌遊（25人次）、糕餅文化工作坊（27人次）等 |

### 2. **循環農業與精實農場管理**
*   **執行內容**：建置「雞舍 3.0」，優化外部取蛋動線以強化生物安全、動物福利與食品安全。引進黑水虻資源循環技術（與大仁科大賴文亮教授合作），進行雞糞與農業廢棄物發酵利用；建立傳統作物（大風草、埔姜、月桃）栽培曆與栽培制度。
*   **數據成效**：
    *   完成了 **雞舍 3.0** 設施升級與無抗飼養動線設計。
    *   確立 **大風草**（燻蒸洗浴/抗菌）、**埔姜**（暖胃舒緩）、**月桃**（食藥兩用/保養）等 3 種關鍵傳統植物之農藝栽培與研發基準。

### 3. **生態保育與環境監測**
*   **執行內容**：於老埤社區牛角灣溪田區架設猛禽棲架與自動感應相機，進行長期生態與鳥類物種監測，成功引導黑翅鳶等猛禽進駐協助生物防治，同時捕捉到極具價值的溪流暴漲與野生物影像。
*   **數據成效**：
    *   完成第一年鳥類生態監測基線數據資料庫建立。
    *   架設棲架並成功拍攝到 **黑翅鳶** 等多種猛禽活動影像，引發媒體報導與社區生態關懷。

### 4. **特色商品開發與品牌加值**
*   **執行內容**：結合族群傳統文化與農產進行加值設計，取得品牌智慧財產權，並於校內實體通路進行商業販售測試，同時拓展化妝品國際原料認證（INCI）。
*   **數據成效**：

| 商品 / 智財名稱 | 目前進度與銷售狀態 |
| :--- | :--- |
| **「馬卡道圖像商標」** | **成功取得智慧財產權商標註冊** |
| **馬卡道雞油辣椒醬** | 已經量產，於屏科大員生消費合作社上架公開販售 |
| **馬卡道雞油油蔥酥** | 已經量產，於屏科大員生消費合作社上架公開販售 |
| **紅藜信封捲** | 已經量產，於屏科大員生消費合作社上架公開販售 |
| **月桃米香** | 完成產品研發，進入量產製造與包裝設計階段 |
| **馬卡道萃取物** | 推進取得 **INCI 國際化妝品原料認證** |
## 三、技術創新或特色亮點

1.  **雞舍 3.0 與黑水虻低碳循環農業系統**：
    *   **技術內容**：結合畜產管理與環境工程，設計新型「外部取蛋」雞舍以阻絕病原體，並導入黑水虻將農場有機廢棄物與雞糞高效分解再利用。
    *   **社會/經濟價值**：實現無抗生素之高品質蛋品生產，改善生物安全與動物福利，打造零廢棄的低碳循環農業示範示範點。
2.  **馬卡道文史數位化與跨世代共學教育模組**：
    *   **技術內容**：搜羅海外微縮膠卷史料，運用 VR 虛擬實境、桌遊與多媒體，將「塔加里揚之戰」與採集口述史轉化為數位教材。
    *   **社會/經濟價值**：打破傳統單向教學，透過科技讓國小學童與大學生親近平埔族歷史，成功形塑族群文化認同與世代共學。
3.  **猛禽棲架之生態服務與社區綠色經濟**：
    *   **技術內容**：架設人工高空棲架誘引黑翅鳶等猛禽定居，運用自動攝影機進行大數據監測。
    *   **社會/經濟價值**：以自然生物防治取代化學農藥，維護牛角灣溪生態多樣性，並成為發展生態旅遊與環境教育之核心亮點。
4.  **馬卡道品牌智財授權與商業化模組**：
    *   **技術內容**：完成馬卡道專屬圖像商標註冊，並將月桃、大風草進行 INCI 萃取分析與食品加工試量產。
    *   **社會/經濟價值**：落實智財保護，賦予地方傳統農作物更高的附加價值，建立穩定銷售通路，回饋社區經濟發展。

## 五、成效評估機制

本計畫建立「執行產出（Outputs）→ 學習與社群成效（Outcomes）→ 長期影響（Impact）」之完整三階評估架構，並導入 SROI（社會投資報酬率）計算機制：

1.  **量化與質化追蹤**：
    *   **產出追蹤**：定期統計修課人數（本年度逾 600 人）、教具開發量、活動場次及商品上架毛利。
    *   **意見回饋**：設計利害關係人問卷與訪談，針對國小師生、社區居民及選修學生評估「跨域素養」、「社區參與度」與「滿意度」。
2.  **SROI 評估數據設計**：
    *   訂定核心換算指標：包含「學分學程修畢與作品數」、「虛擬教具採用人次」、「猛禽拍攝時間與次數比率」、「生態解說遊程人次」及「特色商品銷售毛利」，將質化社會效益轉換為具體社會價值金額。
3.  **資料治理與倫理**：
    *   遵循「蒐集→驗證→轉換→歸檔→發布→備份」六步驟進行資料管理，並遵守個人資料與原住民族文化授權倫理。
