以下為您整理之**「洄瀾再起：永續觀光山海情」**慈濟大學 114 年度大學社會責任（USR）計畫重點執行成果報告：
# 「洄瀾再起：永續觀光山海情」114年度執行成果報告
## 一、計畫基本架構與目標
本計畫以「永續旅遊」與「智慧科技應用」雙軸驅動，旨在協助花蓮震後產業擺脫單純的硬體重建，轉型為具備永續韌性與數位競爭力的產業生態系。慈濟大學發揮作為地方創生「智庫」與「引擎」的作用，整合跨領域師資與學生實踐力，建立「診斷、聚焦、培育到升級」的產學共榮發展範式。
*   **計畫名稱**：洄瀾再起：永續觀光山海情
*   **計畫類型**：大學特色類萌芽型計畫
*   **計畫期程**：114年1月1日至114年9月30日（本報告期）
*   **核心議題**：產業鏈結與經濟永續
*   **關聯 SDGs**：
    *   SDG 1 消除貧窮
    *   SDG 8 合宜工作與經濟成長
    *   SDG 12 負責任的消費及生產
*   **實踐場域**：
    *   **固定實踐場域**：花蓮縣花蓮市（含魏嘉賢議員服務處、藍鵲驗證服務股份有限公司、台灣觀光地方創生協會、銀川永續有限公司、洄瀾薯道有限公司、縣餅實業有限公司、家樂達股份有限公司、田祖永續有限公司、喜歡采風烘焙坊、琺璐祚有限公司、莎莉經典美食有限公司、豐禾興實業有限公司、讚炭工房、德利豆乾專賣店、女王萬歲民宿、洄瀾醬人有限公司等16處）。
    *   **合作擴展場域**：花蓮縣新城鄉、吉安鄉、壽豐鄉（壽豐考古博物館、白鮑溪、七星潭戰備坑道）、玉里鎮（金喜檸檬、九日良田）等。
## 二、核心執行內容與數據成效
### 1. **培育永續與數位人才（跨領域課程鏈結）**
開設11門跨領域USR課程，將AI工具、綠色行銷與地方食材融入教學，強化學生實戰能力並協助在地業者轉型。
*   **具體數據**：修課學生達 245 人次；學生自發成立「青和社團」，創立地方品牌「洄瀾系 huilan_galaxy」，並架設 IG、YT、FB 及 Line@ 社群平台。

| :--- | :--- | :--- | :--- |
| **人工智慧軟體應用** | 2學分 / 選修 | 運用 NotebookLM 等 AI 工具協助 3 家旅宿業者診斷痛點與開發 AI 客服原型 | 29 人 |
| **自媒體傳播** | 3學分 / 選修 | 辦理綠幕宣傳片工作坊，結合數位行銷與綠色科技概念製作宣傳影片 | 46 人 |
| **綠色行銷** | 3學分 / 選修 | 辦理花蓮兩天一夜輕旅行，學生製作永續觀光短影音並上架「洄瀾系」平台 | 22 人 |
| **西式點心（初/進階）**| 各4學分 / 選修 | 融入馬告、刺蔥、瑞穗紅茶、剝皮辣椒等花蓮在地食材進行健康烘焙研務 | 41 人 |

| **保健藥膳學** | 2學分 / 選修 | 結合傳統藥膳、天然發酵與花蓮在地農產，提升學生食藥保健知識素養98.5%| - |

### 3. **產業生態系整合與數位服務落地**
輔導花蓮觀光業者從「各自為政」轉為「資源共享」，推動數位工具落地。
*   **具體數據**：
    *   促成「**花蓮永續觀光旅遊發展協會**」成立，整合 **34 家** 在地觀光旅宿與伴手禮業者。
    *   完成 **9 家** 企業（花蓮縣餅、德利豆乾、甜一口糖藝、洄瀾醬人、家樂達、法璐祚、兆鴻石業、喜歡采風烘焙坊、建華開發）之 AI Agent 客服流程診斷、FAQ 彙整與 API 串接規劃。
    *   簽署 **17 份** 合作意向書。
### 4. **成果推廣與國際影響力**
將花蓮地方創生與永續經驗輸出至國內外展覽與學術場域。
*   **具體數據**：參與 **3 場** 大型成果展，校內參與人次達 **42 人次**。
    *   **展覽推廣**：參展「2025 亞太永續博覽會」與「2025 USR EXPO」，並受邀與耕莘專校共同辦理跨域 SIG 交流。
    *   **國際輸出**：前往日本大阪世博實地考察「零廢棄活動設計」；計畫主持人郭又銘副教授赴印尼進行地方創生專題演講。
## 三、技術創新或特色亮點
1.  **AI Agent 智慧客服與企業數位轉型**
    *   **技術與執行內容**：與遠傳電信合作，針對在地觀光與伴手禮業者導入 AI Agent 智慧客服系統。團隊深入 9 家企業進行訪談，協助建置專屬 FAQ 庫與 API 串接，降低傳統自動化客服的門檻。
    *   **社會與經濟價值**：解決震後人力短缺問題，提升業者24小時回應顧客之服務品質與數位行銷效率。
2.  **在地化「綠色永續認證系統」**
    *   **技術與執行內容**：結合「藍鵲驗證服務股份有限公司」，打造適用於在地中小企業的永續旅遊認證標準，並辦理永續稽核員培訓，輔導業者提交綠色認證文件。
    *   **社會與經濟價值**：協助業者（如花蓮縣餅）確立品牌永續定位，讓永續經營從口號轉化為可追蹤的標準化資產。
3.  **「洄瀾系」學生自媒體品牌與地創育成**
    *   **技術與執行內容**：由學生組成「青和社團」，整合綠幕棚拍與 AI 影片剪輯技術，針對在地小農與業者（如女王萬歲民宿、洄瀾醬人）進行短影音創作與多平台行銷。
    *   **社會與經濟價值**：建立「學生做中學、業者獲得免費行銷資源」的雙贏模式，大幅提升花蓮觀光品牌在青年族群中的曝光度。
4.  **國際「零廢棄經驗」在地化落地**
    *   **技術與執行內容**：赴日本大阪世博考察會場之永續與廢棄物減量設計，並將其概念導入「花蓮永續觀光旅遊發展協會」所主辦的在地旅遊活動中。
    *   **社會與經濟價值**：將國際頂尖 ESG/SDGs 實踐經驗輸入花蓮，提升在地活動的環境效益與國際視野。
## 四、資源鏈結與經費執行
*   **外部資源鏈結**：藍鵲驗證服務(股)公司、遠傳電信、花蓮永續觀光旅遊發展協會(34家會員)、魏嘉賢議員服務處、耕莘健康管理專科學校。

## 五、成效評估機制
1.  **評估架構**：採用 **SROI（社會投資報酬）** 評估架構，從三個構面追蹤成效：
    *   *經濟面*：在地產業營收變動、數位轉型導入率、AI客服效益。
    *   *社會面*：學生社會實踐力、產學合作黏著度、社區凝聚力。
    *   *環境面*：永續旅遊推動成果、綠色標章申請數。
2.  **資料蒐集與分析工具**：
    *   *量化指標*：修課人數、活動參與人次、證照取得數、標章申請數、協會會員數。
    *   *質化指標*：課程回饋問卷、利害關係人深度訪談（如花蓮縣餅、女王萬歲民宿、洄瀾醬人等負責人回饋）、實地觀察紀錄。
    *   *工具整合*：數據定期匯入校務研究平台，運用 **Power BI** 進行資料視覺化分析，並將結果回饋至永續發展辦公室以編撰 USR 年報。
3.  **評估發現與結論**：
    *   計畫成功促成業者從「被動接受」轉為「主動追求永續與數位化」。
    *   「AR/VR 作品產出」與「永續認證核發數量」進度稍有延遲，原因為工作坊排定於後半年，且業者蒐集認證佐證資料耗時較長，團隊已指派專員進行一對一文件輔導。
