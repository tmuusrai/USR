這是一份依據明志科技大學《北台首學-山與水之間》114年度執行成果報告書所整理的重點執行成果報告：
# 明志科技大學 USR 計畫 114 年度重點執行成果報告
## 一、計畫基本架構與目標
本計畫為第四期教育部大學社會責任實踐計畫（114–116年）之大學特色類萌芽型計畫，以「淡水河流域」為核心推動場域。計畫旨在透過河川廢棄物調查、生態復育、永續農業與循環經濟，將明志科技大學建構成為區域環境教育中心，並藉由公私協力與跨校合作深化在地永續影響力。
- **計畫名稱**：北台首學-山與水之間
- **計畫類型**：大學特色類萌芽型
- **計畫期程**：114年1月1日至114年9月30日（報告期程）
- **核心議題**：環境永續
- **關聯 SDGs**：
  - SDG 6 乾淨用水及衛生
  - SDG 11 永續城市及社區
  - SDG 12 負責任的消費及生產
- **實踐場域**：
  - **固定實踐場域**：新北市泰山區（各級學校、貴子坑溪、大窠溪）
  - **合作擴展場域**：
    - 水域：新北市新莊區（中港大排、貴子坑溪）；淡水、八里、五股、蘆洲、三重、樹林、鶯歌等區（大漢溪、新店溪、北勢溪）；瑞芳區（鼻頭漁港）。
    - 陸域：桃園市楊梅區（台塑楊梅有機生態農場）。
## 二、核心執行內容與數據成效
### 1. **淡水河流域川廢調查與公私協力行動**
團隊與荒野保護協會及地方水環境巡守隊合作，展開淡水河全流域溯源調查，建立廢棄物熱點資料庫並串聯政府即時通報與清運機制，亦延伸至鼻頭漁港淨港行動。
| 項目 | 具體數據 / 合作單位 |
| :--- | :--- |
| **川廢溯源調查長度** | 自113年331公里擴大至114年**353.5公里** |
| **培訓與出隊人次** | 辦理工作坊培訓**47位志工**；3–8月調查與複查合計出隊**188人次** |
| **鼻頭漁港淨港成果** | 依ISO 20121標準辦理3場，動員**>120人**，清除該港**60%廢棄物** |
| **主要合作夥伴** | 荒野保護協會、富邦人壽、南亞科技、新北市環保局、十河分署 |
### 2. **食農教育推廣與水質改善實驗**
與台塑楊梅農場進行產學合作，於農場規劃食農教育課程及博卡西（Bokashi）有機肥製作示範，並於農場生態池執行有效微生物水質淨化測試。
| 項目 | 具體數據 / 合作單位 |
| :--- | :--- |
| **產學合作與經費** | 與台塑楊梅農場簽署**20萬元**產學合作計畫，規劃20場活動 |
| **執行場次與參與人數** | 截至9月底已辦理**5場**食農教育，累計**353人次**參與 |
| **校內正式課程選修** | 開設「永續農業與綠色生活體驗」，共有**44位學生選修** |
### 3. **校園生態教室建構與永續教育**
於明志科大校園建置「台灣瀕危物種復育生態溝」，並啟動鳥類、昆蟲、植物與台灣原生種水草調查，將校園打造成區域生態教育基地。
| 項目 | 具體數據 / 合作單位 |
| :--- | :--- |
| **生態溝揭牌參與** | 114年8月4日揭牌，包含泰山區長、貴子/貴賢/明志里長、楊梅高中校長等出席 |
| **環境教育活動效益** | 辦理生態瓶製作、校園生態導覽等，截至9月底累計**400人次**參與 |
| **合作單位** | 台北市野鳥學會、楊梅高中、台塑企業總管理處 |
### 4. **減塑循環與跨校永續行動**
推動校園循環餐盒與獨木舟體驗結合減塑宣導，並鏈結「北海岸聯盟」7所大專院校及越南國際夥伴推廣環境行動。
| 項目 | 具體數據 / 合作單位 |
| :--- | :--- |
| **循環餐盒試辦** | 於USR共同培力及環境永續論壇採用鐵盒便當，共**200人次**參與 |
| **跨校聯盟夥伴** | 北科大、致理、文化、淡江、馬偕醫護、台北海洋科大、元培醫事科大 |
| **國際交流** | 越南胡志明市孫德勝大學（夏令營與紅樹林固碳教育） |
## 三、技術創新或特色亮點
1. **無人機（空拍機）川廢監測與學生專業考照**：
   - **執行方式**：導入穿越型空拍機深入紅樹林或陡峭邊坡進行川廢監測，並辦理空拍機訓練營。
   - **價值**：成功輔導學生考取無人機飛行證照，大幅提升難以到達區域的廢棄物監測效率與資料精確度。
2. **廚餘微生物處理與低膽固醇雞蛋循環系統**：
   - **執行方式**：利用有益微生物處理廚餘，養殖黑水虻後作為蛋雞替代飼料。
   - **價值**：有效提升母雞產蛋率，產出的雞蛋膽固醇僅為市售雞蛋的 **1/4**，且 Omega-3 脂肪酸含量更高，實現農業廢棄物高值化循環。
3. **有效微生物（EM）水質生態改善技術**：
   - **執行方式**：因貴子坑溪進行工程，改於楊梅農場小型生態池添加有效微生物菌液進行5個月連續測試。
   - **價值**：顯著改善水體優養化現象，驗證水質淨化技術於流動水體的應用可行性。
4. **獨木舟水域體驗結合環境行動劇**：
   - **執行方式**：與台灣運動帆船協會及果陀劇場合作，於八里推動低強度獨木舟體驗並演出《危急時刻》行動劇，規定參加民眾需攜回10個塑膠廢棄物。
   - **價值**：將親水休閒、淨河行動與戲劇教育結合，創新海洋與環境教育模式。
## 四、資源鏈結與經費執行
### 外部資源引入
- **企業與產學合作**：台塑楊梅農場提供 20 萬元產學合作計畫；南亞科技、富邦人壽提供企業志工人力。
- **NGO與專業單位**：荒野保護協會、台北市野鳥學會、台灣湛藍海洋聯盟、台灣運動帆船協會、果陀劇場。
- **政府機關**：經濟部水利署第十河川分署、新北市環保局、新北市高灘處、泰山區公所。
### 經費執行情形（期程：114年1月1日至114年9月30日）
- **教育部補助款**：核定 2,750,000 元，實際執行 2,013,376 元（執行率 73.21%）。
- **學校配合款**：核定 550,000 元，實際執行 355,713 元（執行率 64.68%）。
- **計畫總經費**：核定 **3,300,000 元**，實際執行 **2,369,089 元**，整體執行率為 **71.79%**。
- **剩餘經費主要用途**：支應114年第四季度之成果發表記者會（11月25日）、川廢調查說明會（12月）、學生循環餐杯推廣活動（11月）及相關計畫結報費用。
## 五、成效評估機制
1. **評估機制構架**：採用 **SROI（社會投資報酬率）** 模式，分為「明確目標與範圍」、「確認利害關係人」、「量化資源投入」、「估算具體成果輸出」及「計算SROI值」五大步驟。
2. **資料蒐集與品保**：建立標準作業流程（SOP），每場活動後由專案助理施測前後問卷並上傳滿意度調查報告，每月彙整統計參與人次與產出。
3. **重要評估發現**：
   - **環境成效**：連續兩年調查顯示，北部流域川廢量顯著低於中南部，且低於頭前溪與蘭陽溪，證實跨縣市橫向整合與攔截機制發揮成效。
   - **社會影響力**：年度成果發表會平均吸引約 20 則新聞報導，議題聲量可維持約一個月，有效提升大眾對河川永續的關注。
